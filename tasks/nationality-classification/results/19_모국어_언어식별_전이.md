# 19 — 모국어 음성으로 배운 언어식별이 외국인의 한국어에서 모국어를 맞히나 (2026-10-01)

**결론: 못 맞힌다.** 모국어 발화로 학습된 언어식별 모델(Whisper large-v3-turbo)에 외국인의 한국어 녹음을 넣으면 결과가 이렇다.

- 87% 를 "한국어"로 정확히 알아본다.
- 한국어를 뺀 나머지 언어 중 화자의 모국어 순위를 보면 언어 평균 top-1 이 **0.05** 다. 2순위로는 거의 항상 "영어"를 낸다.
- 외국인 한국어로 학습한 우리 모델(run_zeroth)은 같은 녹음에서 모국어 top-1 **0.86**, top-5 0.97 이다.

국적·모국어 분류에는 "외국인이 한국어를 말한 녹음"이 필요하다. 모국어 데이터로는 대신할 수 없다.

## 설정

- **데이터.** `test_koraug_zeroth` 의 웹마이크 문장 11,519개(시험 화자, 학습에 없던 사람)를 썼다. 정답은 AIHub 화자 메타의 모국어(26개 언어)다.
- **모델.** Whisper large-v3-turbo(MIT)를 썼다. 다국어 음성 수백만 시간으로 학습했고 99개 언어를 식별한다. 첫 디코더 스텝의 언어 토큰 확률을 썼다.
- **채점.** 한국어(ko)를 뺀 99개 언어 안에서 모국어의 순위를 봤다.
- **비교 모델.** run_zeroth 의 예측 국가를 그 국가의 다수 모국어로 바꿔서 비교했다.

## 결과

| | 모국어 top-1 (언어 평균) | 모국어 top-1 (발화 전체) | 모국어 top-5 (언어 평균) |
|---|---|---|---|
| Whisper (모국어 발화로 학습) | 0.05 | 0.25 | 0.21 |
| run_zeroth (외국인 한국어로 학습) | — | **0.86** | 0.97 (발화 전체) |

- **Whisper 의 발화 전체 0.25 는 영어 화자 덕분이다.** Whisper 는 한국어 다음 순위로 거의 언제나 영어를 낸다. 인도네시아·베트남·중국 화자도 75~94% 가 "영어"로 나왔다. 그래서 영어 화자만 0.76 이 나온다.
- **나머지 언어는 거의 0 이다.** 언어별 top-1 은 인니어 0.10, 일본어 0.13, 베트남어 0.05, 중국어 0.03, 러시아어 0.01 이고, 몽골어·태국어·네팔어·독일어·이탈리아어는 0 이다.
- **중국어·일본어 top-5(0.99·1.00)는 신호가 아니다.** Whisper 가 모든 입력에 대해 en·ja·zh 를 늘 상위에 두기 때문에 생긴 착시다.

## 해석

- 언어식별 모델은 "무슨 언어를 말하나"를 배운다. 억양은 모국어 습관이 한국어에 섞여 나타나는 미세한 차이라, 모국어 발화만으로는 학습되지 않는다.
- 모국어 데이터의 이점은 이미 쓰고 있다. 현재 인코더 XLS-R 이 128개 언어 43.6만 시간으로 사전학습된 모델이다.
- 범용 억양 모델(어느 언어를 말하든 국적 판별)을 만들려면 여러 목표 언어의 외국인 발화가 필요하다. 예를 들어 외국인 영어 + 외국인 한국어다.
