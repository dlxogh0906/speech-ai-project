# 32 — 음성 변환(VC) 점검: 목소리만 바꿔도 국가를 맞히나 (2026-10-21)

꼬리 국가 증강을 TTS 대신 VC 로 할 수 있는지 학습 전에 점검했다. VC 는 실제 녹음의 발음 · 억양은 두고 목소리(음색)만 바꾼다.
판정 모델은 300m 전체학습(`full_300m/best.pt`)이고, 데이터 · 시험 방식은 27 과 같다.

**결론: 근거는 반만 섰다. VC 증강 학습은 해 볼 수는 있지만 기대 이득이 작다.**

(뒤이은 학습 결과: `33_음성변환_증강_교차검증.md` — 꼬리는 오르지 않았다.)

- **모델은 꼬리 국가 화자의 목소리를 외웠다.**
  - 학습한 꼬리 국가 화자(97명)의 발화는 원래 top-1 이 0.979 다. 목소리만 바꾸면 0.144 ~ 0.149 로 무너진다.
  - 같은 변환에서 학습한 머리 국가 화자는 0.947 → 0.515 ~ 0.539 로, 절반 넘게 남는다.
  - 변환기 자체의 손실(자기 목소리로 되돌리기)을 빼고 봐도, 다른 목소리로 바꿀 때 꼬리는 −0.52, 머리는 −0.26 ~ −0.29 떨어진다.
  - 발음을 건드리지 않는 음높이 ±3반음에서도 꼬리 −0.48, 머리 −0.22 로 같은 경향이다.
- **하지만 변환이 억양 단서도 상당히 지운다.**
  - 처음 듣는 머리 국가 valid 화자도 목소리를 바꾸면 top-1 이 0.748 → 0.386 ~ 0.390, top-5 가 0.976 → 0.729 ~ 0.795 로 떨어진다.
  - 자기 목소리로 되돌리기만 해도 top-1 0.619 다. 변환기를 거치는 것만으로 −0.13 이다.
  - 이 점검만으로는 "모델이 처음 듣는 화자에게도 목소리 특성을 쓴다"와 "변환이 발음 · 억양을 바꾼다"를 가를 수 없다. 둘 다일 가능성이 높다.
- **그래서:**
  - 꼬리 국가에서 목소리 암기가 일어난다는 것은 확인됐다. VC 로 목소리를 섞어 학습할 근거는 있다.
  - 다만 변환된 소리에 남는 억양 단서가 원래의 절반 정도라, 그 위에서 배운 것이 실제 새 화자에게 옮겨 갈지는 불확실하다.
  - 하려면 41클래스 모두 같은 비율로 변환해야 한다. 꼬리만 변환하면 결과 20 처럼 "변환된 소리 = 꼬리"라는 지름길이 생긴다.
  - 꼬리 test 9명으로는 작은 개선을 잴 수 없으니, 꼬리 화자 교차검증과 함께 해야 한다(결과 31 §5).

- **한국으로 판정되는 비율**은 거의 그대로다. 한국인 목소리로 바꿔도 머리 valid 4.3% · 중간 train 3.1% 뿐이다.
  - 한국인 목소리를 입혀도 한국인 발음이 되지는 않는다는 뜻이다. 억양 단서의 일부는 남는다.
- **녹음 묶음별로 보면** 꼬리 학습 화자 가운데 웹 녹음(122발화)이 131 녹음(72발화)보다 더 무너진다.
  - TTS 목소리로 바꿨을 때 top-1 이 웹 0.057, 131 0.292 다.
  - 웹마이크 녹음은 화자마다 마이크 · 방이 달라서 모델이 목소리와 녹음 환경을 함께 외운 것으로 본다(`vc_gate_report.md` 의 web · 131 행).

## 3. 해석

- **목소리 암기:** 학습한 화자는 모델이 이미 맞히는 발화다. 그런데도 목소리만 바꾸면 꼬리는 원래의 15% 만 맞히고, 머리는 55% 를 맞힌다.
  - 머리 국가는 화자가 많아 억양 같은 일반적인 단서로 맞히고, 꼬리 국가는 몇 안 되는 화자의 목소리로 맞힌다는 뜻이다.
  - test 의 꼬리 국가가 무작위 수준(top-5 0.089)인 것과도 맞는다. 처음 듣는 꼬리 화자에게는 외운 목소리가 없다.
- **억양 손실:** 처음 듣는 머리 국가 화자에서 다른 목소리 변환은 top-1 을 절반으로 줄인다.
  - 음높이 ±3반음은 발음을 전혀 바꾸지 않는데도 −0.22 다. 모델이 목소리 특성(포먼트 · 음높이)에 꽤 기대고 있다.
  - 그러니 변환된 소리로 학습하면, 모델이 목소리 대신 억양을 쓰도록 바뀔 여지는 있다.
  - 반대로 변환된 소리에는 억양 단서가 덜 남아 있어서, 배울 것 자체가 줄어든다.
- **기대치:** 꼬리 국가의 억양 정보는 여전히 5~15명분이다. VC 는 목소리를 외우는 지름길을 막을 뿐, 새 억양을 만들지 않는다.

## 4. 다음에 한다면

> **2026-10-21 저녁에 아래 1~3 을 했다 → `33_음성변환_증강_교차검증.md`.** 비율은 30% 대신 50% 로 했다.
> 꼬리는 같은 오경보율에서 오르지 않았고, 중간은 조짐만 있으며(test 확실 · valid 0 포함), 웹 전체 · 단어는 떨어졌다.

1. **모든 클래스를 같은 비율로 변환해 섞는다.** 예: 학습 행의 30% 를 다른 목소리로 바꾼 사본으로 바꾼다.
2. **LoRA 이어(300m 전체학습에서)로 학습한다.** 기존 실험과 같은 설정이다. 변환 2.5만 발화와 학습을 합쳐 반나절쯤 걸린다.
3. **꼬리 화자 교차검증으로 잰다.** 꼬리 국가 화자(train 99 · valid 8 · test 9명)를 몇 묶음으로 돌려가며 시험한다.
   - 같은 오경보율로 비교한다.
   - 이 점검의 "학습한 꼬리 화자를 목소리만 바꿔 맞히는 비율"도 함께 본다. 목소리 대신 억양을 쓰게 됐는지 보여 준다.
