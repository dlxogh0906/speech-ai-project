# 26 — 다운샘플링(클래스당 상한) 실험 정리 · XLS-R (2026-10-18 정리 · 10-21 D 추가)

**결론: 다운샘플링으로 나아진 적은 한 번도 없다.** 큰 클래스를 클래스당 N행까지만 남길수록 성능이 떨어졌고,
상한을 올리면(덜 버리면) 올랐다. 2026-10-21 에 인코더 전체 학습으로 클래스 비율만 바꿔 깔끔하게 다시 재도 같았다(§7).
작은 국가의 겉보기 상승은 그 국가를 더 자주 찍은 몫이었고, 같은 오경보율에서는 꼬리가 오히려 낮았다. 데이터를 버리지 않는 균형화(균등·가중 샘플링, 손실 재가중)도 소수 클래스를 살리지 못했다.
병목은 행 수가 아니라 **소수 클래스의 학습 화자 수**다. 자르면 큰 클래스의 화자 다양성만 줄고, 작은 클래스에 새 화자는 생기지 않는다.

- 다운샘플링 = 학습 데이터에서 클래스마다 최대 N행(`cap`)만 무작위로 남기고 나머지를 버린다. 적은 클래스는 그대로 둔다.
- 모든 수치는 **화자 분리 시험셋**(학습에 없던 화자) 기준이다. 실험마다 클래스 수와 지표가 다르니 표 머리를 확인할 것.

## 5. 데이터를 버리지 않는 균형화 — 비교용

같은 불균형에 대해 데이터를 버리지 않고 뽑는 빈도나 손실만 바꾼 처방들이다.

| 처방 | 설정 | 결과 | 출처 |
|---|---|---|---|
| 클래스 균등 샘플링 | 2B 동결 · 61클래스 | micro top-5 0.931 → 0.902, macro top-5 0.498 → 0.484 | `docs/EXPERIMENTS.md` E3 |
| 가중 샘플링 (추출 확률 ∝ 1/n^β) | 2B 동결 · 62클래스 | β 0.5 ~ 0.75: 외국어 top-5 0.919 → 0.921, 중간 구간 F1 0.163 → 0.174. 대신 top-1 0.755 → 0.734 ~ 0.745. β=1(완전 균등)은 top-1 · top-5 모두 기준보다 낮음 | `docs/notion_weighted_sampling.md` |
| 손실 재가중 · 오버샘플 · logit adjustment | 2B 동결 · 61클래스 | macro-F1 0.197 → 0.183 / 0.154 / 0.124 | `01_실험별_성능.json` `불균형처리_비교` |

동결 실험에서 전체 top-5 를 올린 건 가중 샘플링 β 0.5 ~ 0.75 뿐이었고(+0.2%p 남짓), 그때도 학습 화자 3명 이하 클래스의

다수 클래스의 정확도를 소수 클래스 쪽으로 옮긴 교환이다.

- 줄이는 법(`scripts/data/make_capped_manifest.py`): 클래스 목표 = min(행 수, 상한). 클래스 안 출처 비율은 그대로 두고,

- 한국 클래스는 63,466 → 10,000 → 2,000 → 1,008 행으로 줄었다. 화자 420명은 모두 남았다.
- 평가: 학습 화자 수 구간(꼬리 ≤15 · 중간 16~100 · 머리 >100)을 나눠 보고, 화자 부트스트랩 95% 구간을 냈다. 시드는 1개라 학습 무작위성은 구간에 들어가지 않는다.
  작은 국가의 점수는 그 국가를 얼마나 자주 찍느냐에 따라 움직이므로, **같은 오경보율**에서도 견줬다(`29_꼬리_오버샘플링_증강_손실.md` §2.2 와 같은 방법).

**결론: 깔끔하게 다시 재도 다운샘플링으로 나아진 것은 없다.**

- **전체 · 머리 · 단어 — 상한을 낮출수록 단조로 떨어진다.**
  - 상한 없음 → 1만 → 2천 → 1,008 순서로, 웹 전체 top-5 는 0.894 → 0.878 → 0.866 → 0.843, top-1 은 0.651 → 0.623 → 0.591 → 0.549 다.
  - 머리 국가 top-5 는 0.954 → 0.948 → 0.929 → 0.909, 웹 단어 top-5 는 0.718 → 0.676 → 0.670 → 0.640 이다.
- **꼬리 (학습 화자 ≤15) — 같은 오경보율에서는 오히려 낮다.**
  - 겉보기 꼬리 top-5 는 0.089 → 0.036 → 0.125 → 0.135 다. 꼬리 오경보가 7.8% → 12.0% → 23.8% → 31.0% 로 함께 늘었다.
  - 오경보를 20% 로 맞추면 0.151 → 0.078 → 0.094 → 0.089 다. 대조군 대비 −0.057 ~ −0.073 이고, 1만 · 2천은 구간이 0 아래다.
- **중간 (16~100) — 겉보기 상승은 거의 다 더 자주 찍은 몫이다.**
  - 겉보기 중간 top-5 는 0.590 → 0.654 → 0.701 → 0.738 이다.
  - 같은 오경보율(50%)에서는 +0.003 · +0.040 · +0.021 이다. 구간이 모두 0 을 포함한다.
- **한국어 원어민을 외국인으로 찍기 시작한다.** 한국 클래스의 행이 같이 잘리기 때문으로 본다.
  - Zeroth 원어민 낭독 오판이 457발화 중 2 → 9 · 6 · 10개다. Kspon 은 670발화 중 0 → 4 · 8 · 11개다.
- **버리지 않고 마지막에만 균형을 맞추면 손해가 작다 — LoRA 이어 · 행 균등 1,008 (`28_학습안함_LoRA_행균등.md`).**
  - 300m 전체학습에서 출발해, 같은 1,008 목록으로 LoRA 만 2 epoch 학습한 모델이다.
  - 웹 전체 top-5 는 −0.009 만 잃는다. 한국어 원어민도 그대로다(Zeroth 오판 3개).
  - 같은 오경보율에서 중간이 +0.027 [+0.001, +0.059] · +0.039 [+0.009, +0.074] 높다. 꼬리는 −0.026 ~ +0.021 로 그대로다.
  - **단 이 중간 몫은 행 균등 덕이 아니다.** 같은 LoRA 를 전체 목록(자연 분포)으로 250스텝만 이어도 같은 오경보율에서 +0.026 · +0.046 이다(`29_꼬리_오버샘플링_증강_손실.md` §5.7).

### 7.5 해석

- **큰 클래스를 자르면 그 나라의 발화 다양성만 준다.** 작은 클래스에는 아무것도 더해지지 않는다(§6).
  그래서 작은 국가를 더 자주 찍는 효과만 남고, 가려내는 힘은 늘지 않았다.
- **꼬리는 같은 오경보율에서 오히려 낮다.** 버린 행만큼 표현이 약해진 것으로 본다. 비꼬리 top-1 도 같이 떨어진다(오경보 20% 에서 0.782 → 0.756 → 0.713 → 0.663).
- **valid 기준만 보면 다운샘플링이 나아 보인다.** 1만 · 2천의 valid 기준(웹 top-5 + 국가 평균 top-5)이 대조군보다 높다(1.613 · 1.614 vs 1.600).
  국가 평균이 비율 몫으로 오르기 때문이다. test 의 같은 오경보율 비교가 필요한 이유다.
- **작은 국가를 더 자주 보여 주는 것이 목적이라면** 학습을 바꿀 필요가 없다. 대조군의 작은 국가 로짓에 상수를 더하면 된다(`29_꼬리_오버샘플링_증강_손실.md` §3.1).
- 결론은 A · B · C 와 같다. 병목은 행 수가 아니라 작은 클래스의 학습 화자 수다.
