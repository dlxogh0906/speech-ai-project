# 46 — 9월 2B 동결 + 0704 헤드를 지금 test 로 다시 재기 (2026-10-31)

질문(사용자): 모델 비교 데모에서 한국인 녹음을 "한국 1.00" 으로 맞힌 모델이 "전체적인 클래스 별 성능 어떻게 되는지".
계기: 10-31 데모 녹음 1건(한국인, 3.4초, 문장 1개)에서 60개 모델 중 한국 1위가 16개였다. 서비스 구성과 9월 모델이 한국으로 봤고 10월 모델 41개는 하나도 한국으로 보지 않았다. 그중 데모의 "2B 동결 + 선형 헤드 (9월 보고용)" 가 한국 1.000 이었다.
이번에 한 것: 그 모델(2B 동결 31층 + `0704` 헤드)을 다른 모델들과 같은 화자 8:1:1 test 로 채점하고, 최종 점검(10-26)과 같은 도구로 클래스별 표를 만들었다.

**결론: 한국인을 잘 알아들어서 1.00 이 나온 것이 아니다. 웹마이크 녹음을 거의 못 맞히고, 외국인도 자주 한국으로 부른다.**

- **웹마이크 문장(앱 입력과 같은 종류): top-1 0.202 [0.181, 0.223] · top-5 0.323 [0.298, 0.349].**
  - 앱 주 모델 run_zeroth 는 0.776 / 0.959, 300m 전체학습은 0.777 / 0.957 이다.
  - 화자의 문장을 3개 합쳐도 0.219 / 0.303 이다. 짧은 녹음 탓이 아니다.
- **외국인을 한국으로 부른 비율이 7.2% 다.** 웹 문장 4.4%, 웹 단어 17.8% 다. run_zeroth 는 0.26%, 300m 전체학습은 0.01% 다.
  - 필리핀의 9%, 몽골의 17%, 태국의 12% 가 한국으로 갔다.
  - 그러니 한국인 녹음에 한국이 나온 것은, 웹마이크 녹음을 한국 쪽으로 미는 버릇과 구분되지 않는다.
- **한국인 코퍼스 test 도 더 낮다.** Kspon 0.939 · 한국어 채널 증강 0.934 · Zeroth 낭독 0.807 이다. 나머지 두 모델은 모두 0.99 이상이다.
- **원인은 학습 데이터다.**
  - `0704` 헤드는 131 읽기 · 041 유럽 문장 · 043 아시아 일부 · 한국어로 학습했다(결과 07). 040 · 042 웹마이크는 본 적이 없다.
  - 본 데이터인 041 웹은 0.591 / 0.889 로 300m 전체학습(0.637 / 0.880)과 비슷하다. 안 본 040 · 042 는 top-1 0.026 · 0.024 다.
  - 그래서 머리 국가 중 필리핀 · 인도네시아 · 미국 · 베트남 · 중국 · 일본 · 몽골 · 영국 · 싱가포르가 top-1 0.06 이하로 무너진다.
- **누수 주의 — 이 모델에 유리한 쪽이다.**
  - `0704` 헤드는 화자 8:1:1 분할 전 목록으로 학습했다. 그래서 지금 test 의 131 · 041 · 043 화자 일부를 봤을 수 있다.
  - 131 읽기(0.828 / 0.967) · 041 · 시험 화자 1~2명뿐인 꼬리 국가(이란 0.833 · 타지키스탄 0.917 · 캄보디아 0.583)의 높은 값은 그 때문일 수 있다.
  - 그래도 웹 전체가 0.20 이라 결론은 바뀌지 않는다. run_zeroth 도 분할 전 목록으로 학습해 누수 의심이다(결과 24).
- **데모 이름 정정.** 데모의 "2B 동결 + 선형 헤드 (9월 보고용)" 은 CLAUDE.md 보고 수치(0.798 / 0.950)의 `0702` 헤드가 아니다. 거기에 043 아시아를 더한 `0704` 헤드다. 옛 test 로는 0.784 / 0.941 이다(결과 07).

**정리:** 한국인 사용자를 한국으로 판정하면서 다른 나라도 맞히는 것은 앱 구성(run_zeroth + 원어민 게이트)이다. `0704` 는 후보가 아니다.

## 4. 재현

임시 체크포인트(2B 인코더 + 0704 헤드)를 `/dev/shm` 에 만들고 평가한 뒤 지웠다. 5.8 GB 라 `/data` 에 두지 않는다.

```bash
source tools/env.sh
# 1) 임시 체크포인트 — frozen_lp_2b 의 인코더(사전학습 그대로)에 0704 헤드를 얹는다
$PY - <<'EOF'
import sys, torch; sys.path[:0] = [".", "tasks/nationality-classification/src"]
from country_classifier.model_zoo import _xb
ck = torch.load("$NATIONALITY_OUTPUTS/webmic_kd/full_encoder_spk811/frozen_lp_2b/best.pt", map_location="cpu")  # 경로는 펼쳐 쓴다
W, b, mu, sd = _xb().head_from_0704([str(x) for x in ck["labels"]])
ck.update(head={"weight": torch.from_numpy(W), "bias": torch.from_numpy(b)}, mu=mu, sd=sd)
torch.save({k: ck[k] for k in ("encoder", "layer", "xlsr", "backbone", "labels", "head", "mu", "sd")}, "/dev/shm/report2b_0704/ckpt.pt")
EOF
# 2) test 채점 (데모와 같이 돌릴 때는 --gpu_mem_frac 로 상한 — 이번엔 0.3, 약 20분)
$PY tasks/nationality-classification/scripts/train/finetune_full_encoder.py --eval_only --ckpt /dev/shm/report2b_0704/ckpt.pt \
```
