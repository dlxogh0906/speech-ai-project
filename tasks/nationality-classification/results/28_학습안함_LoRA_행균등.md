# 28 — 학습 안 한 모델 · LoRA 행 균등 (2026-10-20)

`27_전체미세조정_300m_2B_불균형.md` 에 이어지는 실험이다. 데이터 · 시험지 · 평가 방법은 27 과 같다.

**결론: 행 균등 목록으로 LoRA 만 살짝 더 학습하면, 큰 국가를 거의 잃지 않고 중간 국가를 크게 올린다. 꼬리는 그대로다.**

- **LoRA · 행 균등 · 300m 에서 이어**가 300m 변형 중 가장 좋은 교환이다.
  - 방법: 300m 전체학습(27 의 대조군)에서 출발해, 클래스당 1,008행 목록으로 LoRA(2.65M)와 헤드만 1,000스텝 학습했다.
  - 대조군 대비 중간 국가 top-5 +0.124, 국가 평균 +0.032 다.
  - 잃은 것은 웹 전체 −0.009, 머리 −0.006 뿐이다.
  - 같은 목록으로 인코더 전체를 학습했을 때(행 균등 · 전체학습)는 머리 −0.044, 웹 전체 −0.050 이었다.
  - 사후 로짓 보정과 견주면 중간 국가는 +0.060 높고, 국가 평균은 같다.
- **LoRA · 행 균등 · 사전학습에서**는 2 epoch 으로는 크게 모자라다. 웹 top-5 0.730 으로, 학습 안 함(0.640)과 전체학습(0.894) 사이다. valid 가 끝까지 오르고 있었다.
- **학습 안 한 모델**은 웹 top-5 300m 0.640 · 2B 0.652 다. 사전학습 XLS-R 고정에 선형 헤드만 붙인 모델이다.
  - 인코더 전체학습이 +0.25 를 더한다(0.894).
  - 2B 와 300m 의 차이는 학습 전에도 작고(+0.012), 학습 뒤에는 없다.
- **꼬리(학습 화자 ≤15)는 어떤 방법으로도 그대로다.** 이번 실험들도 0.03 ~ 0.09 다. 27 의 결론(병목은 화자 수)과 같다.

> **2026-10-21 덧붙임 — 중간 +0.124 의 대부분은 중간 국가를 더 자주 찍은 몫이다.**
> 다른 나라 발화의 top-5 에 중간 국가가 끼는 비율(오경보)이 47% → 62% 로 늘었다. 오경보율을 같게 맞추면 이득은 +0.03 ~ +0.04 로 준다(`29_꼬리_오버샘플링_증강_손실.md` §2.2).
> 남은 +0.03 ~ +0.04 도 행 균등 덕이 아니다. 같은 LoRA 를 전체 목록(자연 분포)으로 250스텝만 이어도 같은 만큼 나온다(29 §5.7).
> 행 균등이 더하는 것은 작은 국가를 더 자주 보여 주는 쪽으로의 이동이고, 이는 사후 로짓 보정으로도 얻는다. "웹 전체를 거의 잃지 않는 교환"이라는 점은 그대로다.

> **2026-10-22 덧붙임 — 한국인 원어민 발화는 학습 안 한 모델도 발화 0.87 ~ 0.95 · 화자 100% 를 Korea 로 부른다(§7).**
> 단, 학습과 같은 코퍼스 안의 시험이라 억양을 알아들었다는 증거는 아니다.

수치를 읽는 법:

- **시험지:** test 한 장(`test_koraug_zeroth.csv`, 19,680발화 · 1,390명)이다. 학습 · 선택 · 보정값 결정에는 쓰지 않았다(모두 valid).
- **평가:** 모든 모델을 같은 bf16 · 240초 배치로 쟀다.
- **신뢰구간:** 95% 구간은 화자 부트스트랩 1,000회다. 시드는 모델마다 1개다.

## 3. 해석

### 3.1 학습 안 한 모델

- **전체학습이 대부분을 만든다.** 300m 기준으로 학습 안 함 → 전체학습 차이는 다음과 같다.
  - 웹 전체 top-5 +0.254 [+0.242, +0.267], top-1 0.340 → 0.651
  - 단어 +0.387, 웹 문장 국가 평균 +0.181, 131 +0.111
- **크기 차이는 학습 전에도 작다.** 학습 안 한 2B − 300m 은 웹 전체 top-5 +0.012, 131 국가 평균 +0.049 다. 전체학습 뒤에는 웹 전체 −0.005 로 사라진다(27 §5.2).
- **꼬리는 학습 전에도 거의 0 이다(0.016 · 0.031).** 무작위 5개 찍기(≈0.12)보다 낮다.
  - 헤드는 클래스별 같은 수로 맞췄고, 그 행은 거의 다 맞힌다(학습 정확도 0.93 · 1.00).
  - 그런데도 새 화자에게는 통하지 않는다. 화자 5~15명으로는 국적이 아니라 그 사람들을 외운다.
- **한국어는 학습 전에도 높다.** Kspon top-5 0.973 · 0.985, 한국어 증강 0.993 · 0.996 이다. 전체학습 뒤 1.000 이다.

### 3.2 LoRA · 행 균등

- **이어 학습이 통하는 이유:** 전체 데이터(화자 11,054명)로 배운 표현은 그대로 두고, 클래스 비율만 고르게 다시 맞춘다.
  - 행 균등 · 전체학습은 인코더 2.4억 개를 4만 행에 맞췄다. 그러다 큰 국가를 크게 잃었다(머리 top-1 −0.104).
  - LoRA 는 바꿀 수 있는 양이 1% 남짓이고, 학습도 1,000스텝뿐이다. 그래서 잃은 것이 작다.
- **사후 로짓 보정과의 차이:**
  - 사후 보정은 모든 국가의 점수를 학습 비율만큼 일정하게 옮긴다.
  - LoRA 는 표현까지 조금 바꾼다. 그래서 중간 국가에서 더 얻었다(+0.060). 예: 말레이시아 0.50 → 0.72, 홍콩 0.86 → 0.92.
  - 대신 꼬리는 사후 보정만큼 오르지 않았다(−0.047, 구간 경계).
  - 국가 평균은 같다(+0.005, 0 포함). 재학습이 필요 없는 사후 보정이 여전히 가장 싸다.
- **사전학습에서 시작한 LoRA 는 이 예산으로는 비교가 안 된다.** 4만 행 · 2 epoch · 2.65M 파라미터로는 사전학습 표현을 국적 쪽으로 충분히 옮기지 못한다(웹 top-5 0.730).
  - 그래도 학습 안 함(0.640)보다는 +0.09 높고, valid 는 계속 오르고 있었다.
  - 얼마나 더 오를지는 더 길게 돌려 봐야 안다.
- **꼬리는 그대로다.** LoRA 이어 0.089 로 대조군과 같다. 클래스 비율 보정은 화자가 어느 정도 있는 중간 국가까지만 통한다.

## 4. 주의

- **시드 1개 · 단일 시험지다.** 0.01 안팎의 차이는 다시 돌리면 뒤집힐 수 있다.
- **학습 안 한 모델의 헤드는 2만 행으로만 맞췄다(클래스당 약 487행).** 71만 행 전부로 맞추면 조금 더 오를 수 있다.
- **보고용 "2B 동결 + 헤드"(top-5 0.950)와는 비교할 수 없다.** 분할 · 헤드 · 시험지가 다르다.
- **LoRA 설정은 한 번씩만 돌렸다.** rank 8, 학습률 1e-4 · 3e-4, 2 epoch 이다. 학습률이나 rank 를 고르는 비교는 하지 않았다.
- **LoRA 사전학습 실험의 출발점은 "300m 학습 안 함"과 조금 다르다.** 선형 헤드를 행 균등 목록에서 뽑은 2만 행으로 맞췄다(valid 1.1843 vs 1.1487).
- **부트스트랩 구간은 같이 비교한 모델 묶음에 따라 조금 달라진다.**
  - `compare_logits_bootstrap.py` 는 난수 하나를 비교 순서대로 이어 쓴다.
  - 그래서 같은 두 모델의 구간도 문서마다 ±0.005 쯤 다를 수 있다.

## 7. 덧붙임 (2026-10-22) — 한국인 원어민 발화를 넣으면

질문: 학습 안 한 베이스 XLS-R 에 한국인이 말한 한국어를 넣으면 무엇이 나오나.

- **베이스 XLS-R 만으로는 국가가 나오지 않는다.** 출력층이 없는 인코더라, 20 ms 마다 층별 벡터(300m 1,024차원 · 2B 1,920차원)만 나온다.
  - 국가 이름이 나오는 가장 작은 단계가 이 문서의 "학습 안 함"이다. 인코더는 사전학습 그대로 두고 선형 헤드만 학습했다.
- 아래는 이미 있는 test 로짓에서 Korea 행만 다시 센 것이다. 새로 학습하거나 추론하지 않았다.

| 한국인 원어민 test | 발화 (화자) | 300m 학습 안 함 | 2B 학습 안 함 | 300m 전체학습 | 2B 전체학습 |
|---|--:|--:|--:|--:|--:|
| Zeroth 낭독 | 457 (10) | 0.888 | 0.867 | 0.996 | 0.985 |
| Kspon 대화 | 670 (67) | 0.881 | 0.891 | 1.000 | 1.000 |
| Kspon + 채널 증강 | 1,360 (68) | 0.951 | 0.954 | 0.999 | 0.996 |
| 화자 단위 (세 묶음 모두) | | 1.000 | 1.000 | 1.000 | 1.000 |

- 값은 Korea 가 1위인 비율이다. 화자 단위는 같은 화자 발화의 확률을 평균해 1위를 본 것이다.

- **틀린 원어민 발화는 주로 영어권으로 간다.** 300m 학습 안 함의 Zeroth 오답 51개 중 싱가포르 17 · 영국 12 · 미국 11 이다. 2B 학습 안 함은 카자흐스탄 14 · 싱가포르 10 · 미국 9 다.
- **원어민 구분은 국가 구분보다 훨씬 쉽다.** 학습 안 함에서 원어민은 발화 0.87 ~ 0.95 를 맞히지만, 외국인의 국가는 웹 top-1 0.34 ~ 0.36 이다. 전체학습이 원어민 쪽 남은 +0.04 ~ +0.12 를 채운다.

**이 숫자를 "억양을 알아들었다"는 증거로 쓰면 안 된다.**

- Korea 클래스는 학습 · 시험 모두 원어민 전용 코퍼스(Zeroth · Kspon · Kspon 채널 증강)다. 외국인은 전부 AIHub 웹마이크 · 505 다.
