## 1. 집계 범위와 단위

- 기준은 배포 정보의 `run_zeroth/ep0.pt (EMA)`와 연결된 `lab131full_zeroth`입니다. 마지막 단계는 `run4/ep0.pt`에서 이어 학습했으므로, 이 문서의 숫자는 이전 초기 모델·교사 모델까지 합친 누적 고유 데이터 수가 아닙니다. 별도 게이트, YouTube·LoRA 추가 실험도 합산하지 않았습니다. 서비스 모델 식별 근거는 10/14 검증 기록과 보존된 배포 정보입니다.
- **샘플 1개 = 학습 CSV 1행의 음성 녹음 파일 1개**입니다. 세 국가에는 중복 경로와 별도 증강 행이 없어 학습 행 수와 고유 녹음 수가 같습니다.
- **화자 수 = 데이터셋 구분자가 포함된 고유 화자키 수**입니다. 로더의 `speaker_id`는 행 번호이므로 사람 수로 세지 않았습니다. 서로 다른 데이터셋에 같은 사람이 다른 ID로 등장하는 경우까지 확인한 실제 인원 수는 아닙니다.
- **문장 길이 = 전체 녹음 라벨의 공백 기준 어절 수**입니다. 낭독 제시문과 실제 발화 전사를 따로 계산하며, 문법적 문장 수·형태소 수·LLM 토큰 수가 아닙니다. 한 녹음에 여러 문장이 들어갈 수 있습니다. 전사·제시문은 이 문서의 통계 작성에 사용했고, 국적분류 모델의 직접 입력은 음성입니다.
- 학습 목록의 경로·라벨·순서·길이를 실제 학습 로더와 다시 대조했습니다. 원본 음성 일부는 10/11 정리 이후 삭제된 상태이므로 음성 길이는 보존된 매니페스트 값을 사용했습니다. 과거 학습량과 현재 보유 음성량은 다릅니다. 원문 누락을 0어절로 채우지 않았습니다.

- **원본 길이와 실제 입력 길이를 구분해야 합니다.** 학습 입력은 음성 앞 최대 8초이며, 원본 전사 전체의 어절 수는 그 구간의 어절 수와 일치한다고 볼 수 없습니다.
- **국가 라벨은 순수한 단일 모국어 집단이 아닙니다.** 특히 필리핀의 영어, 우즈베키스탄의 러시아어 비중을 함께 봐야 합니다. 이 분포만으로 오분류의 인과 원인을 확정하지는 않습니다.
- 실제 로더의 학습·검증 목록과 매니페스트 **행 수·입력 순서·경로·라벨·길이 일치**, 기존 통계의 클래스별 행 수·화자 수·과제 합계·문장 길이 구간 합계 일치를 확인했습니다. 세 국가의 분할 간 화자키 중복은 0개입니다.
