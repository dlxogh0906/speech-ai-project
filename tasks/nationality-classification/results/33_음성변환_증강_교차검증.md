### 1.3 꼬리 화자 교차검증

- **시험 화자:** 꼬리 12개국 가운데 웹 문장이 있는 11개국 78명이다(train 61 · valid 8 · test 9). 르완다는 웹 문장이 없다.
- **묶음:** 국가마다 화자를 섞어 4묶음에 돌려 담았다. 묶음당 19~20명이다.
- **묶음 목록:** 행 균등 1,008 목록에서 그 묶음 화자의 행을 뺐다. 그리고 같은 국가의 남은 화자의 안 쓴 행으로 1,008행까지 채웠다.
  - 방글라데시는 남은 행이 모자라 822 · 823행이다.
- **사전학습에서 LoRA 로 학습했다.**
  - 300m 전체학습은 꼬리 train 화자를 이미 학습했고, 그 목소리를 외웠다(결과 32). 거기서 이어 학습하면 빼 둔 화자를 이미 본 모델이 된다.
  - 설정: LoRA r8 · lr 3e-4 · 헤드 1e-3 · 2 epoch · EMA 0.99. valid 로 고르지 않고 학습 끝 EMA 를 쓴다.
  - 대조군(ctrl)과 VC 50%(vc50)는 같은 목록 · 같은 seed 다. 묶음 4개 × 2 = 모델 8개다.
  - 대신 묶음 모델이 약하다. 표준 test 웹 문장 top-1 0.48 · top-5 0.81 이다(300m 전체학습은 0.777 · 0.957).
- **시험 발화:** 빼 둔 화자의 웹 문장이다. train 화자는 무작위 12개, valid · test 화자는 전부 넣었다. 모두 888발화다.
- **오경보 맞추기:** 묶음 모델마다 표준 test 의 꼬리 밖 웹 문장(11,411발화)으로 b 를 따로 맞췄다.
- **집계:** 4묶음의 발화를 합쳐 국가 평균 top-5 를 낸다. 구간은 꼬리 화자 78명을 부트스트랩 1000회 뽑아서 낸다.

## 6. 해석

- **꼬리:** 결과 32 의 예상대로다.
  - VC 는 꼬리 화자의 목소리를 외우는 지름길을 줄였다. 학습 화자를 다른 목소리로 바꿔도 0.23 → 0.77 로 맞힌다.
  - 그러나 처음 듣는 꼬리 화자는 여전히 못 맞힌다. 꼬리 국가의 억양 정보가 5~15명분뿐인 것은 그대로다.
- **중간:** 학습 화자가 16~100명이면 억양 정보가 어느 정도 있다. 목소리 지름길을 막자 그 정보를 더 쓰게 됐을 수 있다.
  - test 에선 확실했고(+0.057 ~ +0.070), valid 에선 절반 크기로 0 을 포함했다(+0.023 ~ +0.032).
  - 시드 1개 · 사후 추가 비교라 확정하지 않는다.
- **전체 · 단어 손실:**
  - 300m 전체학습은 목소리 · 녹음 환경 특성을 국적 단서로 꽤 쓴다(결과 32: 음높이 ±3반음만으로 머리 valid top-1 −0.22).
  - VC 사본이 그 단서를 절반의 행에서 지우면서 머리 국가와 단어 판정이 떨어졌다.
  - 단어는 1초 안팎이라 억양 단서가 적고 목소리 단서 비중이 컸던 것으로 본다. 짧은 클립은 변환 품질도 나쁠 수 있다. 확인하지 않았다.
- **체크포인트 선택:** VC 쪽 valid 기준은 step 250 에 정점을 찍고 내려갔다. 고른 모델은 꼬리 오경보가 35% 로, 꼬리를 많이 찍는 초반 모델이다.
  - 같은 오경보율로 보면 학습 끝 EMA 가 더 낫다(중간 test +0.070 vs +0.014).
  - valid 기준(웹 top-5 + 국가 평균 top-5)이 오경보를 늘리는 모델을 고른다는 결과 29 의 관찰과 같다.

## 7. 다음에 한다면

1. **단어 과제는 변환하지 않고 비율을 낮춘다(예: 문장 · 자유발화의 25%).** 단어 · 머리 손실을 줄이면서 중간 이득이 남는지 본다.
2. **시드 2~3개로 다시 돌린다.** 중간 +0.03 ~ +0.07 이 시드 잡음이 아닌지 보려면 필요하다. 1회에 1시간쯤이다.
3. **꼬리는 새 화자 수집이 남은 처방이다.** VC · TTS · 오버샘플링 · 손실 · 증강 모두 같은 오경보율에서 꼬리를 확실히 올리지 못했다(결과 31).
