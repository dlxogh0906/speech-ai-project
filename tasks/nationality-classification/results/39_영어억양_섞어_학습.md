# 39 — 영어 억양 음성을 섞어 학습하면 한국어 꼬리가 나아지나: 2단계, 실제로 섞어 학습 (2026-10-23)

질문(팀 제안, 38 의 다음 단계): 38 에서 "한국어에서 배운 모국어 단서가 영어에서도 통한다"(필요조건)를 확인했다.
이번엔 Speech Accent Archive(SAA) 영어를 실제로 학습에 섞어서, **한국어 test** 의 꼬리 · 중간 국가가 나아지는지 본다.

**결론: 꼬리는 안 오른다. 중간은 test 에서 오르지만 valid 에서 재확인이 안 되고, 웹 전체 · 단어는 확실히 떨어진다. VC 증강(33)과 거의 같은 모양이다. 지금 형태로는 쓰지 않는다.**

- **꼬리(학습 화자 ≤15): 같은 오경보율에서 오르지 않는다.**
  - test 의 차이 구간은 모두 0 을 낀다. valid 선택 −0.031 ~ +0.005, 학습 끝 EMA +0.010 ~ +0.068 이다.
  - 꼬리 78명 교차검증은 +0.010 ~ +0.021 이다. 4개 오경보율 중 15% 하나만 0 밖이다([+0.005, +0.041]). VC(33)의 +0.011 ~ +0.024 와 같은 크기다.
- **중간(16~100): test 에서만 오른다.**
  - 학습 끝 EMA 가 test 오경보 40% 에서 +0.070 [+0.017, +0.109], 60% 에서 +0.092 [+0.033, +0.122] 다.
  - 같은 비교를 valid 에서 하면 −0.026 · +0.033 · +0.004 로 모두 0 을 낀다. 33 의 VC 와 같은 꼴이다.
- **대가는 확실하다.** 웹 top-1 이 −0.010 / −0.022(valid 선택 / 학습 끝 EMA), 웹 단어 top-5 가 −0.031 / −0.034 다. 모두 구간이 0 을 안 낀다.
- **영어 자체는 배웠다.** 학습에 안 넣은 영어 화자 383명의 비원어민끼리 AUC 가 꼬리 0.752 → 0.885 · 중간 0.820 → 0.915 로 올랐다(학습 끝 EMA). 그게 한국어로는 넘어오지 않았다.

## 6. 읽기

- **영어에서 배운 것이 한국어로 넘어오지 않았다.** 영어 확인용 꼬리 AUC 는 0.752 → 0.885 로 크게 올랐다. 그런데 한국어 꼬리는 같은 오경보율에서 test · 교차검증 모두 구간이 0 을 낀다.
  - 모델이 영어 입력과 한국어 입력을 따로 처리하는 길을 배운 것으로 보인다(확인 안 함). 38 에서 본 "공유되는 단서"는 있지만, 영어 6시간(조각 2,851개)이 한국어 쪽 결정 경계를 옮길 만큼은 아니었다.
- **중간 test 상승은 VC(33)와 같은 모양이다.** 33 에서도 학습 끝 EMA 의 중간이 test 에서 +0.070 · +0.057 이었지만 valid 에서는 0 을 꼈다. 이번에도 valid 에서 +0.033 · +0.004 로 0 을 낀다.
  - 학습량도 다르다. 학습 끝 EMA 는 SAA 판이 290 step(13%) 더 돌았다. 28 에서 중간 이득이 "이어 학습한 양"에서 왔다는 걸 봤으니, 이 차이가 섞였을 수 있다. valid 선택은 거꾸로 SAA 판이 덜 돌았다(250 vs 1,000 step).
- **대가는 확실하다.** 웹 top-1 −0.022 · 단어 top-5 −0.034(학습 끝 EMA)이고 구간이 0 을 안 낀다. 영어 8초 조각이 학습의 14% 를 차지하면서 한국어 단어 · 문장 top-1 을 깎은 것으로 보인다(확인 안 함).
- **원래 질문(팀 제안)에 대한 답:** 영어 억양 음성을 섞는 방법 자체는 말이 된다(38). 다만 이번 규모(SAA 6시간 · 같은 문단)로는 한국어 꼬리에 의미 있는 이득이 없다.

## 7. 다음 (안)

- **이 형태로 더 키우지 않는다.** 아래는 다시 해 볼 때의 선택지다.
  - 영어 비율을 낮춘다(예: 나라당 50행). 웹 · 단어 손실을 줄이고 중간 이득이 남는지 본다.
  - 같은 step 수 대조군을 둔다. 대조군을 2,500 step 까지 돌려 학습량 차이를 지운다.
  - 시드 2~3개로 반복한다. 중간 +0.05~+0.09 가 시드 잡음인지 본다.
- 크게 다시 하려면 데이터부터 바꿔야 한다. SAA 는 화자당 문단 하나 · 비상업 라이선스다. 상업 이용이 되고 문장이 다양한 억양 표기 영어(Common Voice 의 accent 항목 등)가 있어야 한다.
