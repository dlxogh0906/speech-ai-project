# 16 — 화자 균형 샘플링 · focal loss 실험 (2026-10-01)

**결론: 둘 다 채택하지 않는다.** 학습 화자가 적은 국가의 마이크 녹음 성능이 오르지 않았다(정답 순위도 그대로).
전체 지표 변화는 ±0.6%p 안이고, 통계적으로 의미 있는 이득은 **단어 한 개 발화의 top-5 +2%p** 하나뿐이다.
꼬리 국가의 병목은 샘플링·손실이 아니라 **학습 화자 수**라는 기존 결론(docs/PROJECT_DEVELOPMENT_JOURNEY.md ③)과 같다.

## 1. 설정

현재 최고 모델 `run_zeroth` 와 **같은 시작점(run4/ep0.pt) · 같은 데이터 · 같은 하이퍼파라미터 · 1 epoch** 에서 아래만 바꿨다.

| 실험 | 바꾼 것 |
|---|---|
| 기준 `run_zeroth` | 없음 (기존 학습) |
| A `run_spkbal` | **화자 균형 샘플링** — 행 r 의 추출 확률 ∝ (N_c/N)·(1/S_c)·(1/n_s). 국가 비율은 그대로, 국가 안 화자는 같은 비중, 화자 안 발화는 고르게. epoch 당 774,819행 복원 추출 |
| B `run_spkbal_focal` | A + **focal loss** γ=2 (라벨 CE 항만, α·클래스 가중 없음) |

- 샘플러 확인: 국가 비율 차이 2.6e-14. 화자당 발화 범위가 이란 162~659 → 217~266, 한국 3~1,602 → 89~166 으로 고르게 됐다.
- 코드: `experiments/webmic_kd_train.py` 의 `--spk_balance` · `--epoch_size` · `--focal_gamma` (기본값이면 기존과 같다).
- 학습 시간: A 4,567초 · B 4,461초 (A100). 학습 중 부스 운영 서비스(GPU 8905) 응답 0.09 → 0.10~0.12초로 영향 거의 없음.
- checkpoint 선택은 하지 않았다 — 기존과 같이 epoch 끝(ep0, EMA) 가중치를 수출해 평가했다.
