# 31 — 꼬리 국가 실험 종합: 같은 오경보율로 한 표에 (2026-10-21)

26 · 27 · 28 · 29 · 30 · 33 의 모든 모델을 **한 기준(300m 전체학습)** 에 대해 같은 방법으로 다시 쟀다. 데이터 · 시험지는 27 과 같다.
(2026-10-21 저녁: 33 의 음성 변환(VC) 증강 3개 행을 더했다. 다른 행의 값은 그대로다.)

**결론: 꼬리 국가(학습 화자 ≤15)를 확실히 올린 실험은 없다.**

- **겉보기 꼬리 top-5 는 여러 실험에서 0.089 → 0.10 ~ 0.18 로 올랐다.**
  - 모두 꼬리 국가를 더 자주 찍어서 생긴 몫이다. 꼬리 오경보가 7.8% → 10 ~ 41% 로 함께 늘었다.
- **오경보율을 맞추면, 0 보다 확실히 높은 실험이 없다.**
  - 모든 실험이 기준 대비 −0.15 ~ +0.05 안에 있다.
  - 가장 나은 것은 **LoRA 이어 · 꼬리 ×3 + 131 웹 음질**이다. 네 오경보율 모두에서 +0.010 ~ +0.021 이다.
    - 하지만 108발화 중 1~2발화 차이이고, 구간 아래 끝이 0 이다.
    - 게다가 한국어 원어민을 외국인으로 찍는다(Zeroth top-1 0.993 → 0.897, 문서 29 §2.4). 쓸 수 없다.
  - **VC 50% (학습 끝 EMA, 문서 33)** 는 +0.000 ~ +0.047 로 칸 값은 더 높다.
    - 그러나 20% 에서도 구간 아래 끝이 0 이고, valid 에서는 −0.036 ~ −0.060 이다.
    - 꼬리 화자 78명 교차검증에서도 +0.011 ~ +0.024 로 0 을 포함한다. 웹 전체 top-5 는 −0.028 이다.
- **같은 오경보율에서 확실히 나빠진 실험:**
  - 행 균등 · 행 상한 · 손실 가중 전체학습: −0.04 ~ −0.09
  - TTS 합성: −0.05
  - 학습 안 한 모델: −0.09 ~ −0.15
  - 사전학습에서 바로 LoRA: −0.08 ~ −0.13
- **run_zeroth 만 꼬리가 크게 높다.** 원래 0.453 이고, 같은 오경보율에서 +0.28 ~ +0.34 다.
  - 하지만 출발 모델의 학습 목록이 없어서 test 화자 누수를 배제할 수 없다(문서 27 §5.4).
- **병목은 꼬리 국가의 학습 화자 수(5~15명)다.** 남은 처방은 꼬리 국가의 실제 새 화자를 모으는 것이다.

## 1. 읽는 법

- **꼬리:** 학습 화자 15명 이하인 국가다. train 에 12개국이 있다. test 에는 8개국 · 9명 · 108발화(웹 문장)뿐이다.
- **꼬리 top-5:** 꼬리 국가 발화에서 정답이 top-5 에 든 비율이다. 국가마다 낸 뒤 평균한다.
  - 7개국은 test 화자 1명 · 12발화다. 그래서 **1발화 차이가 0.010** 이다.
  - 5개를 무작위로 찍으면 0.12 다(5/41).
- **오경보:** 꼬리 밖 국가 발화(11,411개)의 top-5 에 꼬리 국가가 하나라도 끼는 비율이다.
- **같은 오경보율 비교:** 꼬리 국가 로짓에 같은 값 b 를 더해, 모든 모델의 오경보를 같은 값에 맞춘다. 그 상태에서 꼬리 top-5 를 비교한다.
  - 맞춘 값은 7.8%(기준 모델의 원래 값) · 15 · 20 · 25% 다.
  - 구간은 꼬리 화자를 부트스트랩 1000회 뽑아서 낸다. b 는 고정한 조건부 구간이다.
- **나머지 top-1:** 오경보 20% 에 맞췄을 때, 꼬리 밖 국가 발화의 top-1 이다. 그 실험이 다른 나라에 치른 값을 보여 준다.

## 3. 해석

- **모든 방법이 바꾼 것은 "꼬리 국가를 얼마나 자주 찍나"뿐이다.**
  - 행을 늘리든(오버샘플링 · 합성), 줄이든(행 균등 · 상한), 손실에 가중을 주든, 꼬리 국가의 학습 화자는 5~15명 그대로다.
  - 같은 효과는 학습 없이 기준 모델의 꼬리 로짓에 b 를 더하는 것만으로 얻는다.
- **기준 모델의 원래 꼬리 top-5 0.089 는 5개를 무작위로 찍는 0.12 보다 낮다.** 꼬리 국가를 거의 찍지 않기 때문이다.
  - 오경보를 20% 로 올려도 0.15 정도다. 지금 모델은 꼬리 국가끼리를 사실상 구별하지 못한다.
- **꼬리 test 가 9명 · 108발화뿐이라, 대략 ±0.05 보다 작은 차이는 잴 수 없다.**
  - +0.02 정도의 작은 진짜 개선이 있어도 이 시험지로는 보이지 않는다.
- **행 수를 조정한 전체학습 계열은 같은 오경보율에서 확실히 나쁘다. LoRA 이어 계열은 ±0.03 안이다.**
  - LoRA 이어 계열은 300m 전체학습에서 출발해 조금만 움직인다. 그래서 기준과 비슷하다.
  - 전체학습 계열은 처음부터 다시 배운다.
    - 행을 줄이면 인코더가 배우는 데이터 자체가 준다(1만 상한 42% · 2천 상한 11% · 행 균등 6%).
    - 손실 가중은 꼬리 국가의 몇 안 되는 화자에 큰 가중을 준다. 중앙값끼리 머리 국가의 약 11배, 가장 적은 방글라데시는 약 26배다.
    - 어느 쪽도 새 꼬리 화자를 가려내는 데 도움이 되지 않았다. 왜 오히려 나빠지는지는 확인하지 않았다.

## 4. run_zeroth 의 꼬리

- 같은 오경보율에서도 +0.28 ~ +0.34 이고 구간이 0 위에 있다. 이 표에서 유일하게 확실한 꼬리 차이다.
- 그러나 학습 화자 7명인 타지키스탄을 웹 1.00 · 131 1.00 으로 맞히는 식이다(문서 27 §5.4). 학습 화자 수로는 설명하기 어렵다.
- run_zeroth 의 출발 모델(KD 인코더)은 학습 목록이 남아 있지 않다. 그래서 이 test 화자를 봤을 가능성을 배제할 수 없다. 누수 쪽으로 본다.

## 5. 남은 방법

- **꼬리 국가의 실제 새 화자를 모은다.** 지금까지의 결과로는 남은 유일한 처방이다.
- **음성 변환(VC)으로 목소리 암기를 막는다 — 해 봤고, 꼬리는 오르지 않았다(`32_음성변환_점검.md` → `33_음성변환_증강_교차검증.md`).**
  - 학습한 꼬리 화자는 목소리만 바꾸면 top-1 0.979 → 0.14 로 무너진다. 모델이 목소리를 외웠다(32).
  - 학습 행 50% 를 다른 목소리로 바꿔 LoRA 이어 학습했다(33). 꼬리는 같은 오경보율에서 test · valid · 교차검증 모두 0 을 포함한다.
  - 중간 국가는 test 에서 +0.057 ~ +0.070 (확실), valid 에서 +0.023 ~ +0.032 (0 포함)다. 웹 전체 top-5 −0.028 · 단어 −0.089 를 내준다.
- **꼬리 평가를 키운다 (측정 쪽) — 33 에서 했다.**
  - 웹 문장이 있는 꼬리 화자 78명(train 61 · valid 8 · test 9)을 4묶음으로 돌려가며 뺐다. 888발화다.
  - 사전학습에서 LoRA 로 학습해야 해서 모델이 약하다(웹 문장 top-1 0.48). 차이의 구간 폭은 ±0.03 정도로, test 9명으로 잴 때(±0.04 ~ 0.08)보다 좁다.
