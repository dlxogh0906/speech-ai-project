# 20 — TTS 합성 음성을 학습에 넣으면 약한 국가가 좋아지나 (2026-10-03)

**결론: 좋아지지 않는다.** 대신 모델이 "합성 음색 = 그 4개국"이라는 지름길을 배운다.

> **2026-10-21 덧붙임:** 새 목소리(VoiceDesign)를 41클래스 모두에 같은 양으로 넣은 판도 해 봤다 → `30_TTS_VoiceDesign_전체학습.md`.
> 특정 국가로 쏠리는 지름길은 생기지 않았지만, 꼬리 국가는 같은 오경보율에서 좋아지지 않았다.

- **대상 4개국의 실제 사람 녹음** (학습에 없던 31명): top-1 0.339 → 0.332 (−0.7%p), top-5 0.701 → 0.671 (−3.0%p).
  - 95% 구간은 top-1 −3.0~+1.8, top-5 −6.4~+0.6 이다. 개선은 없고 오히려 약간 나빠지는 쪽이다.
- **다른 나라 화자를 같은 TTS 로 복제한 음성:** 4개국으로 판정되는 비율이 7.3% → **41.1%** 로 뛰었다.
  - 모델이 억양이 아니라 TTS 특유의 소리를 4개국의 단서로 배웠다는 뜻이다.
- **나머지 41개국 전체:** 변화가 없다. 웹 문장 top-5 +0.08%p, 유의하지 않다.

## 설정

- **대상국:** 말레이시아·인도·태국·홍콩. 성능이 약하면서 실제 시험 화자가 있어 측정 가능한 나라들이다.
- **합성 방식:** Qwen3-TTS(Apache-2.0) ICL 모드로 각 나라 **학습 화자의 목소리를 복제**해, AIHub 131 낭독 문장(그 화자가 읽지 않은 문장)을 새로 만들었다.
  - 결과 18 의 사전 점검에서 억양이 가장 잘 남은 방식이다.
  - 나라당 1,500개, 합계 6,000개, 13.2시간이다.
  - 복제한 학습 화자는 말레이시아 38, 인도 38, 태국 33, 홍콩 60명이다.
  - 길이가 비정상인 출력은 버렸다.
- **학습량 대비 비율:** 기존 학습 행 대비 말레이시아 +9%(16,291행), 인도 +16%(9,468), 태국 +6%(26,306), 홍콩 +5%(28,160).
- **학습:** `run_zeroth` 와 **똑같은 시작점·설정·seed·1 epoch** 로 학습하고(780,819행), 합성 행만 추가했다. 합성 행은 교사 신호가 없어 CE 만 쓴다. epoch 끝 EMA 가중치를 썼다.
- **평가**
  - 시험셋: 19,696행. 대상 4개국은 검증 화자까지 합쳐 31명, 301문장이다.
  - 지름길 점검: 결과 18 에서 만든, **다른 6개국 시험 화자를 같은 TTS 로 복제한 음성 192개**를 썼다.

## 해석

- **결과 18 과 합쳐서 본 실패 경로**
  - TTS 는 억양을 지운다. 발음이 원어민처럼 정확해서 whisper CER 이 0 이다.
  - 그래서 합성 음성에서 4개국과 함께 일관되게 나타나는 것은 억양이 아니라 **TTS 특유의 소리**뿐이다.
  - 모델은 그 소리를 4개국의 단서로 배웠다. 실제 사람 녹음에는 그 소리가 없으니 도움이 되지 않는다.
- **양을 더 늘려도 같은 결과가 예상된다.** 더 많이 넣을수록 지름길만 강해진다.
- **약한 국가의 병목은 "학습·시험 화자 수"라는 기존 결론을 다시 확인했다.**
  - 지금까지 효과가 없던 시도: 샘플링·focal(결과 16), SupCon·화자 적대 학습(팀 기록), 모국어 언어식별 전이(결과 19), TTS 합성(결과 18·20).
