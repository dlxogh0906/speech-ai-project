# 42 — 운율을 모델 안에서 배우게 하면: 학습 4갈래 (2026-10-23)

질문(사용자): 40 의 나라별 운율 특징을 학습할 방법은 없나 → 41(점수 합치기) 다음 단계로 "다음 방법론도 다 시도해보자".
이번에 한 것: 대조군과 같은 학습에 운율을 겨냥한 장치를 하나씩 붙였다.
- 헤드 앞 풀링을 바꾼 것 두 갈래, 운율을 직접 넣은 것 두 갈래다.
- 나머지는 모두 대조군과 같다.

**결론: 넷 다 꼬리 · 중간을 같은 오경보율에서 올리지 못했다. 운율 궤적 입력 · 운율 보조 과제는 모델이 거의 안 바뀌었다(모든 칸 ±0.005 안팎). 평균+표준편차 · attention 풀링은 학습 끝 EMA 에서 웹 단어 top-5 가 +0.015~0.018 올랐다. test · valid 둘 다에서다. 다만 출발점(300m 전체학습)보다는 여전히 낮다. LoRA 학습 중에 단어가 덜 떨어진 것이다.**

- **꼬리 · 중간: 이득 없음.**
  - 같은 오경보율로 맞추면 네 갈래 모두 test · valid 에서 일관된 이득이 없다.
  - 0 을 벗어난 칸이 몇 개 있지만 방향이 칸마다 다르다. 같은 칸이 다른 split 에서 재현되지도 않는다.
    - 예: 평균+표준편차 · valid 선택 · test 꼬리 20% 는 −0.042 [−0.083, −0.009] 다.
    - 같은 갈래 학습 끝 EMA · valid 중간 20% 는 +0.028 [+0.003, +0.044] 인데, test 에서는 −0.010 이다.
  - 꼬리 집단은 test 9명 · valid 8명이다. 한 명만 바뀌어도 ±0.02~0.05 가 움직인다.
- **attention 풀링 valid 선택판의 꼬리 +0.047 [+0.000, +0.100] 은 오경보 이동이다.**
  - 꼬리 오경보가 14.2% → 17.2% 로 늘었다. 같은 오경보율로 맞추면 +0.021 · −0.026 · +0.000 (10 · 20 · 30%) 이다.
  - 29 · 31 에서 본 것과 같은 꼴이다.
- **운율 궤적 입력 · 운율 보조 과제는 모델이 그 정보를 거의 안 쓴다.**
  - 궤적 칸의 헤드 가중치는 원래 칸의 0.06 배다.
  - 보조 과제는 그 자체로 잘 배웠다(보조 MSE 1.29 → 0.50, 정답은 표준화한 값).
  - 그런데도 분류는 그대로다. 운율 정보가 이미 표현 안에 있다는 41 의 결론과 맞는다.
- **풀링 두 갈래의 단어 상승은 test · valid 에서 재현됐다. 하지만 "개선"이라기보다 "덜 떨어짐"이다.**
  - 학습 끝 EMA · 웹 단어 top-5:
    - 평균+표준편차: test +0.017 [+0.010, +0.024] · valid +0.018 [+0.002, +0.033]
    - attention: test +0.015 [+0.007, +0.024] · valid +0.016 [−0.001, +0.029]
  - 출발점(300m 전체학습 best 16k)의 test 단어 top-5 는 0.718 이다. 대조군은 0.694, 두 갈래는 0.711 · 0.709 다.
  - valid 곡선을 보면 대조군은 0.728 → 0.692 로 떨어져 머물고, 두 갈래는 더 떨어졌다가 끝에서 0.71 까지 회복한다(§3).
  - 대가가 있다. 131 국가 평균 top-5 가 평균+표준편차 test −0.012 [−0.020, −0.000] 이다(valid −0.011, 0 을 낌). Zeroth 원어민 오답은 457발화 중 2 → 6 이다.
- **attention 은 결과가 평균+표준편차와 거의 같다.**
  - 점수 층 가중치 크기가 0.10 이라 프레임 점수가 ±1.2 를 못 넘는다. 그래서 프레임 가중치 차이는 많아야 약 10배다.
  - 이건 상한이고, 실제 가중치 분포는 재지 않았다.

| attention | +0.006 · −0.008 · +0.007 | −0.003 · −0.002 · +0.010 | −0.011 · +0.021 · −0.000 | +0.013 · −0.009 · +0.009 |

- 굵게 = 구간이 0 을 벗어난 칸. 구간 전체는 `matched_fa_{test,valid}.md` 에 있다.
  - 꼬리 칸의 구간은 대부분 ±0.02~0.08 폭이다. valid 꼬리의 +0.048 들은 [+0.000, +0.083] 으로 0 에 붙어 있다.
- 0 을 벗어난 칸이 + 쪽 · − 쪽 다 있고, 어느 것도 다른 split 이나 다른 오경보율에서 재현되지 않는다.
- 원래 오경보율 (test 꼬리, valid 선택): 대조군 14.2% · 평균+표준편차 15.0% · attention 17.2% · 운율 궤적 14.7% · 운율 보조 14.5%.
  - attention 의 원래 꼬리 칸 0.135 (대조군 0.089) 는 이 오경보 차이에서 나온다.

## 5. 새 칸을 얼마나 쓰나 — 헤드 가중치

헤드 입력은 모두 표준화돼 있다(평균 · 표준편차 칸은 μ/σ, 운율 칸은 LayerNorm). 그래서 칸별 가중치 크기(41개 출력에 대한 노름)를 견줄 수 있다.

| 갈래 | 원래 1,024칸 중앙값 | 새 칸 중앙값 | 비 (valid 선택 · EMA) |
|---|--:|--:|--:|
| 평균+표준편차 (새 1,024칸) | 1.005 · 1.009 | 0.088 · 0.101 | 0.09 · 0.10 |
| attention (새 1,024칸) | 1.006 · 1.007 | 0.104 · 0.114 | 0.10 · 0.11 |
| 운율 궤적 (새 128칸) | 1.000 · 1.003 | 0.061 · 0.061 | 0.06 · 0.06 |

- 새 칸은 0 에서 시작해 2,210 step (헤드 lr 1e-3) 동안 배운 만큼이다. 더 오래 배우면 커질 수 있다.
- 표준편차 칸은 1,024개라 칸마다 작아도 합치면 영향이 남는다. 단어 차이가 여기서 나온 것으로 본다.
- 운율 궤적 칸 128개는 칸 수도 적고 가중치도 작다. 분류 결과가 대조군과 거의 같은 것과 맞는다.
- attention 점수 층(Linear 128→1)의 가중치 크기는 0.10 이다(valid 선택 0.098 · EMA 0.104).
  - tanh 출력이 ±1 이므로 프레임 점수는 ±1.2 (√128 × 0.104) 를 넘지 못한다.
  - 그래서 가장 큰 프레임 가중치와 가장 작은 것의 비가 e^2.4 ≈ 10배 이하다. 실제 분포는 재지 않았다.

## 6. 읽기

- 41 에서 "운율 정보는 모델이 이미 가지고 있다"고 봤다. 이번에 모델 안에 넣어 배우게 해도 같은 답이 나왔다.
  - 궤적을 직접 줘도 거의 안 쓴다.
  - 보조 과제로 표현이 운율을 맞히게 만들어도(MSE 0.50) 분류는 안 바뀐다.
- 꼬리가 안 오르는 이유는 여전히 화자 수다(27 · 34 · 35). 운율은 그 병목을 풀지 못한다.
- 평균+표준편차 풀링의 단어 효과는 운율과 상관없는 부수 효과로 보인다. 짧은 단어 발화에서 프레임 변동 정보가 LoRA 학습 중 단어 손해를 줄였다.
  - 시드 1개 · 2 epoch 결과다.
  - 출발점(전체학습 300m)보다 단어가 낫지는 않다.
