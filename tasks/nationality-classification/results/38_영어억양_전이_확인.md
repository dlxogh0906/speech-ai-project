# 38 — 영어 억양 음성으로 꼬리를 보강할 수 있나: 1단계, 모국어 단서가 영어에서도 통하나 (2026-10-23)

질문(팀 제안): 꼬리 · 중간 국가 사람의 영어 음성은 구하기 쉽다. 그걸 학습에 넣으면 한국어 발화로 국적을 가리는 성적(특히 꼬리)이 나아질까.
이번에 한 것: **학습 없이**, 지금 모델에 영어 억양 음성을 그대로 넣어 "한국어에서 배운 모국어 단서가 영어에서도 통하는지"만 봤다.
영어로 학습해서 한국어가 나아지려면 이게 먼저 성립해야 한다(필요조건). 충분조건은 아니다.

**결론: 통한다 — 한국어보다 약하지만 우연보다 확실히 높다.**

- **비원어민끼리 AUC (0.5 = 단서 없음):** 300m 전체학습이 꼬리 0.754 [0.697, 0.806] · 중간 0.725 [0.675, 0.774] · 머리 0.800 [0.761, 0.828] 이다.
  - 같은 모델의 한국어 test 화자 AUC(꼬리 0.924 · 중간 0.983 · 머리 0.991, 참고용)보다는 낮다.
- **한국어로 더 학습한 모델일수록 영어에서도 잘 가린다.** 꼬리 기준 학습 안 함 0.660 → 전체학습 0.754 → LoRA VC 50% 0.773 이다.
  - 한국어 국적 학습이 키운 단서 일부가 영어에도 있다는 뜻이다. 거꾸로(영어로 학습 → 한국어)도 도움이 될 여지가 있다는 신호지만, 증명은 아니다.
- **꼬리 몇 나라는 영어 화자가 우리 학습 화자보다 많다.** 에티오피아 31명(우리 3명) · 방글라데시 14(3) · 파키스탄 21(11) · 이란 22(15) · 네팔 14(11) · 칠레 7(5) 이다.
  - 르완다 · 잠비아 · 투르크메니스탄은 1명, 키르기스스탄은 2명, 홍콩은 0명이다. 이 나라들은 영어로도 거의 없다.
- **한국인의 영어는 Korea 로 가지 않는다.** Korea AUC 0.574(비원어민끼리) · top-5 0.039 다. 우리 Korea 클래스는 "원어민 한국어"라서다.
- 영어 전체는 주로 미국으로 찍힌다(1위의 66%). 그래서 top-1 · top-5 는 의미가 적고, 순위만 보는 AUC 로 판정했다.

## 2. 방법

- **모델 3개:** 300m 학습 안 함 · 300m 전체학습 · LoRA 이어 · 행 균등 + VC 50% (valid 선택). 대시보드와 같은 체크포인트이고, 학습은 하지 않았다.
- **입력:** 녹음을 앞에서부터 10초씩 자른 3,456조각이다(마지막 조각이 3초 미만이면 버림). 평가는 우리 `--eval_only` 그대로다(bf16).
- **화자 점수:** 조각별 log-softmax 의 평균이다. 화자마다 녹음이 하나라 화자 단위로만 잰다.
- **나라별 지표**
  - top-5 적중 · top-5 오경보: 그 나라 화자에게 정답이 5위 안에 든 비율, 다른 나라 화자에게 그 나라가 5위 안에 낀 비율이다.
  - **AUC:** 그 나라 점수 하나로 그 나라 화자와 나머지 화자를 가르는 정도다. 순위만 보므로 영어가 통째로 미국 쪽으로 쏠려도 영향이 없다.
  - **AUC (비원어민끼리):** 양쪽에서 영어 원어민을 뺀 것이다. 나머지 화자의 37% 가 미국 · 영국 원어민이라, "억양이 있으면 외국 나라 점수가 다 오른다"만으로도
    보통 AUC 가 0.5 를 넘는다. **이 칸을 판정에 쓴다.**
- **묶음:** 우리 학습 화자 수로 꼬리(≤15) · 중간(16~100) · 머리(>100)로 나누고, SAA 화자가 3명 이상인 나라만 평균했다(꼬리 8 · 중간 9 · 머리 19개국).
- **구간:** 나라마다 화자를 복원추출 1000회 해서 95% 구간을 냈다.

## 4. 주의

- **필요조건만 봤다.** 영어를 학습에 넣었을 때 한국어 꼬리가 오르는지는 따로 재야 한다. 단서가 겹친다고 영어 학습이 한국어로 옮겨 간다는 보장은 없다.
- **녹음 조건이 섞였을 수 있다.** SAA 는 수십 년에 걸쳐 여러 곳에서 모았다. 나라마다 녹음 환경이 다르면 그것도 단서가 된다. 확인하지 않았다.
- **라벨은 출생 국가다.** 모국어가 다른 화자가 섞여 있다(잠비아 1명은 벵골어, 말레이시아 2명은 영어 원어민 등). 거르지 않았다.
- **화자당 녹음 하나 · 25초 안팎 · 모두 같은 문단이다.** 학습에 쓰면 내용이 하나뿐이라 문장을 외우기 쉽다.
- **꼬리 몇 나라는 영어로도 없다.** 르완다 · 잠비아 · 투르크메니스탄 1명, 키르기스스탄 2명이다. 묶음 평균에서도 뺐다.

```bash
source tools/env.sh; F=$NATIONALITY_OUTPUTS/webmic_kd/full_encoder_spk811; D=$NATIONALITY_OUTPUTS/webmic_kd/lab131full_zeroth_r16k_spk811

for x in full_300m:full300m frozen_lp_300m:frozen300m lora_eq1008_vc50_from_full300m:lora_vc50; do
  $PY $FT --eval_only --ckpt $F/${x%%:*}/best.pt --test $A/probe_chunks10s.csv --out $P/${x#*:}; done   # 모델마다 GPU 30초
$PY -I $S/saa_probe_report.py --csv $A/probe_chunks10s.csv --train $D/train.csv --meta $A/meta.csv \
    --models "300m 학습 안 함=$P/frozen300m/logits.npz" "300m 전체학습=$P/full300m/logits.npz" \
    "LoRA 이어 · 행 균등 + VC 50% (valid 선택)=$P/lora_vc50/logits.npz" > $P/report.md
```
