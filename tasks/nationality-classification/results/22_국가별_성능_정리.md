# 22 — 국적 분류 성능 정리: 국가별 · 문장 수별 (2026-10-03)

새 모델(run_zeroth)과 지금 GPU 8905 에서 서빙 중인 옛 모델을 **같은 시험 문장**으로 비교했다. 숫자는 모두 **1위 정답 / 5위 안 정답**이고, 화자 1명을 한 표로 센다. 측정 방법은 맨 아래 [측정 기준](#측정-기준)에 있다.

## 한눈에

- **새 모델은 1문장 0.77, 3문장 합산 0.86, 5문장 0.88 이다** (외국인 1,007명, 1위 정답). 5위 안 정답은 1문장부터 0.96 이다.
- **지금 서빙 모델은 1문장 0.25 이고, 문장을 합쳐도 0.27 이다.** 판정이 유럽 나라로 쏠려 있다. 그래서 몇몇 유럽 나라는 정답률이 높아 보이지만, 그 나라로 판정한 문장 대부분이 오답이다. 예를 들어 '독일'로 판정한 문장 중 진짜 독일인은 18% 다.
- **문장을 합치면 대부분 나라가 오른다.** 1→3문장 기준으로 몽골 0.62→0.85, 우즈베키스탄 0.51→0.79, 미국 0.48→0.63, 홍콩 0.28→0.47 이다.
- **합쳐도 낮은 나라는 대개 모국어가 다른 나라와 같다.**
  - 불가리아 시험 화자 4명은 모두 모국어가 튀르키예어라 튀르키예로 판정된다.
  - 페루·콜롬비아는 모국어가 스페인어라 스페인으로 판정된다.
  - 영어권인 미국·영국·필리핀·인도는 서로 헷갈린다.
  - 억양이 알려 주는 것은 국적보다 모국어다.
- **학습 화자가 6~16명뿐인 칠레·키르기스스탄·네팔·파키스탄은 0 이다.** 시험 화자도 1명씩이라 값은 불안정하다.

## 측정 기준

- **새 모델**: run_zeroth (XLS-R 300m 17층 지식증류 인코더 + 41개국 헤드, ONNX). GPU 8922 데모와 `/multi` 테스트 페이지가 이 모델이다.
- **지금 서빙 모델**: GPU 8905 에서 서빙 중인 옛 모델 (`/data/speech-ai/weights/final/nationality`).
  - 새 모델과 구조(300m KD 인코더 + 헤드)는 같고, 학습 데이터가 다르다.
  - 학습에 AIHub 040(영어권)·042(중국·일본) 웹 마이크 화자가 없었다 (결과 10).
- **시험 데이터**
  - AIHub 외국인 한국어 음성 040~043 (웹 마이크 녹음)의 문장·자유발화 11,519개다. 외국인 1,007명, 36개국이다.
  - 단어 한 개짜리 발화는 뺐다.
  - 화자 대부분(918명)이 12문장씩이고, 문장 길이 중앙값은 6.6초다.
  - 한국인은 kspon·zeroth 원어민 녹음 1,127개, 77명이다.
- **화자 분리**: 시험 화자 1,084명 중 학습·검증 화자와 겹치는 사람은 0명이다.
- **채점**
  1. 한 화자의 문장 k개를 무작위로 20번 뽑는다 (문장이 k개뿐이면 1번).
  2. 각 문장의 log 확률을 평균한 뒤, 정답 나라가 1위인지 / 5위 안인지 본다.
  3. 화자별로 평균하고, 그걸 다시 나라별·전체로 평균한다.
  - 문장이 k개보다 적은 화자는 그 열에서 빠진다.
- **학습 화자**: 학습 데이터(`train.csv`)에 있는 나라별 서로 다른 화자 수다.
- **모국어**: AIHub 메타데이터(040~043 `language`, 505 `mother_tongue`)에서 화자마다 가장 많이 적힌 값이다.
- **반영하지 않은 것**: 표는 모델 출력 그대로다. 8922 서빙에 붙은 한국인 게이트·무음 정규화는 들어 있지 않다.
  - 서빙 그대로 재면 외국인 1위 정답은 1·3·5문장 0.73·0.83·0.85 로, 모델 단독보다 3~4점 낮다(결과 23).
  - 외부에 서비스 성능으로 말할 때는 이 값을 쓴다.
- **주의**: AIHub 웹 마이크 녹음 기준이다. 부스·폰 녹음은 마이크와 소음이 달라 값이 다를 수 있다 (결과 11·14 참고).
