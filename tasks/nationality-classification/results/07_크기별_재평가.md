# 07 — 모델 크기별 재평가 (2026-08-05)

백본 크기(2B vs 300m)와 양자화(fp32 vs int8)가 정확도·용량·지연에 얼마를 쓰는지.

---

## ① 백본 크기 — 기존 수치, 같은 test 셋으로 짝을 맞춤

**주의 — 크기 비교에 `0702` 를 쓰면 안 된다.** 그 실험의 test 셋은 043 아시아가 빠진
133,509발화이고, `0704`·`0705` 는 043 을 포함한 135,770발화다. 자주 인용되는 2B top-5
`0.9496` 은 앞쪽 값이라 300m 의 `0.9331` 과 나란히 놓으면 크기 손실이 과장된다.

같은 셋(135,770)에서의 값:

| | XLS-R 2B (`0704`) | XLS-R 300m (`0705`) | 차이 |
|---|--:|--:|--:|
| top-1 | 0.7838 | 0.7510 | −0.0328 |
| top-5 | 0.9410 | 0.9331 | −0.0079 |
| macro top-5 | 0.6294 | 0.6170 | −0.0124 |
| 사용 층 | 31 | 17 | |
| 백본 용량 | 25 GB | 3.6 GB | **7분의 1** |

top-5 를 0.8%p 내주고 백본을 7분의 1로 줄인다. 배포는 300m.

test 구성: 505 국내 92,999 / 041 유럽 25,163 / 043 아시아 2,609 / 한국어 14,999.

## ② int8 양자화 — 신규 실측

지금까지 int8 검증은 `quantize_onnx_300m.py` 의 클래스별 샘플 wav **41개**뿐이었다.
실제 test 오디오로 잰 건 이번이 처음이다.

`scripts/eval/eval_size_tradeoff.py --n 1000` · `aihub_country41_811/test.csv` · 4스레드 CPU

| | fp32 ONNX | int8 ONNX | 차이 |
|---|--:|--:|--:|
| 용량 | 960 MB | **279 MB** | 3.4배 작음 |
| 발화 1건 지연 | 1,343 ms | 1,264 ms | 1.06배 |
| **top-1 (정답 대비)** | 0.8070 | **0.8040** | **−0.003** |
| **top-5 (정답 대비)** | 0.9630 | **0.9610** | **−0.002** |
| top-1 일치율 (fp32 대비) | — | 91.8% | |
| top-5 집합 일치율 | — | 38.2% | |

**정확도 손실은 top-1 0.3%p · top-5 0.2%p 뿐이다. 용량은 3.4배 줄어든다.**

⚠️ **일치율로 판단하면 안 된다.** 처음엔 "top-1 예측의 8.2%가 바뀐다"를 근거로 int8 을
기각했는데, 정답 대비로 재보니 정확도는 거의 그대로였다. 바뀌는 예측은 대부분 원래
틀렸던 것이거나 비슷한 클래스끼리 자리를 바꾼 것이다. top-5 집합 일치 38.2% 도 같은
착시다 — 5개 중 하나만 달라도 불일치로 세는 기준이라 낮게 보일 뿐, 실제 top-5 정확도
차이는 0.2%p 다. **모델 교체 판단은 반드시 정답 대비 지표로 한다.**

**속도는 거의 안 는다(1.06배).** 동적 양자화가 MatMul 만 int8 로 바꾸고 앞단 conv 는
fp32 로 남기는데(`op_types_to_quantize=["MatMul"]`, ConvInteger 회피), 이 모델은 conv
특징 추출기가 시간을 잡아먹어서 Transformer 쪽만 줄여봐야 벽시계가 안 줄어든다.

**권고 — 디스크·메모리가 빠듯하면 int8 을 써도 된다.** 0.3%p 를 내주고 681 MB 를
아낀다. 속도를 기대하고 쓰면 안 된다.

측정 조건: `aihub_country41_811/test.csv` 무작위 1,000발화(seed 42) · 4스레드 CPU.
⚠️ 이 test 셋은 `metrics.json` 의 0.751/0.933 을 만든 셋(135,770·37클래스)이 **아니다**
(120,220·29클래스, 041·043 미포함이라 더 쉽다). fp32 0.8070 이 0.751 과 다른 이유다.
fp32·int8 을 **같은 표본에 태워** 나란히 잰 값이므로 둘의 비교는 유효하다.
