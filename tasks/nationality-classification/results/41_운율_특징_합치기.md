# 41 — 운율 특징을 모델에 더하면 나아지나: 점수 합치기 (2026-10-23)

질문(사용자): 40 에서 본 나라별 운율 특징을 학습에 쓸 방법이 없나.
이번에 한 것: 모델을 다시 학습하기 전에 싼 시험부터 했다.
- 운율 특징만으로 작은 분류기를 만들어, 그 점수를 지금 모델 점수에 더했다.
- 더해서 오르면 모델이 아직 못 쓰는 정보가 있다는 뜻이다. 안 오르면 이미 쓰고 있거나 쓸모없는 정보다.

**결론: 안 오른다. 운율 특징 점수를 더해도 대시보드 칸 · 꼬리 · 중간 모두 그대로다. 손으로 만든 운율 특징에는 모델이 이미 가진 것 이상의 정보가 없다. 운율을 겨냥해 모델 구조를 바꾸는 일(헤드 교체 · 음높이 입력 · 보조 과제)은 기대가 낮다.**

- **valid 가 운율 점수 가중치로 0 을 골랐다.** valid NLL 이 가장 낮은 가중치를 0~1 에서 찾았다. 네 조합(기준 모델 2개 × 특징 7 · 22개) 모두 0 이었다. 조금만 더해도 valid 가 나빠졌다.
- **모델 점수의 온도를 함께 맞춰도 마찬가지다.**
  - 온도 2 · 가중치 0.1 이 골라졌다. valid NLL 은 온도만 맞춘 것보다 0.001~0.002 낮아질 뿐이다.
  - test 대시보드 칸 차이는 모두 ±0.004 안이고, 구간은 모두 0 을 낀다(머리 +0.002 [+0.000, +0.004] 하나만 경계).
  - 꼬리 · 중간을 같은 오경보율로 맞춰도 ±0.02 안팎이다. test 에서 0 을 벗어난 칸 하나(학습 끝 EMA · 22개 · 중간 40% +0.016)는 valid 에서 재현되지 않았다(+0.006, 0 을 낌).
- **운율이 맞히는 발화는 모델도 이미 맞힌다.** test 외국인 13,308발화로 봤다.
  - 모델이 틀린 발화에서 운율 분류기가 맞히는 비율은 3.4%(7개) · 4.7%(22개)다. 무작위 2.4% 와 거의 같다.
  - "운율만 맞히는" 발화는 106 · 149개(0.8% · 1.1%)뿐이다. 이걸 다 구해도 웹 top-1 이 1%p 남짓 오르는 게 상한이다. 운율 점수가 약해서 그 발화만 골라 바꿀 수가 없다.
- **운율 혼자서는 약하다.**
  - 발화 하나로 외국인 top-1 0.053 · 0.107 이다(무작위 0.024).
  - 화자의 발화를 다 모아도 0.122 · 0.210 이다. 같은 방식으로 모은 모델은 0.843 이다.
- **곁가지: 모델이 과신한다.** 모델 점수를 온도 2 로 나누면 valid NLL 이 1.40 → 1.02 로 크게 좋아진다.
  - 순위는 안 바뀌어서 top-1 · top-5 는 그대로다. 확률값을 화면에 보여 줄 거라면 손볼 만하다.
  - 이 값은 「LoRA 이어 · 행 균등 1,008」 기준이다. 서비스 모델(KD ONNX)은 따로 확인해야 한다.

## 1. 설정

| | 내용 |

| 기준 모델 | 「LoRA 이어 · 행 균등 1,008」 valid 선택 · 학습 끝 EMA (39 의 대조군). valid · test 로짓을 그대로 쓴다 |
| 운율 특징 | 40 과 같은 22개(`prosody_feats.py`). 서비스에서는 읽은 문장을 모르므로 문장 보정을 안 한다. 속도 = 자기 모음 수 / 발화 구간 |

| 합치기 | log softmax(모델 / T) + w · log p(운율). ① T = 1 · w ∈ 0~1 ② T ∈ {1, 1.5, 2, 3, 4, 6} · w ∈ 0~2 를 valid NLL 로 골랐다. test 는 고른 뒤 한 번 쟀다 |

## 4. 읽기

- **모델이 이미 운율 정보를 쓰고 있다.** 운율 분류기가 맞히는 발화는 대부분 모델도 맞힌다. 모델이 틀린 발화에서는 운율도 우연 수준이다(2.4% 대비 3.4~4.7%).
  - XLS-R 은 소리를 통째로 듣는다. 그래서 속도 · 쉼 · 리듬 같은 큰 단서는 이미 표현 안에 있는 것으로 보인다(직접 확인은 안 함 — 표현에서 운율 특징을 예측해 보는 시험은 안 했다).
- **특징 22개가 운율의 전부는 아니다.** 억양 윤곽의 모양이나 강세 위치 같은 세밀한 정보는 이번 특징에 없다.
  - 그러니 "운율을 더 잘 담는 구조"(평균 + 표준편차 · attention pooling 헤드)가 쓸모없다고 증명한 건 아니다.
  - 다만 40 에서 나라 차이 자체가 작았고(화자 분산의 2~11%), 음높이 쪽은 재현도 안 됐다. 그래서 기대는 낮다.
- **꼬리는 원래 기대하지 않았다.** 화자 3~15명으로 화자 SD 1배도 안 되는 차이를 배울 수 없다. 꼬리 칸은 이번에도 그대로다.
