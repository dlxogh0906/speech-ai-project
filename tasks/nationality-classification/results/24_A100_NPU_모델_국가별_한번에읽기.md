# 24 — 기존 A100 모델 vs NPU 모델: 글 한 번에 읽기(`/predict_long`) 국가별 비교 (2026-10-05)

## 결론

- **전체 정확도 차이가 크다.** 한 번에 읽기를 적용하면 외국인 1위 정답이 이렇게 된다.
  - 기존 A100 서버(옛 모델): 1문장 0.25 → 3문장 0.32 → 5문장 0.32.
  - NPU 서버(새 모델): 0.73 → 0.83 → 0.85.
  - 5위 안 정답은 A100 이 0.38~0.49, NPU 가 0.94~0.98 이다.
- **한국인 원어민**: A100 은 0.86 → 0.97(3문장)이고, NPU 는 모든 경우 1.00 이다.
- **NPU 가 크게 앞서는 나라**는 아시아·영어권이다(3문장, NPU − A100).
  - 일본 +92%p · 싱가포르 +86 · 중국 +80 · 필리핀 +76 · 인도네시아 +71 · 베트남 +68 · 몽골 +60 · 미국 +49 · 영국 +42.
- **A100 이 더 높아 보이는 나라는 그 나라로 몰아 판정한 결과다.** 루마니아 · 카자흐스탄 · 불가리아 · 독일 · 브라질 · 콜롬비아가 그렇다.
  - 3문장에서 A100 이 '루마니아'라고 한 305건 중 진짜 루마니아인은 12% 다. NPU 는 28건 중 100% 다(아래 정밀도 표).
- **둘 다 못 맞히는 나라**: 말레이시아, 학습 데이터가 거의 없는 칠레·키르기스스탄·네팔·파키스탄, 영어권과 헷갈리는 인도.

## 비교 조건

| | 기존 A100 서버 (GPU 8905, 토큰 있는 기존 주소) | NPU 서버 (8905, 2026-10-05 `/predict_long` 반영) |
|---|---|---|
| 모델 | 옛 모델 `encoder_kd_run2` (`/data/speech-ai/weights/final/nationality`) | 새 모델 `run_zeroth` + 확인 모델 게이트 τ0.9 |
| 전처리 | 없음(원본 입력) | 주 모델은 무음 정규화, 확인 모델은 원본 입력 |
| `/predict_long` | **없다.** 같은 규칙을 붙였다고 가정하고 계산했다 | 운영 중 |

- **NPU 의 확인 모델은 A100 8905 모델과 같은 파일이다**(sha256 같음).
  - 그래서 NPU 서빙을 재현할 때 남긴 확인 모델 출력(원본 입력)이 곧 A100 서버의 판정이다. 두 서버를 같은 녹음·같은 구간으로 비교했다.
- **시험 데이터**: 학습에 없던 외국인 웹마이크 화자(1·3·5문장에 1,007·983·972명)와 한국인 원어민 77명(kspon·zeroth)이다.
- **한 번에 읽기 재현**: 같은 화자의 문장 3·5개를 이어 붙이고 `/predict_long` 규칙으로 3·5구간으로 나눴다. 화자당 2묶음이다. 1문장은 문장 하나다.
- **NPU 값의 계산 방식**: 같은 모델을 GPU(ONNX)로 계산했다.
  - NPU 실서버와의 1위 일치는 2026-10-05 6/6, 결과 15 의 617개 기준 97.5% 다.
- **화자 1명 = 1표**로 셌다. ⚠ 는 시험 화자가 1~2명이라 값이 불안정한 나라다.

## 해석할 때 주의

- **NPU 서빙에서는 일부 유럽·중앙아시아 나라가 결과 22(모델 단독)보다 낮다.** 예: 1문장 루마니아 0.84 → 0.64, 카자흐스탄 0.51 → 0.30, 불가리아 0.31 → 0.21.
  - 서빙의 무음 정규화 때문이다. 한국인 원어민 녹음이 외국인으로 잘못 나오던 문제를 막으려고 넣은 처리다(결과 11).
  - 모델 단독 숫자로 나라별 성능을 말하면 안 되고, 이 문서의 NPU 열을 쓴다.
- **⚠ 나라는 화자 1명의 결과가 곧 그 나라 값이다.** 투르크메니스탄·타지키스탄·캄보디아에서 A100 이 높은 것도 이 표본에서 나온 값이다.
- **AIHub 웹마이크 녹음 기준이다.** 부스·폰 녹음은 다를 수 있다.
- **A100 `/predict_long` 은 실제로 없는 기능을 계산한 것이다.** 붙인다면 이 값이 나온다는 뜻이다.
