# 35 — 꼬리 국가만 따로 판정하면: 두 단계 판정의 상한 (2026-10-22)

질문: "꼬리 부분만 따로 판정하는 모델을 만들면 어떤가."

꼬리만 따로 판정하는 모델은 결국 두 단계다. ① 이 사람이 꼬리 국가 사람인가, ② 그렇다면 꼬리 12개국 중 어디인가.
지금 모델이 각 단계를 얼마나 하는지, 이미 있는 로짓으로 쟀다. 새로 학습하지는 않았다.
(34 는 화자 수 실험이다 → `34_학습화자_수_실험.md`.)

**결론: 꼬리만 따로 판정하는 모델을 만들어도 꼬리는 오르지 않을 것으로 본다.**

막히는 곳은 ① "꼬리 국가 사람인가"이다. 이 단계는 모델을 따로 만든다고 쉬워지지 않는다.

- **꼬리 발화는 대부분 꼬리 밖 이웃 나라나 큰 나라로 간다.**
  - 41클래스 top-1 에서 95% 가 꼬리 밖 국가로 간다. 행선지는 우즈베키스탄 · 러시아 같은 이웃 나라와 인도네시아 · 루마니아 같은 큰 나라다.
  - 꼬리 국가끼리 헷갈려서 틀리는 경우는 3.5% 뿐이다.
- **② 꼬리 국가끼리는 조금 구별된다.**
  - 꼬리 국가 사람인 줄 안다고 치고 12개국 안에서만 고르면 발화 1개 top-1 0.33 이다. 우연은 0.08 이다. 화자 단위(약 9문장 합산)로는 0.46 이다.
  - 녹음 묶음(web040~043)이 정답을 흘려서 생긴 점수만은 아니다. 같은 묶음의 후보 안에서 고르면 0.44 이다. 우연은 0.18, 묶음에서 가장 흔한 나라를 늘 고르면 0.25 다.
- **① 꼬리 국가 사람인지 가려내는 힘은 AUC 0.85 다(화자 단위 0.92). 꼬리가 전체의 1% 라 이 정도로는 모자란다.**
  - 화자 단위로, 꼬리 밖 화자의 1%(21명)를 꼬리로 보내면 꼬리 화자 17명 중 8명이 넘어온다. 그중 꼬리 국가까지 맞히는 사람은 5명이다.
  - 꼬리로 판정한 29명 가운데 21명(72%)은 실제로는 꼬리 밖 사람이다.
- **① → ② 두 단계 판정은 41클래스 꼬리 로짓에 같은 값 b 를 더하는 것과 결과가 같다.**
  - 꼬리 밖 발화를 같은 비율(5 · 10 · 20%)만큼 꼬리로 보내도록 맞추고 비교했다.
  - 꼬리 top-1 은 두 단계 판정이 0.183 / 0.215 / 0.241, b 더하기가 0.183 / 0.215 / 0.234 다.
  - 교차검증 모델에서도 0.104 / 0.143 / 0.184 대 0.104 / 0.143 / 0.188 이다.
  - b 더하기는 결과 31 에서 같은 오경보율로 맞추면 이득이 없었던 그 조정이다.
- **따로 학습하면 나아질까 — 직접 학습해 보지는 않았다. 나아지지 않을 것으로 본다.**
  - ① 이 해야 하는 일은 키르기스스탄 대 우즈베키스탄 · 카자흐스탄 · 러시아, 네팔 · 파키스탄 대 인도, 칠레 대 스페인 · 콜롬비아를 가르는 것이다.
  - 꼬리 국가의 학습 화자가 5~15명인 한, 이 구별은 막힌다. 따로 학습한 모델도 같은 꼬리 화자 99명만 본다.

## 1. 설정

### 1.1 시험 두 가지

| | 300m 전체학습 | 꼬리 화자 교차검증 (결과 33 대조군) |
|---|---|---|
| 모델 | 300m 전체학습 best (step 16k) | 사전학습에서 LoRA 로 학습한 4묶음 모델 · 학습 끝 EMA |
| 꼬리 시험 화자 | test 9명 + valid 8명 = 17명. 학습에 없던 꼬리 화자 전부다 | 묶음마다 빼 둔 꼬리 화자, 합쳐서 78명 |
| 꼬리 시험 발화 | 웹 문장 156개 · 8개국 | 웹 문장 888개 · 11개국 |
| 꼬리 밖 비교 발화 | 같은 split(test · valid)의 꼬리 밖 웹 문장 | 묶음 모델마다 표준 test 의 꼬리 밖 웹 문장 (11,411개) |
| 주의 | valid 화자는 체크포인트를 고를 때 쓴 자료다 | 모델이 약하다. 표준 test 웹 문장 top-1 0.48 이다(300m 전체학습 0.777) |

- **꼬리:** 학습 화자 15명 이하 12개국이다.
  - 화자 3명: 에티오피아 · 방글라데시 · 잠비아 · 르완다
  - 5~7명: 칠레 5 · 타지키스탄 7
  - 11~15명: 파키스탄 11 · 네팔 11 · 투르크메니스탄 12 · 캄보디아 12 · 키르기스스탄 14 · 이란 15
- **점검:** `eval_full300m_interim_step16k` 로짓은 best.pt 로 낸 test 로짓과 같다(최대 차 0). 그래서 valid 로짓도 같은 모델의 것으로 쓴다.

### 1.2 재는 것

- **① 꼬리 국가인가:** 점수 s = logsumexp(꼬리 12개국 로짓) − logsumexp(나머지 29개국 로짓)다.
  - AUC 는 꼬리 발화의 s 가 꼬리 밖 웹 문장의 s 보다 클 확률이다.
  - 문턱은 꼬리 밖 발화의 x% 가 넘도록 잡는다. 교차검증은 묶음 모델마다 따로 잡는다.
  - 화자 단위는 화자마다 s 를 평균해서 같은 일을 한다. 꼬리 밖도 화자 단위로 본다.
- **② 꼬리 안에서 고르기:** 꼬리 12개국 로짓만 남겨서 고른다.
  - 화자 단위는 그 화자 웹 문장의 log 확률을 평균해서 고른다.
- **두 단계 판정:** ① 문턱을 넘으면 ② 의 1위를, 못 넘으면 꼬리 밖 29개국 중 1위를 낸다.
  - 꼬리 밖 발화가 문턱을 넘으면 그 발화는 틀린다.
- 모든 값은 웹 문장(단어 RW 제외)의 국가 평균이다. 구간은 꼬리 화자를 복원추출 1000회 해서 낸 95% 다.

## 3. 해석

- **꼬리가 안 되는 이유는 이웃 나라와 큰 나라에 먹히는 데 있다(①).**
  - 꼬리 국가끼리는 어느 정도 구별한다(②, 우연의 4배 · 같은 녹음 묶음 안에서 2배).
  - 꼬리끼리 헷갈리는 쌍은 키르기스스탄 · 투르크메니스탄 · 이란이 가장 많다.
- **두 단계로 나눠도 ① 의 문턱을 정하는 문제가 남는다.** 이 문턱은 결과 31 의 "꼬리를 얼마나 자주 찍나"와 같은 손잡이다.
  - 꼬리는 전체 발화 · 화자의 약 1% 다. AUC 0.85 ~ 0.92 로는 꼬리로 보낸 사람의 대부분이 꼬리 밖 사람이다.
  - 같은 정보로 만든 두 단계 판정은 41클래스 + b 와 숫자까지 같다(§2.2).
- **① · ② 를 따로 학습한 모델을 직접 확인하지는 않았다.**
  - 확인하려면 교차검증 4묶음에 ① 이진 분류와 ② 꼬리 12개국 분류를 LoRA 로 학습해서 §2 의 표를 다시 내면 된다. GPU 로 2~3시간이다.
  - 다만 두 모델 모두 꼬리 화자 99명(묶음마다 그 일부)만 본다. 새 꼬리 화자 정보가 없다. 그래서 같은 곡선 위의 다른 점이 될 것으로 본다.
- **제품에서 꼬리 국가를 더 자주 보여 주고 싶다면 새 모델은 필요 없다.**
  - 지금 모델의 꼬리 로짓에 b 를 더하면 된다. 예를 들어 화자 단위로 꼬리 밖 화자 1% 를 내주면, 꼬리 화자 17명 중 5명을 맞힌다.
  - 성능 개선이 아니라 어느 쪽 오답을 더 참을지 고르는 일이다.
- **근본 처방은 결과 31 과 같다. 꼬리 국가의 실제 화자 수를 늘리는 것이다.**
  - 몇 명이 필요한지는 화자 수 실험(34)에 있다: 학습 60명이 최소선, 같은 오경보율에서 15명 −0.15 · 30명 −0.12~0.14 · 60명 −0.035.
