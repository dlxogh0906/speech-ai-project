# 29 — 꼬리 올리기: 오버샘플링 · 증강(131 웹음질 · 파형 · CutMix) · 손실 함수 (2026-10-20 ~ 21)

`28_학습안함_LoRA_행균등.md` 에 이어지는 실험이다. 데이터 · 시험지 · 평가 방법은 27 · 28 과 같다.
모든 실험은 28 에서 가장 나았던 **LoRA 이어 · 행 균등**의 설정을 그대로 쓰고, 학습 목록이나 손실만 바꿨다.

**결론: 꼬리는 오버샘플링으로도, 증강으로도 오르지 않았다. 오른 것처럼 보이는 숫자는 꼬리 국가를 더 자주 찍어서 생긴 것이다.**

> 26 ~ 30 의 모든 모델을 300m 전체학습 기준 · 같은 오경보율로 한 표에 모은 것은 `31_꼬리_실험_종합.md` 에 있다.

- **꼬리 (학습 화자 ≤15) — 진짜 이득 없음.**
  - 겉보기 top-5 는 0.089 → 0.141(꼬리 3배) → 0.182(+ 131 웹음질)로 올랐다.
  - 그만큼 다른 나라 발화의 top-5 에도 꼬리 국가가 더 자주 끼었다: 7.8% → 17.3% → 23.0%.
  - 이 오경보율을 모든 모델에서 20% 로 똑같이 맞추면 꼬리 top-5 는 다섯 모델 모두 0.14 ~ 0.16 이다. 차이는 ±0.01 이고 구간이 0 을 포함한다.
  - 같은 효과는 대조군의 꼬리 점수만 올려도 얻는다. 재학습이 필요 없다.
- **중간 (16~100) — 131 웹음질 증강은 진짜 이득이 있다.**
  - 같은 오경보율(50%)에서 LoRA 이어 · 행 균등보다 +0.064 [+0.023, +0.087] 높다.
  - 꼬리 3배만 한 것은 +0.028 [+0.004, +0.051] 로 작다.
- **대가 — 131 웹음질 증강은 한국어 원어민을 외국인으로 찍기 시작했다.**
  - Zeroth 원어민 낭독 top-1 이 0.993 → 0.897 로 떨어졌다(−0.096 [−0.200, −0.019]).
  - 오판은 test 10명 중 2명에 몰렸다. 둘 다 녹음의 4 kHz 위 에너지가 다른 사람보다 10배쯤 많다.
  - valid 의 한국어는 1.000 이라 모델 선택 단계에서 걸러지지 않았다.
  - 한국어 녹음에도 같은 증강을 넣어 봤지만 고쳐지지 않았다. Zeroth top-1 이 0.864 로 오히려 더 떨어졌다(§2.4).
- **"웹음질" 체인은 실제 웹마이크 녹음과 닮지 않았다.**
  - 체인의 저역 통과(2.5~4.5 kHz) 때문에 사본의 4 kHz 위 에너지가 실제 웹 녹음의 1/50 쯤이다. 전화선에 가깝다.
  - 그래서 중간 국가의 이득은 녹음 환경을 맞춰서라기보다 131 녹음을 다양하게 만든 효과로 본다.
- **손실 함수 — 꼬리를 올린 손실은 없다(§5).**
  - focal γ2 는 CE 와 같다. 라벨 스무딩 0.1 은 모든 구간에서 나빠졌다(웹 top-5 −0.036).
  - 로짓 보정 손실(전체 목록)의 웹 전체 top-1 +0.009 는 목록 덕이었다. 같은 목록의 CE 보다는 −0.011 이다. 이 손실은 사후 로짓 보정처럼 머리 정확도를 작은 국가 쪽으로 옮긴다.
  - 화자 적대는 기울기 반전으로는 발산했다. 혼동(KL) 방식은 발산하지 않았지만 화자 정보를 지우지 못했다. 겉보기 중간 top-5 0.775 는 오경보 74% 의 몫이다(§5.7).
- **LoRA 이어 · 행 균등의 같은 오경보율 중간 이득(+0.03 ~ +0.04)은 행 균등 덕이 아니다(§5.7).**
  - 같은 LoRA 를 전체 목록(자연 분포)으로 250스텝만 이어도 300m 전체학습보다 +0.026 · +0.046 이다.
- **파형 증강 · CutMix(이미지 증강의 음성판) — 꼬리는 겉보기만 올랐고, 깨끗한 test 에서는 셋 다 손해다(§6).**
  - 꼬리 top-5 +0.03 ~ +0.09 는 꼬리 오경보가 14% → 19 ~ 25% 로 늘어난 몫이다. 같은 오경보율에서는 일관된 이득이 없다.
  - 웹 전체 top-5 는 −0.013 ~ −0.026, 웹 단어 top-5 는 −0.045 ~ −0.070 이다. CutMix 는 같은 오경보율의 중간도 −0.055 로 낮다.
  - 한국어 원어민 문제는 생기지 않았다(Zeroth 오판 2 ~ 3개).
  - **잡음에도 강해지지 않았다(§6.6).** 파형 증강은 학습에 넣은 합성 잡음(백색 · 분홍)에만 강해졌다. 실제 생활 잡음 · 음악 속 top-1 은 증강 없는 모델과 거의 같고, 말소리 속에서는 낮다.
    CutMix 는 말소리 10 dB 에서 top-1 이 −0.41 떨어진다(증강 없음 −0.27).

수치를 읽는 법:

- **시험지:** test 한 장(`test_koraug_zeroth.csv`, 19,680발화 · 1,390명)이다. 학습 · 선택에는 쓰지 않았다(모두 valid).
- **꼬리 test 는 9명(108발화)이다.** 꼬리 8개국에 대개 1명씩이다. 꼬리 숫자 하나는 사람 한두 명의 결과다.
- **평가:** 모든 모델을 같은 bf16 · 240초 배치로 쟀다.
- **신뢰구간:** 95% 구간은 화자 부트스트랩 1,000회다. 시드는 모델마다 1개다.

### 2.2 같은 오경보율에서 — 더 잘 가려내나, 더 자주 찍나

행 균등 · 오버샘플링 · 사후 보정은 모두 작은 국가의 점수를 올린다. 그러면 그 국가 발화의 적중이 오르지만, 다른 국가 발화의 top-5 에도 그 국가가 더 자주 낀다.
그래서 모델마다 집단 국가의 로짓에 같은 값 b 를 더해 **오경보율**을 똑같이 맞춘 뒤 적중을 견줬다(`scripts/eval/matched_false_alarm.py`).

- **오경보:** 집단 밖 국가 발화(웹 문장)의 top-5 에 집단 국가가 하나라도 낀 비율이다.
- **적중:** 집단 국가 발화의 top-5 에 정답이 있는 비율이다. 국가 평균이다.

## 3. 해석

### 3.1 꼬리 — 행을 늘려도, 소리를 바꿔도 사람은 그대로다

- **늘린 행은 모두 같은 사람들의 것이다.** 꼬리 12개국의 학습 화자는 5 ~ 15명이다. 3배로 늘린 24,192행에 새 화자는 없다.
- **증강은 녹음 환경을 바꾸지 사람을 바꾸지 않는다.** 모델은 여전히 그 몇 사람의 목소리를 외운다. 새 사람의 국적으로는 일반화하지 못한다.
- **그래서 같은 오경보율에서는 차이가 없다.** 꼬리 국가를 가려내는 힘은 대조군과 같고, 점수만 올라갔다.
  - 27 의 손실 가중 ×17 · 행 균등 · 사후 보정 결과와 같은 결론이다. 병목은 화자 수다.
- **제품에서 꼬리 국가를 더 자주 보여 주고 싶다면** 꼬리 로짓에 상수를 더하는 것으로 충분하다. 학습이 필요 없다. 오경보율은 valid 로 고르면 된다.

### 3.2 중간 — 131 웹음질은 효과가 있다

- 중간 국가는 학습 화자가 16 ~ 100명이다. 사람이 어느 정도 있어서, 비율 보정과 증강이 점수 이동을 넘어 표현을 바꾸는 데까지 가는 것으로 본다.
- 131 웹음질은 같은 오경보율에서 LoRA 이어보다 +0.04 ~ +0.06 높다.
  - 중간 국가의 학습 화자 27% 가 131 이다. 131 녹음을 다양하게 만든 효과가 여기서 나온 것으로 본다.
  - 다만 체인이 웹마이크와 닮지 않았다(§2.4 표: 사본 0.0001 · 웹 0.005 안팎). "녹음 환경을 맞췄다"고 보기는 어렵다.
- 머리 국가는 그대로다(+0.002). 웹 전체는 −0.008 이다. 웹 단어는 −0.032 로 잃는다.

### 3.3 무엇을 쓸까

- **지금 고르라면 여전히 LoRA 이어 · 행 균등이다(28).** 꼬리 3배 · 131 웹음질은 중간 · 국가 평균이 더 높다. 하지만 한국어 원어민을 외국인으로 찍는 문제가 있다. 이 문제가 풀리기 전에는 쓸 수 없다.
- 한국어에도 증강을 넣는 것으로는 풀리지 않았다(§2.4). 좁은 대역 체인 대신 웹 녹음과 닮은 증강이 필요하다.

## 4. 주의

- **꼬리 test 는 9명이다.** 국가 하나에 대개 1명이다. 꼬리 칸은 사람 한 명의 12발화로 정해진다.
- **같은 오경보율 비교의 구간은 조건부다.** b 를 고정하고 화자만 다시 뽑았다.
- **학습량이 조금 다르다.** 꼬리 실험은 6만 5천 행 1 epoch(1,706스텝), LoRA 이어는 4만 1천 행 2 epoch(2,210스텝)이다. 다만 세 실험 모두 step 1,000 의 모델이 뽑혔다.
- **시드 1개 · 단일 시험지다.** 0.01 안팎의 차이는 다시 돌리면 뒤집힐 수 있다.
- **고역 비율은 표본으로 쟀다.** 도메인마다 300행이다. 앞 8초의 4 kHz 위 에너지를 전체 에너지로 나눈 값이다. 잡음도 같이 잡힌다.

## 5. 손실 함수

LoRA 이어 · 행 균등의 설정 그대로 손실만 바꿨다. 기준은 같은 설정의 CE(LoRA 이어 · 행 균등)다.

| 이름 (폴더) | 손실 | 학습 목록 |
|---|---|---|
| LoRA 이어 · 행 균등 · focal γ2 (`lora_eq1008_focal2_from_full300m`) | −(1−p)^γ · log p — 이미 맞힌 행의 손실을 줄인다 | 행 균등 · 2 epoch |
| LoRA 이어 · 행 균등 · 라벨 스무딩 0.1 (`lora_eq1008_ls01_from_full300m`) | 정답 0.9 + 나머지에 0.1 을 고르게 | 행 균등 · 2 epoch |
| LoRA 이어 · 전체 목록 · 로짓 보정 손실 τ1 (`lora_full_la1_from_full300m`) | CE(z + τ·log π) — 학습 중에 클래스 비율을 빼고 배운다. 행 균등 목록에선 아무 일도 안 해서 전체 목록에 쓴다 | 전체에서 무작위 9만 행 · 1 epoch |
| LoRA 이어 · 행 균등 · 화자 적대 λ0.3 (`lora_eq1008_spkadv03_from_full300m`) | CE + 같은 나라 안에서 화자를 맞히는 머리에 기울기 반전 — 화자를 외우지 못하게 | 행 균등 · 2 epoch |

**결론: 손실을 바꿔서 꼬리가 진짜로 오른 실험은 없다.**

- **focal γ2 — CE 와 구별되지 않는다.**
  - 웹 전체 top-5 는 +0.001 이다.
  - 같은 오경보율에서 꼬리는 −0.010 ~ +0.021, 중간은 −0.009 ~ −0.018 이다.
- **라벨 스무딩 0.1 — 모든 구간에서 나빠졌다.**
  - valid 가 학습 내내 출발점보다 낮았다. 규칙대로 고르면 학습 전 모델이 된다(§5.1).
  - 학습 끝 가중치는 웹 전체 top-5 −0.036, 웹 단어 top-5 −0.083 이다.
  - 꼬리 top-5 는 +0.068 로 올랐다. 하지만 꼬리 오경보가 14% → 41% 로 뛴 결과다. 같은 오경보율(20 · 25%)에서는 −0.03 ~ −0.05 다.
- **로짓 보정 손실 τ1 (전체 목록) — 행 균등 CE 보다 웹 전체 top-1 이 높지만, 목록 덕이다.**
  - 행 균등 CE 대비 웹 전체 top-1 +0.009 [+0.003, +0.016], 웹 단어 top-1 +0.021 [+0.008, +0.032] 이다.
  - 같은 목록(전체 9만 행)의 CE 와 견주면 웹 전체 top-1 −0.011 [−0.017, −0.006] 이다. 대신 중간 top-5 +0.049, 국가 평균 +0.016 이다(§5.7).
  - 같은 오경보율에서는 중간 50% 에서만 +0.034 [+0.004, +0.059] 이고, 62% 에서는 −0.009 다. 꼬리는 +0.010 ~ +0.016 으로 구간이 0 을 포함한다.
- **화자 적대 λ0.3 — 기울기 반전은 발산했고, 혼동(KL) 방식도 꼬리 · 중간을 올리지 못했다.**
  - 기울기 반전으로 고른 모델은 발산 전인 step 250 이다. 이 방식은 제대로 쟀다고 보기 어렵다.
  - 혼동(KL) 방식은 발산하지 않았다. 하지만 같은 나라 안 화자를 맞히는 정확도가 0.41 → 0.59 로 올라, 화자 정보를 지우지 못했다.
  - 웹 전체 top-5 −0.030, 웹 단어 −0.083 이다. 겉보기 중간 +0.060 은 같은 오경보율에서 −0.013 · −0.004 다(§5.7).
- **한국어 원어민은 네 모델 모두 괜찮다.** Zeroth 오판이 457발화 중 4 ~ 6개다. CE 는 3개, 131 웹음질은 47개다. 혼동 KL 화자 적대는 8개다.

### 5.6 해석

- **focal:** 행 균등 목록에서는 focal 이 CE 에 더해 주는 것이 없었다.
- **라벨 스무딩:** 이미 수렴한 CE 모델에서 이어 학습하기에는 맞지 않는다.
  - 출발 모델은 매우 확신한다. 첫 배치의 라벨 스무딩 손실 2.2 는, 정답과 나머지 클래스의 로짓 차가 평균 23 쯤이라는 뜻이다.
  - 라벨 스무딩 0.1 이 바라는 분포는 그 차가 6 쯤이다. 이 차를 줄이는 동안 처음 250스텝에 valid 가 크게 떨어졌고, 2 epoch 안에 돌아오지 못했다.
  - 꼬리 오경보가 41% 로 뛴 것은, 정답이 아닌 클래스들의 로짓이 서로 비슷해져 top-5 의 2 ~ 5위가 흐트러진 결과로 본다. 라벨 스무딩이 클래스 사이의 닮음 정보를 지운다는 보고(Müller 외 2019)와 맞는다.
- **로짓 보정 손실:** 학습 중에 클래스 비율을 빼고 배운다. 그래서 행 균등처럼 작은 국가를 밀어 주면서도 행을 버리지 않는다(9만 행 · 머리 국가 행도 쓴다).
  - 웹 전체 · 단어 top-1 이 CE(행 균등)보다 높은 것은 머리 국가 행이 더 많아서였다. 같은 목록의 CE 는 더 높다(§5.7).
  - 같은 목록의 CE 와 견주면 머리 정확도를 작은 국가 쪽으로 옮긴 것이다. 사후 로짓 보정과 하는 일이 같다.
- **화자 적대 (기울기 반전):** 화자 CE 는 위로 끝이 없다.
  - 기울기를 뒤집으면 인코더는 화자 헤드를 "헷갈리게"가 아니라 "확신 있게 틀리게" 만드는 쪽으로 간다. 그 값이 끝없이 커지면서 국적 특징까지 끌고 갔다.
  - 혼동(KL) 방식에서는 인코더가 줄이는 값이 0 에서 바닥이 난다. 그래서 이렇게 될 수 없다. 실제로 발산하지 않았다(§5.7).
- **화자 적대 (혼동 KL):** 발산은 막았지만, 인코더가 화자 헤드를 이기지 못했다.
  - 화자 헤드는 매 스텝 새 특징으로 학습한다. 같은 나라 안 화자를 맞히는 정확도가 0.41 → 0.59 로 오른 것은 특징에서 화자 정보가 빠지지 않았다는 뜻이다.
  - λ 0.3 으로는 약했을 수 있다. 다만 λ 를 키우면 국적 특징도 같이 흔들 가능성이 크다. 웹 전체가 이미 −0.030 이다.
  - 꼬리 국가는 학습 화자가 5 ~ 15명이다. 그 몇 사람의 목소리를 지워도 남는 국적 정보가 적을 수 있다. 화자 적대가 꼬리를 올리기 어려운 이유로 본다.

### 5.7 보충 실험 — 같은 목록의 CE 대조군 · 발산하지 않는 화자 적대

| 이름 (폴더) | 무엇을 가리나 |
|---|---|
| LoRA 이어 · 전체 목록 · CE (`lora_full_ce_from_full300m`) | 로짓 보정 손실의 이득이 손실 덕인지 목록 덕인지. 같은 9만 행(같은 시드) · 1 epoch · CE |
| LoRA 이어 · 행 균등 · 화자 적대 혼동 λ0.3 (`lora_eq1008_spkconf03_from_full300m`) | 발산하지 않는 화자 적대가 같은 오경보율에서 꼬리 · 중간을 올리나 |

- **혼동(KL) 방식:** 화자 헤드는 떼어 낸 특징으로 같은 나라 안의 화자를 CE 로 맞힌다. 인코더는 멈춘 헤드를 거쳐 KL(고름 ‖ p) 만 줄인다.
  - p 는 같은 나라 화자들에 대한 헤드의 확률이다. λ 는 기울기 반전 때와 같게 0 → 0.3 으로 올린다.
  - `--spk_adv_mode confusion` 이다. 기본값 `grl` 은 예전과 같다.

**결론: 로짓 보정 손실의 웹 전체 이득은 목록 덕이었다. 혼동 방식 화자 적대는 발산하지 않았지만 꼬리 · 중간을 올리지 못했다.**

- **같은 목록의 CE 는 사실상 출발점이다.**
  - valid 가 거의 오르지 않아 step 250 이 뽑혔다(1.6006, 출발점 1.5995). test 도 300m 전체학습과 같다(웹 전체 top-5 차이 −0.001 [−0.004, +0.001]).

- **로짓 보정 손실 − 같은 목록의 CE:**

- **화자 적대 (혼동 KL) — 발산은 없었지만 화자 정보도 지우지 못했다.**

- crop · speed · gain · eq 는 발화마다 각각 0.5 확률, noise 는 0.3 확률로 건다. 아무것도 안 걸리면 원래 학습과 같다(앞 8초).
- 왜 기대하나:
  - crop: 학습 행의 51% 가 8초보다 길다. 지금은 앞 8초만 본다. 웹 단어 test 는 1.5 ~ 2.9초로 짧은데 학습 행은 대부분 그보다 길다.
  - speed: 목소리가 달라진다(화자 인식에서 "새 화자"를 만드는 방법). 몇 사람을 외우는 지름길을 흔들 수 있다.
  - gain · eq · noise: 녹음 환경 단서를 흐린다. §2.4 의 좁은 대역 체인보다 약하고, 모든 행에 같은 확률로 건다.

  - 실제 잡음에서도 낙폭은 +0.024 ~ +0.040 덜하다. 하지만 깨끗한 조건에서 −0.024 낮게 출발한다. 그래서 잡음 속 절대 성능은 기준과 같다(생활 잡음 ±0.001, 연주곡 +0.016).
  - 말소리 4명에는 오히려 약하다(−0.058). 백색 · 분홍 잡음은 다른 사람 목소리와 닮지 않았다.
- **CutMix 는 모든 잡음에 더 약하다. 말소리에서 가장 크다.**
  - 말소리 4명 10 dB 에서 top-1 낙폭이 −0.413 이다(기준 −0.266). top-5 도 −0.25 떨어진다(기준 −0.13).
  - CutMix 는 다른 사람의 말소리 구간을 붙이고 라벨을 나눠 배운다. 그래서 배경의 다른 목소리도 국적 증거로 쓰게 된 것으로 본다.
- **증강 없는 300m 전체학습(출발점)이 모든 조건에서 가장 높다.** 깨끗 +0.012, 잡음 속 +0.018 ~ +0.053 이다.
  - 행 균등 LoRA 이어(증강 없음)가 출발점보다 잡음에 약해졌다. 합성 잡음 20 dB 낙폭이 −0.107 이고, 출발점은 −0.065 다.
- **top-5 낙폭은 파형 증강이 기준과 ±0.01 안이다.** CutMix 계열은 생활 잡음 10 dB · 연주곡 · 말소리에서 −0.02 ~ −0.13 더 떨어진다.
- 학습에 실제 잡음(MUSAN · 음악 · 말소리)을 넣은 실험은 아직 없다. 실제 잡음 강건성이 목적이라면 그쪽을 재야 한다.

### 6.7 해석

- **꼬리:** 증강은 같은 사람의 소리를 바꿀 뿐이다. 새 사람을 만들지는 못한다.
  - 속도 ±10% 는 음높이 · 포먼트를 바꾼다. 그래도 그 사람의 말투 · 억양은 남는다. 그래서 몇 사람을 외우는 지름길도 남는 것으로 본다.
  - 같은 오경보율에서 차이가 없는 것은 오버샘플링(§3.1) · 손실(§5.6)과 같다. 병목은 여전히 화자 수다.
- **웹 전체 · 단어:** test 는 깨끗한 웹 녹음이다. 증강이 주는 불변성은 이 test 에서 보상받지 못했다. 학습 분포만 test 에서 멀어졌다.
  - 단어가 가장 많이 잃었다. 단어는 출발점(300m 전체학습)에서 멀어질수록 잃는 구간이다. 증강 없는 LoRA 도 출발점보다 −0.038 이고, 증강은 그 위에 −0.045 ~ −0.070 을 더 잃었다.
  - 무작위 자르기는 짧은 단어 test 를 도우려고 넣었는데 돕지 못했다. 문장에서 자른 조각은 따로 읽은 단어와 운율이 다를 수 있다. 확인하지는 않았다.
- **CutMix:** 국적은 발화 전체에 하나다. CutMix 는 두 사람이 이어 말하는 소리를 만들고, test 에는 그런 소리가 없다.
  - 소프트 라벨이 수렴한 모델을 흔든 것(§6.1)까지 더해, 중간 · 131 에서 확실히 낮다.
- **한국어 원어민:** 이번 증강은 대역을 자르지 않는다(음색 ±6 dB · 잡음만). §2.4 의 좁은 대역 체인과 달리 원어민 오판이 늘지 않았다.
  - "체인 자체(저역 통과)가 문제였다"는 §2.4 의 추정과 맞는다. 다만 증명은 아니다.
- **잡음:** 백색 · 분홍 잡음 증강은 백색 · 분홍 잡음에만 강해졌다(§6.6). 실제 잡음과 닮지 않은 증강으로는 실제 잡음 강건성을 사지 못했다.
  - §2.4 의 교훈과 같다. 증강은 실제로 만날 소리와 닮아야 효과가 있다.
- **무엇을 쓸까:** 이번 증강은 어느 것도 쓰지 않는다. 증강 없는 모델이 깨끗한 test 에서 낫고, 실제 잡음 속에서도 같거나 낫다.

## 7. 다음에 해 볼 것

- **웹마이크와 닮은 체인:** 저역 통과를 빼거나 6 ~ 8 kHz 로 올린다. 실제 웹 녹음의 고역 분포에 맞춘다.
- **실제 잡음으로 증강:** `noise_pools`(MUSAN 생활 잡음 · FMA 음악 · Kspon 말소리)를 학습에 섞는다. 깨끗한 행을 더 남긴다(증강 확률 0.2 안팎). §6.6 의 잡음 test 로 잰다.
  - 말소리를 섞을 때는 한국어 말소리만 쓰면 "한국어 배경 = 외국인"이 될 수 있다. 섞는 비율을 한국어 행에도 같게 둔다.
- **valid 선택 기준을 바꾼다:** 지금 기준(웹 top-5 + 국가 평균 top-5)은 작은 국가를 자주 찍는 모델을 고른다(§5.7 · `26_다운샘플링_정리.md` §7.5).
  같은 오경보율의 국가 평균을 쓰거나 웹 top-1 을 넣는다.
- **valid 에 한국어 점검을 넣는다:** Zeroth · Kspon top-1 이 떨어지면 그 모델은 고르지 않는다.
- **꼬리:** 여전히 새 화자를 모으는 것 말고는 수단이 없다. 꼬리를 더 자주 보여 주는 건 사후 상수로 충분하다.
