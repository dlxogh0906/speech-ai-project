- **버그**: 9/24 데모·번들은 게이트가 정규화된 파형을 봤다 → 외국인 1초 발화의 84%, 깨끗한 발화도 약 10점을 Korea 로. 게이트 입력을 raw 로 고쳤다(`KD_GATE_INPUT=raw`, 기본).
- **booth 재학습**(`run_booth`: zeroth 에서 이어서, 군중잡음·폰·짧은 발화 증강): 외국인은 잡음에서 크게 좋아졌지만(0.25→0.47, 오판 33%→6%) **한국인이 나빠졌다**(최저 0.84).
  군중잡음이 한국어 대화라 "한국어 배경 ≠ Korea" 를 배운 것으로 보인다. 부스 목표(한국인)에 반하므로 **채택하지 않는다.** 표준 시험지는 zeroth 와 같다.
- 약한 곳은 한국인의 1초 발화·5 dB 군중잡음(0.98). → 최소 유성 1초(`KD_GATE_MIN_SEC=1.0`), 폰을 입 가까이(20~30 cm).
- 폰 코덱 버그: imageio ffmpeg 4.2.2 가 iPhone Safari MP4 를 첫 1초만 읽었다 → 시스템 ffmpeg 6.x 사용(번들 README 에 "ffmpeg ≥5 필수").
