# 45 — 파형과 mel 을 같이 입력: 자기 어텐션 융합 (2026-10-29)

질문(사용자): "입력을 여러 개로 받으면 — 음성(파형)도 받고 mel 도 받고 — 성능이 오르지 않나. self attention 으로 같이 학습해 보자. 300m XLS-R 로."
이번에 한 것: 대조군과 같은 이어 학습에, 같은 파형에서 만든 로그 mel 줄기와 자기 어텐션 융합을 붙였다. 두 갈래다.
- mel + XLS-R: XLS-R 프레임과 mel 프레임을 한 시퀀스로 이어 자기 어텐션을 태운다. 두 입력이 서로를 본다.
- mel 만: mel 프레임만 같은 어텐션에 태운다. 두 입력을 섞는 몫과 mel 정보만 더한 몫을 가르는 대조다.

**결론: 안 오른다. 두 갈래 모두 대조군과 같다. 모델이 mel 칸을 거의 쓰지 않는다.**

- **웹 · 131 · 문장 전체: 차이 없음.**
  - 웹 top-1 · top-5, 문장 top-5, 131 top-5 의 차이는 모두 ±0.004 안이다.
  - 조금 잃은 칸이 있다. mel 만(valid 선택)의 웹 top-1 은 −0.004 [−0.007, −0.001] 이다. 학습 끝 EMA 의 웹 단어 top-5 는 −0.003 · −0.005 다.
- **꼬리 (학습 화자 ≤15): 이득으로 볼 수 없다.**
  - 같은 오경보율로 맞추면 test 에서 +0.010 ~ +0.047 이다. 하지만 구간 아래 끝이 모두 0 이다. test 꼬리는 9명 · 108발화뿐이라, 발화 한두 개 차이다.
  - valid(8명 · 48발화)에서는 모든 칸이 0 이다. mel 만(valid 선택)의 오경보 10% 칸 하나만 −0.048 이다.
  - VC(33) · SAA 영어(39) · 운율(42)과 같은 모양이다. test 에서만 조금 보이고 valid 에서 재현되지 않는다.
- **중간 (16~100): 차이 없음.**
  - test 학습 끝 EMA 는 −0.012 ~ +0.006 이고 구간이 모두 0 을 낀다.
  - mel + XLS-R(valid 선택)의 오경보 40% 칸은 −0.022 [−0.045, −0.002] 로 오히려 낮다.
- **mel 칸은 거의 쓰이지 않는다.**
  - 헤드에서 mel 256칸의 가중치 크기 중앙값이 원래 1,024칸의 0.05 ~ 0.06 배다.
  - 운율 궤적 입력(42)의 0.06 과 같은 수준이다.
- **두 입력을 섞는 몫은 없었다.** mel + XLS-R 와 mel 만이 같은 결과다. 어텐션으로 서로 보게 해도, mel 만 따로 더한 것보다 나은 점이 없다.

## 4. mel 칸을 얼마나 쓰나

헤드 입력은 모두 표준화돼 있다. 원래 칸은 μ/σ 로, mel 칸은 LayerNorm 으로 맞췄다. 그래서 칸별 가중치 크기(41개 출력에 대한 노름)를 견줄 수 있다.

| 갈래 | 원래 1,024칸 중앙값 | mel 256칸 중앙값 | 비 (valid 선택 · EMA) |
|---|--:|--:|--:|
| mel + XLS-R | 1.003 · 1.005 | 0.053 · 0.054 | 0.05 · 0.05 |
| mel 만 | 1.002 · 1.005 | 0.061 · 0.060 | 0.06 · 0.06 |
| (참고) 42 운율 궤적 128칸 | 1.000 · 1.003 | 0.061 · 0.061 | 0.06 · 0.06 |

- 새 칸은 0 에서 시작해 2,210 step(헤드 lr 1e-3) 동안 배운 만큼이다.
- 이 학습에서 mel 쪽 신호는 분류를 거의 바꾸지 못했다. "mel 에 정보가 없다"와 "짧은 학습이라 다 못 배웠다"를 이 실험만으로 완전히 가를 수는 없다.

## 5. 읽기

- **사투리에서는 mel 이 통했는데 국적에서는 안 통한 이유:**
  - 사투리에서 mel 모델(EAT)은 혼자서도 강했다. 봉인 test 0.940 으로 XLS-R 2B(0.942)와 같았다. 그래서 합치면 0.960 이 됐다.
  - 국적에서는 mel 계열이 혼자서 약하다. 10-17 백본 비교(학습 안 함)에서 EAT 0.385, XLS-R 300m 0.490 이었다.
  - 보탤 정보가 적은 줄기는 섞는 방식(앙상블 · 이어 붙이기 · 자기 어텐션)을 바꿔도 크게 보태지 못한다.
- **XLS-R 은 이미 주파수 정보를 본다.** 파형에서 직접 합성곱 필터를 배운다. 손으로 만든 mel 이 따로 줄 몫이 작다. 운율(41 · 42)에 이어 스펙트럼도 같은 답이다.
- **꼬리는 여전히 화자 수 문제다(27 · 34 · 35).** mel 줄기도 같은 5~15명만 보므로 그 병목을 풀지 못한다.
