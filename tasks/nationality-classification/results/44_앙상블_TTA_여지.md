# 44 — 국적 모델 앙상블 · TTA 로 더 오를 여지 (2026-10-26)

질문: "국적 분류 모델도 TTA 나 앙상블 시 성능 향상의 여지가 있나."

이미 있는 test 로짓으로 앙상블을 계산했다. 새로 학습하지 않았다. 모델마다 log-softmax 를 같은 가중치로 평균했고, 가중치를 test 로 고르지 않았다. TTA 는 지금 모델(300m 전체학습)로 test 전체 19,680발화에 변형 6가지를 돌려 쟀다(GPU 약 7분, 결과 21 과 같은 변형).

**결론: 여지는 있지만 작다. 앱처럼 문장 여러 개를 합산하면 대부분 사라진다. 계산량은 모델 수만큼 는다.**

- **앙상블**
  - 300m + 2B 는 발화 1개 top-1 +0.018 [+0.014, +0.023], top-5 +0.007 [+0.004, +0.010] 이다.
  - 셋(300m + 2B + LID 초기화 300m)이면 +0.020 · +0.008 이다.
  - 같은 화자 3문장 합산에서는 +0.007 ~ +0.011 로 준다. 앱 기본 흐름(3 · 5문장 합산)에서 기대할 몫은 1%p 안팎이다.
  - 2B 는 CPU · NPU 서빙이 무겁다(그래서 KD 로 300m 을 만들었다). 300m 두 개(300m + LID 초기화 300m)는 계산 2배에 +0.010 · 3문장 +0.006 [+0.000, +0.012] 이다.
- **TTA (지금 모델, test 전체)**
  - 속도 · 잡음 · 구간 6가지 변형을 평균하면 발화 top-1 +0.011 [+0.007, +0.015], top-5 +0.001 [−0.001, +0.003] 이다. 계산은 6배다.
  - 3문장 합산 뒤에는 +0.006 [−0.000, +0.012] 로, 0 보다 높다고 하기 어렵다.
  - 작은 나라는 조금 잃는다. 국가 평균 top-5 0.661 → 0.651, 중간 국가 0.590 → 0.563, 꼬리 0.089 → 0.068 이다.
  - 변형 하나만 넣으면 모두 원본보다 낮다(top-1 −0.008 ~ −0.023). 여러 개를 평균해야 조금 오른다.
  - 단어(2~3초)는 조금 더 오른다(0.296 → 0.317). 짧은 발화의 흔들림을 평균이 줄이는 것으로 보인다.
  - 같은 비용이면 다른 문장을 더 읽게 하는 편이 훨씬 크다. 결과 21 에서 문장 2개 합산은 +0.065, 4개는 +0.091 이었다. TTA 는 같은 녹음을 비튼 것이라 새 억양 정보가 없다.
- **학습 끝 EMA 체크포인트는 추가 비용 없이 top-1 +0.015 [+0.008, +0.022] 다. 대신 작은 나라를 잃는다.**
  - 중간 국가 top-5 0.590 → 0.476, 꼬리 0.089 → 0.036, 발화 top-5 −0.005 다. 학습을 더 하면서 큰 나라 쪽으로 기운 것이다.
  - 머리 국가만 보면 이득이고, 나라 고루 보면 손해다.
- **어느 쪽도 꼬리를 올리지 않는다.** 앙상블 · TTA 의 꼬리 top-5 는 0.068 ~ 0.089 로 기준(0.089)보다 같거나 낮다. 결과 34 의 결론(병목은 화자 수) 그대로다.

## 3. 읽기

- **앱에 넣을 가치가 가장 큰 순서**: 문장 더 읽히기(무료에 가깝고 +6~9%p) ≫ 앙상블 300m + 2B(+1.8%p, 합산 뒤 +0.7%p, 2B 서빙 비용) > TTA 6가지(+1.1%p, 6배, 합산 뒤 +0.6%p) ≈ 300m 두 개 앙상블(+1.0%p, 2배, 합산 뒤 +0.6%p).
- 앱은 이미 3 · 5문장을 합산하므로, TTA 를 붙여 얻는 몫은 1%p 미만이고 계산은 6배다. 권하지 않는다.
- 앙상블 · TTA 는 꼬리 국가 문제를 풀지 못한다. 모국어가 같아 늘 같은 쪽으로 틀리는 4개국(말레이시아 · 페루 · 콜롬비아 · 불가리아, 14명)은 TTA 로 top-1 이 0.250 → 0.143 으로 내려갔다(결과 21 ② 마지막 열).
- 학습 끝 EMA 를 서빙 모델로 바꾸는 건 비용 없는 선택지다. 다만 중간 · 꼬리 국가를 잃으니 "머리 국가 top-1 이 우선"일 때만 권한다.
