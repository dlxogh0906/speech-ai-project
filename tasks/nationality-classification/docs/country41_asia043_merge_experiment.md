## 2. 왜 이 실험인가

- ⑧까지의 best는 평가가능 클래스가 34/41. **이란·파키스탄·방글라데시·싱가포르 등 7개
  클래스는 화자가 없어 평가 자체가 불가**했고, 인도(top5 0.04)·키르기스(0.02)·타지크(0.0)
  등은 사실상 죽어 있었다.
- ③의 교훈("알고리즘이 아니라 화자를 늘려야")과 ⑧의 교훈("양보다 포맷 정합 — 문장만")을
  그대로 적용할 새 재료로 **043 데이터셋**(아시아어 사용자 한국어 발화, 웹 녹음)을 도입.
- **⑥의 실패를 반복하지 않기 위한 핵심 설계 = 선별 병합**: 043 발화의 85%는
  인도네시아·베트남인데 이들은 이미 top5 0.88/0.99라, 전부 병합하면 잘되는 클래스에
  다른 도메인 데이터를 붓는 ⑥형 회귀 위험만 있다. → **저성능/평가불가 14클래스만** 채택.

## 4. 실험 설계

- feature: frozen XLS-R 2B, **layer 31** mean-pool, max_sec 12s, clamp[-50,50], fp16 저장
  (기존 캐시와 완전 동일 규격; `$SPEECH_AI_DATA/taeho_layers_asia/train.npz`, 19,689×3×1920).
- 학습: `merge_country41_euro.py --euro 1 --euro_sent_only 1 [--asia043 1]`,
  linear head, AdamW lr 1e-3, 60ep, valid macro5로 best 선택, seed 42.
- split: 화자 단위 label-stratified 8:1:1 (seed 42). **043 화자 추가로 전역 재배정이
  일어나므로**, (A) 병합 전 재실행(재현 확인용)과 (B) +043을 같은 세션에서 함께 실행.
- (A)는 저장된 ⑧ best와 **소수점까지 동일 재현** (micro 0.9496/macro 0.6754) → head A ≡ ⑧ best.

### 5-2. micro 하락(-0.0074)의 정체 = 시험범위 확대

- B에서 신규 043 test 발화(2,609개)만 제외하면 micro top5 = **0.9505 > A의 0.9496**.
- B의 블록 성능을 A의 시험 구성비로 재가중해도 **0.9508**.
- 역으로 옛 모델에게 B의 혼합 시험지를 주면 (133,509×0.9496 + 2,609×0.2844)/136,118 = **0.9369 < 0.9422**.
- → **기존 시험범위에서는 B가 우세. 하락분은 전부 "새 문항 편입" 효과.**

### 5-3. macro 하락(-0.043)의 정체 = 분모효과

## 6. 043 블록이 0.518에 그친 이유 (해부, §9 anatomy.json)

- **H1 학습화자수 병목 — 주원인 (지지)**: Spearman(train화자수, top5) = **+0.72**.
  train 화자 ≥57 (우즈벡 107·카자흐 57) → top5 0.92/0.81. ≤23 클래스는 전부 ≤0.48.
  0.518은 "잘되는 우즈벡·카자흐(1,001행)" + "붕괴한 저화자 클래스(1,608행)"의 혼합평균.
- **H4 화자단위 붕괴 (지지)**: test 34화자 top5 분포가 쌍봉 — ≥0.8이 11명(우즈벡·카자흐),
  <0.2가 11명(전원 저화자 클래스). 실패는 발화가 아니라 **화자 단위** = ③의
  speaker-disjoint 일반화 병목 재현.
- **H2 발음과제 탓 — 기각**: 문장과제 0.527 vs 발음문장 0.504 (Δ0.023, 방향도 클래스별
  혼재). 발음과제 문장 포함 결정은 유효. 길이 자체는 완만히 유효(<4s 0.447 → ≥12s 0.567).
- **H3 혼동 구조 (지지)**: 오분류는 ①언어·지리 인접 대형클래스로 흡수
  (파키스탄→인도 23%, 타지크→우즈벡 37%, 네팔→인도 33%, 이란→튀르키예 31%),
  ②웹도메인 대형클래스 prior 쏠림(방글라→스페인 47%, 말레이→스페인 32%).
  칠레·필리핀의 진짜 하락(−0.09/−0.06)도 같은 메커니즘(새 이웃에게 확률질량 잠식)으로 해석.

## 7. 결론

1. **0704_country41_sent043를 새 best로 채택.** 같은 조건 비교에서 전 시험지 우세
   (old-test macro +0.082, 043-test top5 +0.233), 부작용은 극소화자 2클래스(칠레·필리핀)뿐.
2. 선별 병합 전략(잘되는 클래스는 안 건드림)이 ⑥형 회귀를 막았다 — 505 블록 0.9615→0.9640.
3. 이란(총 14명)·파키스탄(10명)이 0.16~0.26에 머무는 것은 **방법이 아니라 데이터 한계**.
   043의 해당 국적 화자를 전부 넣고도 이 수준 — 개선하려면 화자 추가 수집뿐.
4. 남은 평가불가 4클래스: **에티오피아·르완다·잠비아**(아프리카 — 3개 데이터셋 모두 부재),
   **싱가포르**(1화자 → train 전용). "아시아권 데이터셋으로 아시아권은 해결, 아프리카는
   미해결" 예측이 그대로 실현.
5. 배포 처방: 화자 <5명 클래스(방글라데시·싱가포르·키르기스 등)는 deploy에서 drop
   또는 "불확실" 처리 권장 (0.0~0.2짜리 예측을 노출하지 않는 것이 낫다).
