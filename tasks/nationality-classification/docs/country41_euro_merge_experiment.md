# 41클래스 국적 분류 — 기존(505) vs 신규 유럽(041) 데이터셋 병합 실험

> ⚠️ **비교 조건 caveat (상단 고지)**: baseline과 merged는 **완전히 동일한 split이 아님.** speaker-disjoint 8:1:1(seed 42)을 각 실험의 데이터 풀(baseline=505+한국어, merged=505+한국어+041) 위에서 따로 수행하므로, 505 test에 포함되는 화자 구성이 두 실험에서 다름. 따라서 전체 micro 수치의 직접 비교는 **동일 test 비교가 아님** — 6장에서 출처별로 분해해 해석함.

> ⚠️ **표본 caveat**: test 화자 1~2명 또는 test 발화가 극소수인 클래스의 top1/top5는 통계적으로 신뢰할 수 없음(아래 표에서 `*` 또는 ‘해석 주의’로 표시).

> ⚠️ **용어**: 두 데이터셋 차이는 ‘아시아 vs 유럽’이 **아니라** **505(스튜디오 낭독) vs 041(online 웹마이크)** 의 녹음환경 차이임 (505에도 유럽 국적자 존재).

---

## 1. 실험 개요

- **과제**: 외국인의 한국어 발화로 **국적 41클래스** 분류 (40개 국가 + 한국어 모국어 화자).
- **기존 데이터셋**: 505 ‘외국인 한국어 발화 음성’ (전세계 외국인, 스튜디오 낭독).
- **신규 데이터셋**: 041 ‘교육용 유럽어 모국어 사용자 한국어 음성’ (유럽어권, online 웹마이크).
- **모델 파이프라인**: frozen XLS-R 2B → **layer 31 mean-pooling** feature → **linear probe** (인코더 미세조정 없음).
- **split**: speaker-disjoint **8:1:1**, seed 42, label-stratified.
- **병합 방식**:
  - 041의 `nationality` 필드를 기존 40개 국가 라벨에 매핑, **기존 41클래스에 없는 국적은 drop.**
  - 041 화자 ID에 **`EU_` prefix** → 505 화자 ID와 충돌 방지.
  - 한국어 및 041에 없는 아시아권 클래스(중국·일본 등)는 기존 데이터 그대로 유지.
  - **41클래스 중 20개에 041 데이터가 합쳐짐**, 나머지 21개(한국어 + 20개)는 데이터 불변.

- 분모: 94,427+52,606+14,999 = **162,032** = merged 전체 test_n **162,032** → 일치 ✅

## 9. 결론 및 다음 실험 제안

### 핵심 결론
- **도움이 된 클래스**: 화자가 대폭 늘어난 스페인·이탈리아·독일·프랑스·튀르키예 등은 top5가 크게 상승하고, 루마니아·불가리아 등 5개는 **처음으로 평가 가능**해짐.
- **저하/혼동 클래스**: 우즈베키스탄·영국·미국 등 기존에 잘 되던 클래스는 041 유입 후 하락 (출처 도메인 혼동 + 유사 악센트 경쟁).
- **기존 505 성능은 실제로 유지됨** (505 test top5 0.9575→0.9587). 전체 micro 하락은 ‘성능 저하’가 아니라 **어려운 041(online) test가 추가된 구성 변화**.
- **신규 online 데이터 성능 수준**: 041 test top1 ≈ **0.455**, top5 ≈ **0.818**. 배포 환경이 웹(online)이라면 이 수치가 **실제 배포 정확도에 더 가까움**.
- **극소수 화자 클래스의 한계**: 병합해도 칠레·타지키스탄·투르크메니스탄·콜롬비아 등은 test 화자 1~3명이라 **통계적으로 평가 불가/무의미**, top1 ~0.

### 한계점
- baseline과 merged의 split이 **완전히 고정되지 않음** (각 풀에서 재stratify) → 동일 test 비교 아님.
- test 화자 1~2명 클래스의 수치는 신뢰 불가.
- 505(스튜디오) vs 041(online) **녹음환경 차이**가 성능 분해의 핵심 교란 요인.
- **frozen feature + linear probe** 구조라 도메인 불변/유사 악센트 분리 학습이 구조적으로 불가.

### 다음 실험 우선순위
1. **극소수 화자 클래스 유지/drop 기준 수립** (예: 병합 후 test 화자 ≥ 5 또는 train 화자 ≥ 10) → 클래스셋 확정 후 **split 동결.**
2. **online 도메인 대응 audio augmentation** (505에 코덱/노이즈/대역제한 추가로 online 근사).
3. **domain-balanced / class-balanced sampling** 으로 출처·클래스 쏠림 완화.
4. **XLS-R encoder 부분 fine-tuning 또는 LoRA** (frozen 한계 돌파 — 도메인 불변 + 유사 악센트 분리).
5. **domain-adversarial learning / domain-invariant representation** 실험.
6. **505↔041 cross-domain 평가** (505로 학습→041로 평가, 반대도) 로 도메인 전이력 측정.
