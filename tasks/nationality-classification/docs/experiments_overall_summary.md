# 외국인 한국어 발화 국적/모국어 분류 — 실험 종합 정리 (인수인계용)

작성: 2026-06-26 · 인코더: XLS-R 2B · 클래스: 62 (외국어 61 + 한국어) · split: **speaker-disjoint** · feature: 12s mean-pooled
공통: 별도 표기 없으면 split = `feature_resplit_61_merged6_seed42_target_counts`, 지표 = **foreign 61-way**(한국어 제외)

> **한 줄 결론:** frozen 표현 위 모든 시도(decoupling·불균형처리·증강)가 **macro-F1 ~0.19**에서 막힘. 인코더 partial finetune도 (top-5 기준) frozen 동급·과적합. 근본 원인 = **소수 클래스의 학습 화자 수 부족.**

## 0. 지표 정의 (혼동 금지)
- **probe/decoupling/증강**: `macro-F1`, `top1`(=정답률), `top5`. 버킷 = 클래스를 **train 화자 수**로 나눔(head/mid/few 또는 A/B/C/D).
- **finetune**: `macro/micro **top-5**` (← F1 아님). frozen top-5 베이스라인(macro 0.498 / micro 0.93)과 비교.

## 5. 핵심 발견 — 성능 = "학습 화자 수"

per-class 분석: top1을 가르는 건 발화 수가 아니라 **train 화자 수**.

| train 화자 | top1 |
|---|---|
| ≥100 (중·일·베·태·영어·한국어) | 60~100% |
| 20~55 (몽골·미얀마·우즈베크·러시아·말레이·인니) | 26~85% |
| ~10~30 (스페인·광동·터키) | 10%대 (top5는 생존) |
| ≤3 | 거의 0% |

증거: **투르크멘어(발화1346/화자1)·키냐르완다어(605/화자1)·우르두어(504/화자1) → 전부 top1 0%.** 발화 많아도 화자 1명이면 새 화자(test)에서 0%. → macro 0.19의 근본 원인 = **화자 다양성 부족.**
