# 유럽 데이터셋(041) 합치기 실험 — 41클래스 국적 분류

## 1. 실험 개요

기존 **41클래스(40개국 + 한국어)** 국적 분류 모델에 **새 데이터셋(유럽어 모국어 화자)** 을
합쳤을 때 성능이 어떻게 변하는지 검증.

- **목적**: 기존 데이터에서 화자가 1~4명뿐이라 학습 불가였던 유럽/비아시아 국가
  (스페인·루마니아·콜롬비아 등)를 유럽 데이터로 보강하면 살아나는지 확인.
- **방법**: 동일 파이프라인(frozen XLS-R 2B, layer-31 mean-pool feature, linear probe).
  새 클래스 추가 없이 **기존 40개국에 해당되는 국적만 합치고 나머지는 drop**.

### 데이터셋
| | 기존 (505) | 추가 (041) |
|---|---|---|
| 정식명 | 외국인 한국어 발화 음성 | 교육용 유럽어 모국어 사용자 한국어 음성 |
| 성격 | 전세계 외국인 (아시아 비중 큼) | 유럽어권 화자 |
| 녹음 | 스튜디오 낭독 | **online(웹마이크)** |
| 발화수 | 102만 | 71만 (40클래스 해당분 45.7만, 나머지 25만 drop) |
| 한국어 | 별도 추가 (300화자 15만) | — |

### 합치는 방식
- **한글 국가명 문자열로 병합** (예: 505의 "러시아" + 041의 "러시아" → 같은 클래스).
- 041은 `nationality` 필드 → 40개국 매핑, 화자ID에 `EU_` prefix(충돌 방지).
- **41클래스 중 20개에 유럽 데이터 합쳐짐**, 21개(한국어 + 아시아전용 20개)는 데이터 그대로.
- speaker-disjoint 8:1:1 split (seed 42), 모든 split에 두 도메인 혼재.

### split 구성 (합친 후)
> 용어: **기존(505)** = 외국인 한국어 발화 음성(스튜디오) / **신규(041)** = 유럽어권(online).
> "아시아 vs 유럽"이 **아니라** "어느 데이터셋/녹음환경에서 왔나"의 구분임 (505에도 유럽 국적자 있음).

| split | 발화 | 화자 | 기존(505) / 신규(041) 발화 |
|---|---|---|---|
| train | 1,186,440 | 2,686 | 834,035 / 352,405 |
| valid | 148,161 | 674 | 95,567 / 52,594 |
| test | 147,033 | 674 | 94,427 / 52,606 |

## 2. 전체 성능 변화

| 지표 | baseline (asia+한국어) | merged (+유럽) | Δ |
|---|---|---|---|
| micro top1 | 0.833 | 0.716 | **−0.12** 🔴 |
| micro top5 | 0.963 | 0.917 | **−0.05** 🔴 |
| macro top1 | 0.356 | 0.348 | −0.01 |
| macro top5 | 0.578 | **0.608** | **+0.03** 🟢 |
| test 등장 클래스 | 29/41 | **34/41** | +5 |

> **micro 하락 / macro top5 소폭 상승 / 측정가능 클래스 5개 증가.**
> 전형적인 "롱테일 살리고 헤드 깎는" 트레이드오프.

### ⚠️ micro 하락은 "성능 저하"가 아님 — test set이 바뀐 것 (도메인 분해)
baseline top5(0.963)는 **기존(505) test만**, merged top5(0.917)는 **기존(505)+신규(041) test** 점수.
신규(041) 5.3만개가 더 어려워서(online) 평균을 끌어내린 것 — 같은 데이터로 보면 변화 없음.

| test 출처 | baseline 41 | merged 41 |
|---|---|---|
| **기존(505)** micro top5 | 0.9575 | **0.9587** (그대로) |
| **한국어** micro top5 | 1.0000 | 0.9995 (그대로) |
| **신규(041)** micro top5 | (없음) | **0.8183** (새로 확보) |
| 전체 micro top5 | 0.9631 | 0.9169 |

> 즉 **기존 데이터 성능은 안 깎임.** 합치기 = "기존 0.958 유지 + 신규(041)를 0.818 top5로 새로 커버".
> 검산: (94,427×0.959 + 52,606×0.818 + 14,999×1.0)/162,032 = 0.917 ✅

## 4. 핵심 발견 & 해석

1. **합치면 다 좋아지는 게 아니다 — 트레이드오프다.**
   - 죽어있던 유럽 클래스(스페인·이탈리아·독일·프랑스 등) 12개 향상 + 5개 부활.
   - 대신 깨끗한 아시아 클래스(우즈벡·영국·미국·필리핀·네팔 등)는 하락.
   - 전체 macro top5만 +0.03, micro는 −0.05.

2. **하락의 원인 = 데이터셋(녹음환경) 차이 — 기존(505,스튜디오) vs 신규(041,online).**
   - 같은 국적이라도 출처 데이터셋으로 갈림: 미국 505: 0.53 vs 041: 0.00, 독일 505: 0.93 vs 041: 0.40.
   - 모델이 악센트가 아니라 **녹음환경/데이터셋**을 부분적으로 학습 → 소수 출처 쪽을 틀림.
   - **도메인 정규화(평균/스케일/whitening) 모두 시도했으나 격차 안 줄어듦** → affine 변환의 한계.

3. **신규(041) test top1 ≈ 0.45 (online).** 배포가 웹녹음(online)이므로,
   **실제 배포 정확도는 기존(505,스튜디오) 숫자(0.83)보다 이 0.45에 가까움** (현실 직면).

4. **방법론 감사 통과 (test 규칙 위반 없음)**: 화자 disjoint(train∩valid∩test=0), 매니페스트
   중복 0, 505/041 화자ID 충돌 0, 한 화자 다중라벨 0, 표준화는 train만, best epoch은 valid로 선택,
   feature는 양쪽 모두 layer-31. **단 caveat**: ① 505 test가 두 실험에서 완전 고정은 아님(재stratify),
   ② 화자 1~2명 클래스(칠레·타지키·투르크멘) 숫자는 통계적으로 무의미.

4. **여전히 화자 부족한 꼬리는 못 살림.** 칠레(1명)·투르크멘(2명)·콜롬비아(3명) 등은
   유럽 합쳐도 top1 ~0.

## 5. 결론 & 다음 스텝

- **단순 병합은 순이득 아님.** 롱테일(macro)엔 소폭 이득, 헤드(micro)엔 손해.
- 한국어 분류는 영향 없음 (1.00 유지).
- 개선 방향:
  1. **화자 극소수 꼬리 클래스 drop** (칠레·타지키·투르크멘·콜롬비아 등) → macro 정리.
  2. **인코더 fine-tune** (LoRA/부분) → 도메인 불변 + 닮은 악센트 분리 (근본 해결).
  3. **오디오 도메인 매칭** (아시아에 online 노이즈 augment) → 도메인 격차 완화.

### 실험 설정 (재현용)
- feature: frozen XLS-R 2B, **layer 31** mean-pool, max_sec 12s, clamp[-50,50], fp16
- probe: linear head, AdamW lr 1e-3, 60 epoch, valid macro-top5로 best 선택
- split: speaker-disjoint 8:1:1, seed 42, label-stratified
- 스크립트: `scripts/merge_country41_euro.py` (`--euro 0/1`)
