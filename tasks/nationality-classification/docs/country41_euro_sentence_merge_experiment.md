# 41클래스 국적 분류 — 505 vs 041(문장만) 병합 실험

> ⚠️ **비교 조건 (상단 caveat)**: baseline/merged는 **완전히 동일한 split이 아님**(각 데이터 풀에서 speaker-disjoint 8:1:1 seed 42를 따로 수행). 따라서 전체 Δ는 split 영향이 섞임 → **8-1에서 동일 505 화자 test로 동결 재평가**한 값을 함께 제시. 또한 **seed 노이즈 플로어(8-2) ±0.05 미만 Δ는 노이즈로 간주.**

> ⚠️ **용어**: 두 데이터셋 차이는 ‘아시아 vs 유럽’이 아니라 **녹음환경(모바일16k vs 웹48k)·과제(문장 vs 단어)·발화길이(12.6s vs 1~5s)** 미스매치임. (505에도 유럽 국적자 존재)

> ⚠️ **문장 필터 정의**: 041 발화 중 prompt **단어 수 ≥ 4** 인 것만 ‘문장’으로 사용. 필터 후 **화자 커버리지 95~100% 유지**(클래스 안 죽음), **발화 수만 37%로 감소**(171,241/457,607).

---

## 0. TL;DR
- **macro top5**: baseline **0.5775** → 혼합 **0.6076** → **문장 0.6754** (문장이 best).
- **micro top5**: baseline **0.9631** → 혼합 **0.9169**(↓) → **문장 0.9496**(회복).
- **micro top1**: 0.8326 → 0.7160 → **0.7981** / **macro top1**: 0.3560 → 0.3477 → **0.3952**.
- **505·한국어 성능은 세 조건 모두 유지** (병합이 기존을 깎지 않음). micro ‘하락’은 어려운 041 발화가 분모에 추가된 구성 변화.
- **041은 단어를 빼고 문장만 쓰는 게 명확히 best** — 거의 모든 유럽 클래스 향상(불가리아 +0.36, 브라질 +0.31 등).
- **도메인 갭은 녹음/화자가 지배**(문장끼리 맞춰도 cross-domain은 +0.07만 회복).
- **극소수 화자 클래스(칠레·타지키 등)는 평가 불가** → 다음 단계 drop 대상.

## 1. 실험 개요 + 데이터셋 실측 메타
- **과제**: 외국인 한국어 발화 기반 **국적 41클래스(40개국 + 한국어)** 분류.
- **모델**: frozen XLS-R 2B → **layer 31 mean-pool** → linear probe. split=speaker-disjoint **8:1:1**, seed 42.
- **병합**: 041 `nationality`→기존 40국 매핑, 외 국적 drop, 041 화자ID에 `EU_` prefix.
- **문장 필터**: 041 발화 중 **prompt 단어 수 ≥ 4** 만 사용(마스크 `sent_mask_ge4.npy`).

## 9. 결론 및 다음 실험
### 핵심 결론
1. **505·한국어 성능 유지** (동결 test 505 0.9575→0.9587, 한국어 1.0). micro ‘하락’은 어려운 041 추가일 뿐 저하 아님.
2. **041 단어 데이터는 국적분류에 유해 → 문장(≥4)만 쓰면 best**: macro top5 0.578→**0.675**, micro 0.917→**0.950**, 유럽 클래스 대부분 향상.
3. **도메인 갭은 녹음(모바일16k vs 웹48k)·화자 지배** (문장 맞춤은 +0.07만). 같은 도메인 내부는 매우 잘 됨(041문장 0.906).
4. **극소수 화자 클래스(칠레·타지키·키르기스·투르크멘·콜롬비아)는 평가·학습 불가** — top5 ~0.
5. **v1의 일부 하락(우즈벡 등)은 split 운** — 동결 test로 정정. 단 영국·미국·필리핀·네팔은 진짜 하락.
### 한계점
- baseline/merged **split 미고정**(8-1 동결로 보완), 노이즈 플로어 ±0.05.
- **505=모바일/문장, 041=웹/단어 → 배포(웹+자연발화)는 둘 다와 다름** → 현재 0.95대는 낙관적, **실배포 추정치는 041 문장 블록(top5 ~0.87) 수준**.
- frozen feature + linear: 도메인 불변/유사악센트 분리 구조적 불가.
### 다음 실험 우선순위
1. **꼬리 클래스 drop 기준 수립**(예: 병합 후 train 화자 ≥10) → 클래스셋 확정 + **split 동결** (041 블록↑ → micro/macro 추가 상승).
2. **041은 문장(≥4)만 사용 확정** (재추출 불필요, 마스크 `sent_mask_ge4.npy`).
3. **녹음-매칭 augmentation** (505에 웹/대역제한) — 격차가 녹음 지배라 유망.
4. **encoder fine-tune(LoRA) + domain-adversarial** — frozen 한계 돌파.
5. **domain-invariant representation** 실험.
6. **배포(웹) 평가셋 소량 수집** — 유일하게 의미 있는 지표 확정.
7. **505↔041 cross-domain 정기 추적**.
