# XLS-R 외국인 한국어 국적/모국어 분류 — 실험 정리

**목표:** 외국어 억양 한국어 음성 → 외국어 61 + 한국어 = **62-class** 분류. 인코더 = XLS-R 2B (대부분 **동결**).
**평가:** speaker-disjoint(테스트 화자는 학습에 없음). 지표 = **top1 / top5 / macro-F1**, 전부 **62-class(한국어 포함) overall** 기준.
**feature:** 음성 앞 N초를 XLS-R로 mean-pool. 별도 표기 없으면 **12s**. split = target_counts.

---

## 3. Partial Finetune — 인코더 상위 8층 학습 (12s, **top-5 지표**)

> 주의: finetune 스크립트의 평가는 **macro/micro top-5** (위 실험들의 top1/top5와 지표 다름).

### 62-class run (`ft62_top8_12s`, 한국어 포함) — epoch 2에서 중단
| epoch | train_loss | test macro top5 | test micro top5 |
|--:|--:|--:|--:|
| frozen 기준 | — | 0.498 | 0.931 |
| 1 | 0.359 | 0.493 | 0.739 |
| 2 | 0.068 | 0.496 | 0.765 |

### 61-class run (`ft_top8_fine811_12s`) — 10 epoch 완료
| epoch | train_loss | test macro top5 | test micro top5 |
|--:|--:|--:|--:|
| frozen 기준 | — | 0.498 | 0.931 |
| 1 | 0.386 | 0.401 | 0.701 |
| **5 (best)** | 0.020 | **0.500** | 0.754 |
| 10 | 0.009 | 0.454 | 0.730 |

→ 최선(ep5)에서도 macro top-5 0.50 ≈ frozen 0.498(동급), micro top-5 0.75 ≪ 0.93(하락) = **과적합, 개선 ❌.**

## 핵심 발견
**성능 = 발화 수가 아니라 "학습 화자 수".**
예: 투르크멘어(발화 1346개, **화자 1명**) → top1·top5 둘 다 0%. 화자 1명이면 새 화자(test)에서 못 맞힘.
