# 41클래스 국적 분류 — 505 vs 041 데이터셋 병합 실험 (v2)
> v1 대비: ① 데이터셋 실측 메타 정정(505=스튜디오❌ → **모바일 16kHz**) ② 진단 4종 추가(split 동결·노이즈 플로어·cross-domain·문장 누수) ③ **041 문장 필터** 결과(best) 반영.

## 0. 핵심 요약 (TL;DR)
- **데이터셋은 포맷이 근본적으로 다름**: 505=**모바일 16kHz·긴 낭독문장(12.6s/15단어)**, 041=**웹 48kHz·단어 55%+짧은문장(1~5s)**. ‘아시아 vs 유럽’이 아니라 **녹음환경+과제+길이** 미스매치.
- **단순 병합(혼합)은 순이득 아님**: micro top5 0.963→0.917(↓), macro 0.578→0.608(소폭↑).
- **split 미고정으로 일부 Δ는 운**: ‘우즈벡 −0.37’은 동결 test에선 **+0.04**(허상). 진짜 하락=영국·미국.
- **041 단어 데이터가 오히려 해로움** → **문장(≥4단어)만 쓰면 best**: **macro top5 0.578→0.675, micro 0.917→0.950, 거의 모든 유럽 클래스 향상.**
- **cross-domain 격차는 녹음/화자 지배**(문장으로 맞춰도 +0.07만 회복).
- **극소수 화자 클래스(칠레·타지키 등)는 평가 불가** → 다음 단계 drop 대상.

## 1. 실험 개요
- **과제**: 외국인의 한국어 발화로 **국적 41클래스** 분류 (40개국 + 한국어).
- **모델**: frozen XLS-R 2B → **layer 31 mean-pool** → linear probe. split=speaker-disjoint 8:1:1, seed 42.
- **병합**: 041 `nationality`→기존 40국 매핑, 외 국적 drop, 041 화자ID에 `EU_` prefix, 41클래스 중 **20개에 041 추가**.

v1의 Δ는 baseline/merged split이 달라 ‘효과인지 운인지’ 분리 안 됨. **동일 505 화자 test로** 재측정:
- 505 전체 top5: baseline 0.9638 → merged 0.9558 (**Δ −0.008**, 사실상 불변).
| 클래스 | v1 Δt5(다른split) | **동결 Δt5** | 판정 |
|---|---|---|---|
| 우즈베키스탄 | −0.37 | **+0.04** | 🔄 v1은 split운(혼동 아님) |
| 영국 | −0.16 | **−0.20** | 진짜 하락 |
| 미국 | −0.13 | **−0.085** | 진짜 하락 |
| 스페인/이탈리아/독일 | +0.95/+0.85/+0.53 | +0.69/+0.79/+0.44 | 진짜 향상 |
> → **‘우즈벡 −0.37’은 허상**(동일 test에선 향상). 진짜 하락은 영국·미국뿐.

### 8-2. seed 노이즈 플로어 (seed 42/7/123)
- 클래스별 top5 std **중앙값 0.008, 최대 0.086.** → **|Δtop5| < ~0.05는 노이즈**(특히 소수 클래스). v1 per-class Δ의 작은 값은 신뢰 불가.

### 8-3. cross-domain 전이 (20클래스, top5)
| 학습→평가 | top5 |
|---|---|
| 505→505 | 0.731 |
| 505→041(혼합) | 0.451 |
| 041→041 | 0.848 |
| 041→505 | 0.621 |
> **양방향 다 하락 = 도메인 갭 실재**(특히 505→041 −0.40). 한쪽이 다른쪽 포함하는 관계 아님.

### 8-4. 문장 누수 / 과제 차이
- **505∩041 prompt 겹침 = 0** (505=긴 낭독문장, 041=단어/짧은문장). 모델이 악센트 아닌 **‘단어냐 문장이냐’로 도메인 구분** 가능.

### 8-5. task-matched cross-domain (041을 문장만으로)
| 학습→평가 | top5 | vs 혼합 |
|---|---|---|
| 505→041(문장) | 0.521 | +0.07 |
| 041(문장)→041(문장) | **0.906** | (내부 매우 높음) |
| 041(문장)→505 | 0.657 | +0.04 |
> **문장으로 맞춰도 cross-domain 격차는 +0.07만 회복** → 격차는 **‘단어/문장’이 아니라 녹음/화자가 지배.** 단, **같은 도메인 내부에선 041 문장이 0.906로 매우 학습 잘 됨**(스페인 449명 등 화자 풍부 + 문장이 악센트 정보 많음).

## 9. 결론 & 다음 실험
### 핵심 결론
1. **505·한국어 성능은 병합해도 유지**(동결 test 0.9575→0.9587, 한국어 1.0). micro ‘하락’은 어려운 041 추가일 뿐 저하 아님.
2. **041 단어 데이터는 국적분류에 저가치/유해** → **문장(≥4)만 쓰면 best**(macro 0.578→**0.675**, micro 0.917→**0.950**, 유럽 클래스 대부분 향상).
3. **도메인 갭은 녹음(모바일16k vs 웹48k)·화자 지배** — 문장 맞춤으론 일부만 해소. 같은 도메인 내부 학습은 매우 잘 됨(041문장 0.906).
4. **극소수 화자 클래스(칠레·타지키·키르기스·투르크멘·콜롬비아)는 평가·학습 불가** — top5 ~0, 041 블록 평균을 끌어내림.
5. **v1의 일부 하락(우즈벡 등)은 split 운** — 동결 test로 정정.
### 한계점
- baseline/merged split 미고정(8장서 동결 재평가로 보완). 노이즈 플로어 ±0.05.
- 505=모바일/문장, 041=웹/단어 → **배포(웹+자연발화)는 둘 다와 다름** → 현재 0.95대는 낙관적, 실배포 ~0.87(041문장) 근처.
- frozen feature+linear: 도메인 불변/유사악센트 분리 구조적 불가.
### 다음 실험 우선순위
1. **꼬리 클래스 drop 기준 수립**(예: 병합 후 train 화자 ≥10) → 클래스셋 확정 + **split 동결.** (041 블록 평균↑ → micro/macro 추가 상승)
2. **041은 문장(≥4)만 사용** 확정 (재추출 불필요, 마스크 `sent_mask_ge4.npy`).
3. **녹음-매칭 augmentation**(505에 웹/대역제한) — 격차가 녹음 지배라 v1 예상보다 유망.
4. **encoder fine-tune(LoRA)+domain-adversarial** — frozen 한계 돌파.
5. **배포(웹) 평가셋 소량 수집** — 유일하게 의미 있는 지표 확정.
6. **505↔041 cross-domain**(8-3) 정기 추적.
