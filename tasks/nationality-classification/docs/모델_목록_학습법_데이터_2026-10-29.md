## 3. 시도했지만 안 쓴 것 (8:1:1 test)

대조군은 300m 전체 학습, 또는 LoRA 이어 · 행 균등 학습이다. 문서마다 적었다.

| 방법 | 데이터 · 학습 | 결과 | 근거 |
|---|---|---|---|
| 사후 로짓 보정 | 학습은 그대로, 추론 로짓에서 τ·log(학습 클래스 비율)을 뺀다 | 국가 평균 0.661 → 0.688 · 웹 전체 0.894 → 0.881 | 27 |
| 행 균등 전체 학습 · 손실 가중 · 행 상한(1만 / 2천) | 같은 목록에서 행 수나 손실 가중치를 조정 | 머리 국가와 웹 전체를 잃고, 같은 오경보율에서 꼬리 이득 없음 | 26 · 27 |
| 학습 안 함(동결 300m / 2B) · 사전학습부터 LoRA | 기본 학습 목록 | 크게 낮다 (꼬리 외 top-1 0.43 ~ 0.49) | 28 |
| 꼬리 오버샘플링 · 131 웹 음질 · 파형 증강 · CutMix | 꼬리 국가 행 3배, 131 을 웹 마이크 음질로 증강, 속도 · 음량 · 음색 · 잡음 · 자르기 | 꼬리가 오른 것처럼 보이지만 꼬리 국가를 더 자주 찍은 것뿐이다. 한국인 판정도 깨졌다 | 29 |
| 손실 함수 (focal · label smoothing · logit adjustment · 화자 적대) | 같은 목록 | 같은 오경보율에서 이득 없음 | 29 |

## 4. 요약

- 구조 · 손실 · 증강 · 합성 데이터 · 다른 입력(운율 · mel)으로는 꼬리 국가가 오르지 않았다. **학습 화자를 늘리는 것만** 효과가 확인됐다(34).
- 지금 바로 할 수 있는 개선은 운영 중인 run_zeroth 를 **300m 전체 학습**으로 바꾸는 것이다. 다만 앱에 붙이려면 한국인 판정 게이트를 다시 맞춰야 한다(`docs/최종_점검_국적_사투리_2026-10-26.md` — 실제 한국인 녹음을 외국인으로 판정한 사례).
- 모델 가중치: 서비스 배포본과 300m 전체 학습 · run_zeroth 학습 원본은 비공개 백업에 있다(`docs/WEIGHTS.md` §7 — `deploy/nat-npu-20261010/` · `train/nationality-full_300m-spk811/` · `train/nationality-run_zeroth/`).
