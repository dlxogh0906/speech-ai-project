# 외국인 한국어 발화 → 국적 분류 : 개발 과정 & 사고 흐름

> 목적: 한국어를 말하면 화자의 **국적을 예측**하는 모델(웹 데모용).
> 다국어 음성 인코더 **XLS-R 2B(wav2vec2)** + AIHub 외국인 한국어 발화 데이터.
> 이 문서는 단계마다 **왜 그렇게 했는지 / 어떤 생각으로 접근했는지 / 성능은 어땠는지**를 순서대로 기록.

## 한눈에 보는 흐름

| 단계 | 문제의식(왜) | 접근(생각) | 성능 |

## ① 베이스라인 — "일단 바닥을 알자"
- **💭 왜**: 모델을 튜닝하기 전에, 가장 단순한 구성이 어디까지 되는지 기준선이 필요했다.
- **🎯 접근**: XLS-R은 128개 언어로 사전학습된 인코더라 **이미 발음/악센트 정보를 품고 있을 것**이라는 가정. 그렇다면 인코더는 **동결**하고 위에 **얇은 linear 분류기**만 얹어도 되지 않을까 (싸고 빠르게).
- **🔧 한 것**: frozen XLS-R 최상위 층 mean-pool → linear, 61개 모국어 분류.
- **📊 성능**: **top5 0.937 / top1 0.731 / macro-F1 0.19.**
- **💡 깨달음**: top-k가 높은 건 **착시** — 중국·일본·베트남·태국 4개 대형 클래스가 다 먹은 것. macro가 바닥이라는 건 **소수 클래스(화자 몇 명)가 아예 안 배워진다**는 뜻. → 문제는 "모델"이 아니라 **데이터 분포(롱테일·화자 부족)** 라고 문제를 재정의.

## ② 레이어 선택 — "어느 층이 악센트를 담나"
- **💭 왜**: 인코더를 동결하기로 했으니, 성능을 바꿀 수 있는 사실상 유일한 손잡이는 **"48층 중 어느 층의 feature를 쓰느냐"** 였다.
- **🎯 접근**: wav2vec2 계열은 **층마다 담는 정보가 다르다**고 알려짐 — 초기층=화자ID/음향, 상위층=ASR(내용/음소). **국적=악센트**는 그 중간(중상위)에 있을 것이라 가설.
- **🔧 한 것**: 여러 층에서 feature를 뽑아 각각 probe로 비교.
- **📊 성능**: **layer 31**이 최상위 층 대비 macro top5 **0.50 → 0.58**. 가설이 맞았다. 덤으로 31층까지만 쓰면 추론도 ~35% 저렴.
- **💡 깨달음**: **올바른 층 선택만으로 공짜 개선.** 이후 모든 실험은 layer 31 고정.

## ③ 불균형 처방 — "롱테일을 살릴 수 있을까" (실패 기록)
- **💭 왜**: ①에서 롱테일이 병목으로 드러났으니, 표준 처방을 써보자.
- **🎯 접근**: 데이터가 불균형이면 **class weighting·리샘플링·augmentation·encoder 부분 fine-tune**으로 소수 클래스를 끌어올릴 수 있을 것이라 기대.
- **🔧 한 것**: 위 기법들을 하나씩 적용·비교.
- **📊 성능**: **전부 유의미 개선 실패.**
- **💡 깨달음**: 결정적. speaker-disjoint 평가에서 **화자 2~4명짜리 클래스는 어떤 재균형·증강으로도 "처음 보는 화자"로 일반화가 안 된다.** 근본 원인은 화자 수 그 자체 → **"알고리즘이 아니라 데이터(화자)를 늘려야 한다"** 로 방향 전환.

## ④ 국적 41클래스 재설계 — "제품에 맞는 라벨로"
- **💭 왜**: 제품 목표는 "모국어"가 아니라 **"국적"** 예측. 그리고 웹 데모엔 **한국인/외국인 구분**도 필요.
- **🎯 접근**: 모국어(61) → **국가(40)** 로 재매핑. 영어·스페인어처럼 여러 나라가 쓰는 언어는 **거주국 기준으로 분리**(영어→미국/영국, 스페인어→페루/콜롬비아/스페인/칠레). + **한국어 모국어 화자** 클래스 = 41클래스.
- **🔧 한 것**: 재매핑 후 speaker-disjoint 재split, layer31 12s feature로 linear probe.
- **📊 성능**: **micro top5 0.963 / top1 0.833 / macro top5 0.578**, **한국어 탐지 F1 0.9995**(거의 완벽).
- **💡 깨달음**: 제품 정의에 맞는 스킴 확정. 다만 **macro는 여전히 낮음** — 유럽/소수국은 화자가 1~4명이라 죽어있음(③의 병목 그대로). → "이 죽은 클래스들을 어떻게 살리지?"가 다음 과제.

## ⑤ 16s feature — "길게 들으면 더 나을까"
- **💭 왜**: 발화가 길수록 악센트 단서가 많을 것.
- **🎯 접근/🔧**: duration sweep에서 16s>12s 경향 확인 → 505+한국어 **16초 feature**도 추출(shard 저장·재개 가능 파이프라인 구축).
- **📊 성능**: 소폭 우세, 12s/16s 둘 다 캐시 확보(본 병합 실험은 12s로 진행).

## ⑥ 유럽 데이터셋(041) 병합 — "화자를 늘려 죽은 클래스를 살리자"
- **💭 왜**: ③의 교훈("데이터=화자를 늘려야")을 실행. 스페인 4명·루마니아 3명·콜롬비아 1명처럼 죽은 클래스를 **유럽 데이터(041)** 로 채우면 학습·평가가 가능해질 것.
- **🎯 접근**: **새 클래스는 안 만들고** 041을 기존 40국에 매핑(nationality 기준), 40에 없는 국적은 drop, 화자ID `EU_` prefix로 충돌 방지.
- **🔧 한 것**: 505+한국어+041(전체) 병합해 41클래스 재학습.
- **📊 성능**: micro top5 0.963 **→ 0.917 (↓)**, macro 0.578 → 0.608(소폭↑). **기대와 달리 순이득이 아니었다.**
- **💡 깨달음**: "데이터 추가 = 개선"이 성립 안 함. **왜 안 오르는지 곧이곧대로 믿지 말고 파헤치기로.**

## ⑦ 신뢰성/도메인 진단 — "숫자를 의심하라" (전환점)
- **💭 왜**: 하락이 진짜 효과인지, 아니면 측정 착시/운인지 구분해야 방향을 못 잃는다.
- **🎯 접근 & 📊 결과** (네 갈래로 각각 검증):
  1. **split 미고정** → 동일 505 화자 test로 **동결 재평가**: "우즈벡 −0.37"은 사실 **+0.04(허상)**. 진짜 하락은 영국·미국뿐.
  2. **노이즈 플로어**(seed 3개): 클래스별 top5 std 중앙 0.008 → **|Δ|<0.05는 노이즈.**
  3. **cross-domain**: 505→041 top5 0.45, 041→505 0.62 (양방향 하락) → **도메인 갭 실재.**
  4. **포맷 실측**: 505 = **모바일 16kHz·긴 낭독문장(12.6s)**, 041 = **웹 48kHz·단어 55%+짧은문장**. prompt 겹침 **0%**.
- **💡 깨달음**: 격차의 근본은 "아시아 vs 유럽"이 아니라 **녹음환경+과제+발화길이 미스매치.** 병합 모델이 악센트가 아니라 **"포맷"** 을 부분 학습하고 있었다. (그리고 이전에 봤던 하락들 상당수가 split 운이었음)

## ⑧ 문장 필터 = best — "양보다 포맷 정합"
- **💭 왜**: ⑦ 진단에서 **041의 "단어(발음과제)" 발화가 유해**하다고 지목됨 (505는 다 문장인데 041은 단어가 절반 이상).
- **🎯 접근**: 041에서 **단어를 빼고 문장(prompt ≥4단어)만** 505에 맞춰 병합하면 내용 confound가 줄 것. 게다가 화자들은 단어·문장을 다 읽었으니 **문장만 걸러도 화자는 유지**될 것이라 예상.
- **🔧 한 것**: 문장 마스크(≥4단어)로 041 필터 → 화자 95~100% 유지, 발화만 37%로 감소(재추출 없이 마스크로). 재학습.
- **📊 성능**: macro top5 0.578 → **0.675**, micro top5 0.917 → **0.950**. 거의 모든 유럽 클래스 향상(불가리아 +0.36, 브라질 +0.31, 카자흐 +0.29 …). **505·한국어 성능은 그대로 유지.**
- **💡 깨달음**: **데이터 "양"보다 "포맷 정합"이 중요.** 단어 발화는 국적분류엔 저가치. → 이 문장-병합 모델을 **best로 저장.**

## ⑨ 아시아(043) 선별 병합 — "필요한 곳에만 붓는다"
- **💭 왜**: ⑧ 이후에도 이란·파키스탄 등 7개 클래스는 평가불가, 인도·타지크 등은 죽어 있었다(전부 화자 부족 — ③의 병목). 아시아권 데이터셋(043)이 그 화자를 갖고 있었다.
- **🎯 접근**: ⑥의 실패(전부 병합 → 잘되는 클래스까지 오염)를 반복하지 않기 위해 **저성능/평가불가 14클래스만 선별** 병합. 인니·베트남(043의 85%, 이미 top5 0.88/0.99)은 의도적으로 배제. 문장 기준도 ⑧과 동일하게 prompt≥4단어로 통일(041 마스크가 발음과제 문장 40%를 포함했음을 재검증으로 확인 후 043도 동일 적용).
- **🔧 한 것**: 043 라벨 전수 → 14클래스 227화자 19,689문장 선별 추출(디스크는 zip 선별해제로 25GB만) → 동일 규격 feature → 4-way 병합(505+한국어+041문장+043) 재학습. 헤드라인이 "하락"으로 보여(micro 0.950→0.942, macro 0.675→0.632) **⑦의 방법론으로 재검증**: frozen head-vs-head + 혼합산수 + 043블록 해부.
- **📊 성능**: 하락은 전부 착시 — ①micro는 어려운 신규 test 2,609문항 편입 탓(제외 시 0.9505>0.9496), ②macro는 신규 3클래스 분모효과(동일클래스 0.6754→0.6756), ③클래스 하락은 칠레·필리핀(극소화자) 빼고 전부 split 화자교체. **같은 시험지에선 전면 우세: old-test macro 0.675→0.757(+0.082), 043-test top5 0.284→0.518.** 타지크 0→1.0, 인도 0.04→0.43, 우즈벡 0.69→0.88, 이란·파키스탄·방글라 평가가능화(34→37/41).
- **💡 깨달음**: **"어디에 붓느냐"가 "얼마나 붓느냐"보다 중요** — 19,689발화(505의 2%)로 macro +0.082. 그리고 043을 안 받은 콜롬비아·브라질·우크라이나까지 동반 상승 = 데이터 추가가 특정 클래스만이 아니라 결정경계 전체를 정리한다. 남은 한계는 여전히 화자 수(이란 14명·파키스탄 10명 → top5 0.16~0.26; 아프리카 3국은 데이터 부재로 평가불가 지속).

## 지금까지의 성능 요약 (한 표로)

| 시점 | 구성 | micro top5 | macro top5 | 비고 |
|---|---|---|---|---|
| ① | 61클래스, top층 | 0.937 | (macro-F1 0.19) | 롱테일 |
| ②→④ | 41클래스, layer31, 12s | **0.963** | 0.578 | 한국어 F1 0.9995 |
| ⑥ | +041 전체(혼합) | 0.917 ↓ | 0.608 | 순이득 아님 |
| ⑧ | +041 문장만 | 0.950 | 0.675 | 이전 best |
| **⑨** | **+043 선별 14클래스** | **0.959*** | **0.757*** | **현재 best** (*동일시험지 기준; 자체 시험지 0.942/0.632는 신규 클래스 편입 표기) |

> **지표 해석 주의**: top5 0.95는 큰 클래스가 끌어올린 다수가중치. **모든 국가 고르게는 macro 0.757**(동일시험지), **배포(웹) 현실치는 041 블록 0.87 / 043 블록은 화자수에 따라 0~0.92** 수준. 평가가능 37/41 (미평가: 에티오피아·르완다·잠비아·싱가포르).

## 관통하는 사고방식 (이 프로젝트에서 배운 접근법)

1. **바닥부터, 싸게** — frozen+linear로 최소구성 먼저. 비싼 걸 하기 전에 문제를 이해.
2. **문제를 재정의** — "모델이 약하다"가 아니라 "데이터 분포가 문제"임을 숫자로 확인(macro).
3. **실패를 기록** — 불균형 처방이 왜 안 되는지 안 것이 "데이터를 늘려야"라는 방향을 줌.
4. **숫자를 의심** — 하락이 효과인지 운인지 split 동결·노이즈 플로어로 검증(가장 중요한 전환점).
5. **원인을 갈라라** — "왜 안 오르나"를 녹음/과제/길이로 분해 → 진짜 레버(문장 필터)를 찾음.
6. **재현 가능하게** — 모든 수치를 소스 파일에서 산출, 보고서에 근거 경로 명시.

## 다음 단계 (우선순위, ⑨ 이후)

1. **꼬리 클래스 drop/불확실 처리 기준**(예: train 화자 <5 → deploy 제외) + **split 동결** → 최종 클래스셋 확정.
2. **화자 추가 수집이 유일한 레버인 클래스**: 이란(14명)·파키스탄(10명)·방글라데시(2)·네팔(4) — 043 화자 전부 넣고도 top5 0~0.26. 아프리카 3국(에티오피아·르완다·잠비아)은 데이터 자체가 없음.
3. **녹음-매칭 augmentation**(505에 웹/대역제한) — 격차가 녹음 지배라 유망.
4. **encoder fine-tune(LoRA) + domain-adversarial** — frozen 한계 돌파.
5. **배포(웹) 평가셋 소량 수집** — 유일하게 의미 있는 지표 확정.
6. 칠레·필리핀 확률잠식 완화(클래스 가중 등) · 문장 임계값(≥3/4/5) sweep — 소규모 ablation.
