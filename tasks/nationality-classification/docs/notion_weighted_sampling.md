# Weighted Sampling 실험 (클래스 불균형 가중 샘플링)

**무엇:** 데이터를 버리지 않고(전부 유지), **소수 클래스를 더 자주 뽑아서** 학습. 강도 = β.
- β=0 자연분포(=baseline), β=1 완전균형(모든 클래스 동일 빈도 = 표준 WeightedRandomSampler)
- 샘플 추출확률 ∝ (1 / 자기 클래스 발화수)^β

**조건:** 62-class(외국어 61 + 한국어), 12s feature, frozen XLS-R + linear head. split = target_counts(speaker-disjoint).

---

## 3. 결론
- **top5 오른 곳 = 화자 10명 이상 회복가능 클래스**: 스페인어 +10.0, 독일어 +9.1, 터키어 +6.1, 인도네시아어 +5.7, 광동어 +5.3.
- **대가 = head 클래스 top1 하락**(중국어 −9.7 등)이나 **head top5는 거의 무손실**(99%대 유지) → **top-5 지표엔 거의 공짜.**
- **화자 1~3 클래스는 그대로 0** (단일화자는 데이터 추가 외 답 없음).
- → **top-5 목표엔 β=0.75(또는 0.5)가 첫 실질 개선.**

다음: β 0.6~0.8 미세 sweep으로 최적점 확정 → layer selection과 결합.
