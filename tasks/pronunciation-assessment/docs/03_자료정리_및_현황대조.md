## 2. 프로젝트 배경과 목적

**사업 배경** (레츠고비버·v3 덱 p3~5): 체류 외국인 약 283만 명 시대, 정착의 최대 장벽은 언어(43.4%)이고 그 실체는 발음(학습 난제 1위 32%). 기존 STT 기반 서비스는 오발음을 "가장 가까운 표준어"로 복원해버려 무엇을·왜 틀렸는지 진단할 수 없다 → **원 음성 파형을 직접 분석**해야 한다는 것이 출발점.

**제품 목적**: 비버톡(Beavertalk) — 외국인 학습자의 한국어 발화에서
① 국적/모국어를 자동 분류(LID)하고 ② 어느 소리를 어떻게 잘못 냈는지 음소 단위로 짚고(MDD)
③ 그 학습자의 모국어(L1) 특유 오류 패턴 가중치(L1-prior)로 국적 맞춤 진단·교정 콘텐츠를 제공.
경쟁 우위 = 공식 범용 모델에 없는 **L1별 특화**(로드맵 p15 "공식 5종 어디에도 L1 조건화 없음").

**과제 맥락**: 2026 전북특별자치도 공공데이터 AI 활용 창업 경진대회(제품·서비스 개발 부문, 덱 2종 2026-07-14). AIHub 공공데이터(국적분류용 "외국인 한국어 발화" + 교육용 040~043 코퍼스, 총 1,725GB·13,376시간) 재가공이 핵심 스토리. B2G(전북 가족센터·언어교육원) 선진입 → B2C 앱 → B2B API 로드맵. 특허 3건 출원(2026-07-13 기준, 레츠고비버 p15).

**기술 전개의 실제 역사** (자료→진행 문서로 재구성):
1. **갈래 A(알고리즘, ~07-06 완결)**: Speech_lab record MDD 26.8만 + gold 188만 적재 → L1-prior 81개국·카탈로그·벤치마크(lift ×1.18) — 자료 폴더 문서 대부분이 이 시기의 산출물.
2. **갈래 B 1차(record 트랙, ~07-11)**: record 라벨로 CTC 학습 → gold 평가 0.208 미달·record 평가 0.80 천장 → 혼란.
3. **핵심 발견(07-13~15)**: 라벨 3종(TAG/record/gold)의 용도 구분 — **MDD 학습·평가 정답은 TAG(전문가 실현형 전사)뿐**. gold는 실현형이 없어 채점 자체가 성립 안 함(공식 0.96 모델도 gold에서 0.40).
4. **TAG 트랙 완성(07-15~19)**: 전 언어권 통합 학습 F1 0.9547 → LAR 도메인 적응(단어누락 정밀도 0.07→0.68) → GOP 점수 트랙 → 웹 데모 외부 공개. 이것이 "지금의 실제".
