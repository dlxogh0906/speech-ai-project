## 조건

- **녹음:** `manifest_foreign_clean_v2/test_unseen` 23,562개. 41개 모국어 화자 1,168명이다. **학습에 쓴 문항을 새 화자가 읽은 녹음**이며, 새 문장 일반화 수치가 아니다([08](08_문장암기_일반화.md)).
- **채점:** 다섯 모델 모두 `eval_actual_ctc.py score` 를 쓴다.

  - 화면 표시 규칙(문턱·VAD)은 적용하지 않았다. 모델이 낸 출력을 그대로 비교했다.

## 지표

- **인식률** = 1 − PER, PER = (S + D + I) ÷ N(정답 레이블 자모 수).
  - "오류가 있는 녹음"은 정답 레이블과 표준 발음이 다른 녹음이다(전체 6,496개, 그중 단어 4,405개).
- **재현율 · 정밀도 · F1 · FRR:** MDD 계층 평가 정의(TA·FR·FA·TR)를 따른다.
  - **진단 정확도** = CD ÷ (CD + DE) = 1 − DER
  - **FRR(헛지적)** = 맞게 읽은 자리 중 모델이 다르게 적은 비율

## 주의

- **Whisper 받아쓰기의 숫자·영문:** 받아쓰기의 4.4%(1,029녹음)에 숫자·영문이 섞여 KoG2P가 일부를 읽지 못했다. 그 녹음을 빼고 재도 F1 0.248, 헛지적 11.47%로 결론이 같다.
- **영어 화자:** 영어 화자만 보면 slplab의 PER이 더 낮다(4.51% vs M3 5.52%, M2 5.27%). 나머지 8개 모국어 그룹은 M3가 더 낮다.
- **헛지적:** M3는 오류를 더 잡는 대신 헛지적이 1.49% → 2.55%로 늘었다.

## 재현

```bash
source tools/env.sh; E=tasks/pronunciation-assessment/scripts/eval; A=$MDD_OUTPUTS/analysis; X=$MDD_OUTPUTS/experiments
$PY $E/compare_public_baselines.py \
  --utt whisper=$A/baselines_2026-11-03/whisper_test_unseen.utt.jsonl --utt m1=$A/baselines_2026-11-03/m1_test_unseen.utt.jsonl \
  --utt slplab=$X/slplab_compare/slplab_test_unseen.utt.jsonl --utt m2=$X/w2vbert/w2vbert_fcv2_test_unseen.utt.jsonl \
  --utt m3=$A/sentence_jamo_accuracy_2026-11-03/m3_test_unseen.utt.jsonl --pair slplab m3 \
  --out $A/baselines_2026-11-03/compare_public_baselines.json
```

`*.utt.jsonl`은 각 모델의 `*_preds.jsonl`을 `eval_actual_ctc.py score`로 채점해 만든다.
- **Whisper:** `baseline_whisper_kog2p.py`로 예측을 만든다(transformers ≥ 4.36 환경).
- **M1:** `decode_hf_ctc.py`로 예측을 만든다.
