# 발음평가 MoE 파일럿

2026-10-31 10:09 KST 학습·평가 완료. **이번 MoE 후보는 사전 기준 미달로 운영 미채택이다.** 운영 M3는 유지한다. §1~3은 실행 전에 고정한 설계, §4는 완료 결과다.

**무엇이 달라졌나:** 바깥 평가에서 동일 비율 혼합→MoE의 정상 헛지적률은 6.15→6.06%, 정확 진단은 35.69→37.40%였다. 그러나 기존 일반 CTC와 비교하면 오류를 114개 더 정확히 잡는 동안 정상 헛지적도 1,957개 증가했고, 내부 평가에서는 정확 진단 증가와 정상 1% 기준에 모두 실패했다. 바깥 정확 진단 차이의 문항 bootstrap 구간은 두 대조군 대비 모두 0을 포함한다. 이 결과로 MoE의 일반적인 개선 효과를 확인했다고 할 수 없다.

## 1. 무엇을 시험하나

**질문:** 음성에 따라 전문가의 조합을 학습하면, 같은 전문가를 항상 동일 비율로 사용하는 모델보다 발음 오류를 정확하게 찾을 수 있는가?

| 비교 모델 | 바꾸는 것 | 이번에 완료한 학습 |
|---|---|---:|
| 기존 일반 CTC(C0) | 과거 fold0 대조군의 저장 모델·예측 사용 | 0회, 기존 결과 재집계 |
| **동일 비율 대조군** | 4개 전문가의 출력을 항상 25%씩 혼합 | 같은 부모에서 추가 2,000회 |
| **MoE 후보** | 음성 특징으로 계산한 softmax 비율에 따라 4개 전문가 혼합 | 같은 부모에서 추가 2,000회 |

전문가는 각각 `1024 → 256 → 1024`의 작은 신경망이며 12층 특징을 읽는다. 라우터는 12층·24층 음성 특징을 읽고 프레임마다 네 비율을 정한다. 혼합 결과를 24층 표현에 더한 뒤 기존 CTC 출력층으로 자모를 예측한다. 정답 음소·문항·모국어를 라우터에 입력하지 않는다.

네 전문가를 모두 계산하는 **dense MoE**다. 일부 전문가만 실행하는 sparse MoE의 속도 절감이나 거대 MoE 백본을 시험하는 것은 아니다. 전문가가 특정 음소를 담당한다고 미리 지정하지 않으며, 실제 역할 분화도 결과로 확인해야 한다.

148만 비원어민 발화 전체를 새로 다시 학습하는 실험이 아니다. 위 자료는 기존 자료를 재분할한 **개발 비교**이고, 이미 평가한 fold0를 재사용한다. 새 독립 최종 검증으로 부르지 않는다. 기존 가중치 λ=.3은 적용하지 않는다.

## 3. 성공·중단 기준

문턱은 보정 자료에서만 정하고 내부·바깥 평가에 고정한다. 아래 조건을 **내부 평가에서 모두** 만족해야 이번 후보를 통과로 기록한다.

| 확인할 것 | 통과 기준 |
|---|---|
| 정상 보호 | 채점 가능한 정상의 헛지적률 ≤ **1%** |
| 실제 오류 검출 | 전체 확정 오류의 정확 진단 재현율이 **동일 비율 대조군과 기존 C0 모두 초과** |
| 채점 범위 | 정상·오류 각각의 Coverage가 두 대조군 이상 |
| 특정 음소·삭제·삽입의 손해 | 오류 30개 이상 범주의 정확 재현율 감소가 두 대조군 대비 각각 5%p 이내 |
| 불필요한 삽입 지적 | 정상 gap의 헛삽입률 증가가 각각 0.2%p 이내 |

잘못 발음한 위치를 찾았어도 실제 소리를 틀리게 지적하면 정확 진단에 포함하지 않는다. 관측할 수 없는 오류도 전체 확정 오류 분모에 남긴다. 문항·화자를 각각 묶은 paired bootstrap 구간을 함께 보고한다. 단일 seed·고정 보정 문턱·반복 사용한 개발 자료의 결과라는 제한이 있다.

통과하지 못하면 이 후보를 실패로 기록한다. 통과하더라도 추가 fold 실행·운영 배포가 자동으로 승인되는 것은 아니다.
