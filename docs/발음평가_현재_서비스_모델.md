# 발음평가 현재 서비스 모델

문서 갱신: **2026-10-29 KST** · 마지막 원격 운영 확인: **2026-10-25 KST**.

**마지막으로 확인한 한국어 발음평가 운영 모델은 M3, `w2vbert_synth_tense_v2/step_3000`이다.** w2v-BERT 2.0 기반 추가 학습 모델을 100% 사용한다. 이 문서 갱신 과정에서 서버를 다시 조회하거나 재시작하지 않았다.

## 성능과 과거 XLS-R 수치의 비교

**M3 운영 설정을 재현한 보존 평가의 오류 재현율은 31.95%, 정밀도는 46.29%, 오류 검출 F1은 0.3781이다.** 10월 22일 표시 코드 수정까지 반영한 값이며, 오늘 운영 요청 전체에서 새로 측정한 값은 아니다. 과거 XLS-R의 **weighted F1 0.9547**과는 지표부터 다르다.

| 지표 | 과거 XLS-R `tag_all_lar` | M3 운영 설정 재현 | 기록값 차이(M3−과거) |
|---|---:|---:|---:|
| 정상 포함 weighted F1 | 0.9547 | 동일 조건 비교값 미확인 | 계산 불가 |
| 오류 검출 F1 | 0.4319 | **0.3781** | **−0.0538** |
| 오류 재현율 | 40.22% | **31.95%** | **−8.27%p** |
| 오류 정밀도 | 46.63% | **46.29%** | **−0.34%p** |
| 발음숙달 PCC · 화자 단위 | 0.6622 | 0.683 | 약 +0.0208 |
| 이해가능 PCC · 화자 단위 | 0.6825 | 0.713 | 약 +0.0305 |
| 유창성 PCC · 화자 단위 | 0.7618 | 0.752 | 약 −0.0098 |

**마지막 열은 서로 다른 평가 기록의 산술 차이다. 같은 조건에서 측정한 모델 교체 효과는 아직 제시할 수 없다.**

- **과거 오류 평가:** TAG test 178,049발화, 정상/오류 1,799,725위치 중 오류 74,439개. canonical·TAG·인식열의 3열 정렬 뒤 오류 여부를 이진 채점한다. 정상 비중이 95.86%여서 전부 정상으로 판정해도 weighted F1은 0.9384다. 원래 0.9547은 이 기준선보다 +0.0163이며 오류 검출률 95.47%를 뜻하지 않는다. 예측에 따라 정렬 위치·정답 분모가 달라지는 기존 채점기의 한계도 있다. [원 결과](../tasks/pronunciation-assessment/results/01_mdd_모델별성능.json), [기존 평가 감사](../tasks/pronunciation-assessment/results/06_실험감사.md).
- **M3 화면 평가:** 학습에서 본 224문항, 학습에 쓰지 않은 화자의 테스트 6,720발화 중 당시 말소리 1초 조건을 통과한 **2,281발화**다. 표준발음 보정·표시 정책 적용 후 TP 631·FP 732·FN 1,344이며, 재현율 `631/1,975`, 정밀도 `631/1,363`, F1 `2×631/(2×631+732+1,344)=0.3781`이다. **헛지적 발화 19.6%**도 같은 부분집합의 값이다. 거절된 4,439발화를 포함한 전체 서비스 검출률이나 새 문장 성능으로 해석하지 않는다. 이 카운트는 오류 자리의 경고 여부를 세며, 지적한 실제음이 TAG와 같은지까지 요구하지 않는다. [배포 검증 §3·§10](발음평가_개선_반영_2026-10-21.md).
- **점수 평가:** 과거 PCC는 화자별 전체 가용 발화(약 150개)를 평균한 값이다. M3는 통과 문장 26,390발화·테스트 화자 800명의 별도 평가이며 화자당 10발화 이상에서 평균을 비교한다. 옛 30발화 집계 0.6455/0.6707/0.7615와도 조건이 다르다. M3의 **화면 0~100점** PCC는 종합 0.612·발음 0.502·유창성 0.659로, 위 **1~5점 회귀 출력**의 PCC와 구분한다. [과거 점수 원 결과](../tasks/pronunciation-assessment/results/03_점수_3종.json), [M3 점수 검증](발음평가_개선_반영_2026-10-21.md#3-5-점수).

M3 원시 근거는 `$MDD_OUTPUTS/analysis/canonical_source_2026-10-11/report_ft3000_margin1_ds50m.json`의 `report.accepted_only.전체.choose`와 `$MDD_OUTPUTS/analysis/score_shift_ft3000_2026-10-19/report.json`이다. F1과 차이는 위 저장 카운트·보고값으로 계산했으며, PCC 차이는 M3의 소수 셋째 자리 보고값을 사용한 근삿값이다.

**동일 조건 비교의 빈칸:** `tag_all_lar`와 M3의 동일 UID·입력 검사·기준열·정렬·표시 정책 비교, 그리고 동일 화자·발화 수로 집계한 PCC 비교가 필요하다. 현재 표만으로 M3가 XLS-R보다 좋아졌거나 나빠졌다고 결론내리지 않는다. 옛 표의 `F1 0.70 / PCC 0.60 달성` 표시는 당시 지표·집계에 한정하며, 현재 서비스 목표 달성으로 이어지지 않는다.

| 입력 버킷 | 192 / 448 / 1024 프레임 |
