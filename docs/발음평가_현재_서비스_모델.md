# 발음평가 현재 서비스 모델

문서 갱신: **2026-10-29 KST** · 마지막 원격 운영 확인: **2026-10-25 KST**.

**마지막으로 확인한 한국어 발음평가 운영 모델은 M3, `w2vbert_synth_tense_v2/step_3000`이다.** w2v-BERT 2.0 기반 추가 학습 모델을 100% 사용한다. 이 문서 갱신 과정에서 서버를 다시 조회하거나 재시작하지 않았다.

위 절대경로는 **원격 NPU 서버**의 경로다. GitHub에는 코드·문서가 있으며 모델 가중치와 컴파일 자산은 별도로 관리한다. 저장소 앱의 기본 인자만으로 운영 모델·설정이 선택되는 것은 아니다.

## 이전 모델·로컬 실행·연구 모델 구분

| 구분 | 모델 / 경로 | 역할 |
|---|---|---|
| **NPU 운영** | **M3 `w2vbert_synth_tense_v2/step_3000`** | 10월 21일 100% 모델 반영, 10월 25일 실행 상태 확인 |
| 이전 NPU 운영 | 기존 모델과 추가 학습 모델의 50:50 혼합, `mix_2026-10-16/` | 10월 17일 반영 후 M3 100%로 교체. 과거 배포·되돌리기 기록 |
| 기존 CLI / `deploy/mdd-api` | XLS-R 300M `tag_all_native` + `score_models_v2_native.joblib` | `deploy/serve.sh mdd` · `deploy/infer_mdd.sh`의 기존 번들 경로. `MDD_SERVE_CKPT` / `MDD_SERVE_SCORER`로 지정 |
| 과거 평가 / `deploy/mdd-demo` 기본값 | XLS-R 300M `tag_all_lar` | weighted F1 0.9547 · PCC 0.662/0.683/0.762의 근거 모델. M3 운영 성능으로 인용하지 않음 |
| 연구 | H0 백본 비교, P1 probe, P3 B0~B3, P6 기여도 계산, λ=.3 fold0 통제 파일럿 등 | 오프라인 진단·통제 비교. 운영 채택 기록 없음 |

`tag_all_native`의 weighted F1 0.9558 역시 해당 모델·평가셋의 과거 결과다. 연구의 `prior` 기준이나 H0 성적도 순수 운영 응답과 구분한다. 최근 연구 진행과 성능은 [진단 감사·후속 실험 기록](발음평가_진단누락정보_감사_2026-10-26.md)을 따른다.
