# 발음평가 현재 서비스 모델

문서 갱신: **2026-10-29 KST** · 마지막 원격 운영 확인: **2026-10-25 KST**.

**마지막으로 확인한 한국어 발음평가 운영 모델은 M3, `w2vbert_synth_tense_v2/step_3000`이다.** w2v-BERT 2.0 기반 추가 학습 모델을 100% 사용한다. 이 문서 갱신 과정에서 서버를 다시 조회하거나 재시작하지 않았다.

## 성능과 과거 XLS-R 수치의 비교

**w2v-BERT가 모든 기준에서 더 좋다는 결론은 아니다.** 기존 학습 문항에서는 XLS-R보다 오류를 더 검출했지만 정상 헛지적도 늘었다. 같은 학습량의 새 문항 실험에서는 CAL 문턱 적용 후 XLS-R이 더 나았고, 두 모델 모두 정상 헛지적 1% 목표를 넘었다. 아래에서 완성된 모델 비교와 학습 조건을 통제한 백본 비교를 구분한다.

**과거 weighted F1 0.9547과 같은 지표도 측정할 수 있다.** 같은 평가 녹음의 모델 예측을 같은 채점기에 넣으면 된다. 예측 캐시가 있으면 재집계하고, 없으면 해당 모델로 추론해야 한다. 직전 문서의 ‘미확인/계산 불가’는 측정 불가능이 아니라 **`tag_all_lar`와 현재 M3를 그 조건으로 직접 비교한 결과를 제시하지 못했다는 뜻**이었다. 다른 시험의 숫자를 뺀 열은 모델 선택에 답하지 못하므로 제거했다.

### 같은 녹음에서 비교한 기존 모델: 검출 증가와 헛지적 증가

10월 16일 보존 결과는 **XLS-R `tag_all_native` 대 w2v-BERT M2 `step_38000`**다. 같은 30문항·23,562발화, 같은 VAD·greedy 인식·기준열 투영을 사용했고 화면 표시 문턱은 적용하지 않았다. 두 모델이 학습에서 본 문항의 새 화자 평가다. `tag_all_lar`나 현재 M3의 직접 비교로 바꾸어 읽지 않는다.

| 같은 23,562발화 | XLS-R `tag_all_native` | w2v-BERT M2 | M2−XLS-R |
|---|---:|---:|---:|
| 오류 검출 F1 | 0.4331 | **0.4567** | +0.0236 |
| 오류 재현율 | 41.81% | **48.76%** | +6.95%p |
| 오류 정밀도 | **44.92%** | 42.95% | −1.96%p |
| 정상 헛지적률 · 낮을수록 좋음 | **2.09%** | 2.64% | +0.55%p |
| 실제음까지 맞힌 오류 비율 | 35.12% | **40.98%** | +5.86%p |

**이 시험에서는 w2v-BERT M2가 오류 검출 F1과 실제음 진단에서 나았다. 정상 보호와 지적 정밀도는 XLS-R이 나았다.** F1의 재현율은 오류 자리에서 기대음과 다르게 인식했는지를 세며, 실제음까지 맞힌 비율은 별도 행이다. 완성된 모델의 학습 이력이 다르므로 차이를 백본 구조만의 효과로 해석하지 않는다.

원시 근거: `$MDD_OUTPUTS/analysis/compare_vs_old_2026-10-16/{old_xlsr,base}.json`. 모델 경로·발화 수·manifest와 [채점 코드](../tasks/pronunciation-assessment/scripts/eval/eval_tense_ft.py)의 `site_stats`를 대조했다. [당시 비교 보고서](발음평가_개선_반영_2026-10-17.md#3-2-모델-단독-성능-화면-규칙-없이-받아쓰기-기준)의 ‘처음 XLS-R’은 이 `tag_all_native`다.

현재 M3의 추가 학습 효과도 **별도의 동일 15,000발화**에서 측정돼 있다. M2→M3는 오류 F1 **0.4673→0.4823**, 오류 재현율 **51.61→59.02%**, 실제음까지 맞힌 비율 **43.34→49.64%**였고, 정상 헛지적도 **2.69→3.33%**로 늘었다. 화면 표시 전 인식 평가이며 위 23,562발화 표와 이어 붙여 XLS-R→M3 차이를 계산할 수 없다. 근거는 `$MDD_OUTPUTS/analysis/synth_tense_ft_v2_2026-10-12/{base,v2_3000}.json`이다.

### 같은 학습량의 새 문항 비교: 보정 후 XLS-R 우세, 두 모델 모두 목표 미달

H0는 두 백본을 각각 원어민 Stage1 10k→Stage2 4k까지 같은 배치·노출량으로 학습했다. 각 모델의 seen CAL 정상에서 1% 문턱을 정하고, 학습에서 제외한 **9문항·4,009발화**에 그대로 적용한 결과다. 기존 운영 모델과 다른 연구 모델이며, 이 9문항은 반복 분석한 개발 자료다.

| 백본 / Stage2 | 새 문항 정상 헛지적률 · 낮을수록 좋음 | 새 문항 정확 실제음 진단 재현율 · 높을수록 좋음 |
|---|---:|---:|
| w2v-BERT 2k | 1.95% | 11.03% |
| XLS-R 300M 2k | **1.88%** | **11.81%** |
| w2v-BERT 4k | 4.82% | 12.20% |
| XLS-R 300M 4k | **2.87%** | **13.83%** |

**이 보정 정책의 관측 결과는 XLS-R이 낫다. w2v-BERT의 새 문항·저오탐 진단 우월성을 뒷받침하지 않는다.** 반면 문턱 적용 전에는 w2v-BERT의 정상 헛지적이 더 낮았다(4k: 17.63% 대 20.48%). 인식 출력과 CAL 보정의 새 문항 이전은 서로 다른 결과다. 단일 seed·초기 2k/4k 비교이며, 백본 전체의 우열이나 현재 M3의 교체 결론으로 확대하지 않는다. [통제 조건·전체 결과·불확실성](발음평가_진단누락정보_감사_2026-10-26.md#154-초기-스크리닝-완료-2026-10-27).

### 현재 서비스의 보존 성적과 과거 대표 성적

**M3 운영 설정을 재현한 보존 평가의 오류 재현율은 31.95%, 정밀도는 46.29%, 오류 검출 F1은 0.3781이다.** 10월 22일 표시 코드 수정까지 반영한 값이며, 오늘 운영 요청 전체에서 새로 측정한 값은 아니다. 과거 XLS-R의 **weighted F1 0.9547**과는 지표부터 다르다.

| 지표 | 과거 XLS-R `tag_all_lar` | M3 운영 설정 재현 · 다른 평가셋/정책 |
|---|---:|---:|
| 정상 포함 weighted F1 | 0.9547 | 과거 조건으로 직접 비교한 결과 미제시 |
| 오류 검출 F1 | 0.4319 | **0.3781** |
| 오류 재현율 | 40.22% | **31.95%** |
| 오류 정밀도 | 46.63% | **46.29%** |
| 발음숙달 PCC · 화자 단위 | 0.6622 | 0.683 |
| 이해가능 PCC · 화자 단위 | 0.6825 | 0.713 |
| 유창성 PCC · 화자 단위 | 0.7618 | 0.752 |

이 표는 평가 이력이 다른 기록을 식별하기 위한 표다. 모델 우열은 앞의 동일 조건 비교에서 판단한다.

- **과거 오류 평가:** TAG test 178,049발화, 정상/오류 1,799,725위치 중 오류 74,439개. canonical·TAG·인식열의 3열 정렬 뒤 오류 여부를 이진 채점한다. 정상 비중이 95.86%여서 전부 정상으로 판정해도 weighted F1은 0.9384다. 원래 0.9547은 이 기준선보다 +0.0163이며 오류 검출률 95.47%를 뜻하지 않는다. 예측에 따라 정렬 위치·정답 분모가 달라지는 기존 채점기의 한계도 있다. [원 결과](../tasks/pronunciation-assessment/results/01_mdd_모델별성능.json), [기존 평가 감사](../tasks/pronunciation-assessment/results/06_실험감사.md).
- **M3 화면 평가:** 학습에서 본 224문항, 학습에 쓰지 않은 화자의 테스트 6,720발화 중 당시 말소리 1초 조건을 통과한 **2,281발화**다. 표준발음 보정·표시 정책 적용 후 TP 631·FP 732·FN 1,344이며, 재현율 `631/1,975`, 정밀도 `631/1,363`, F1 `2×631/(2×631+732+1,344)=0.3781`이다. **헛지적 발화 19.6%**도 같은 부분집합의 값이다. 거절된 4,439발화를 포함한 전체 서비스 검출률이나 새 문장 성능으로 해석하지 않는다. 이 카운트는 오류 자리의 경고 여부를 세며, 지적한 실제음이 TAG와 같은지까지 요구하지 않는다. [배포 검증 §3·§10](발음평가_개선_반영_2026-10-21.md).
- **점수 평가:** 과거 PCC는 화자별 전체 가용 발화(약 150개)를 평균한 값이다. M3는 통과 문장 26,390발화·테스트 화자 800명의 별도 평가이며 화자당 10발화 이상에서 평균을 비교한다. 옛 30발화 집계 0.6455/0.6707/0.7615와도 조건이 다르다. M3의 **화면 0~100점** PCC는 종합 0.612·발음 0.502·유창성 0.659로, 위 **1~5점 회귀 출력**의 PCC와 구분한다. [과거 점수 원 결과](../tasks/pronunciation-assessment/results/03_점수_3종.json), [M3 점수 검증](발음평가_개선_반영_2026-10-21.md#3-5-점수).

M3 원시 근거는 `$MDD_OUTPUTS/analysis/canonical_source_2026-10-11/report_ft3000_margin1_ds50m.json`의 `report.accepted_only.전체.choose`와 `$MDD_OUTPUTS/analysis/score_shift_ft3000_2026-10-19/report.json`이다. F1은 위 저장 카운트로 계산했다.

**동일 조건 비교의 빈칸:** `tag_all_lar`와 M3의 동일 UID·입력 검사·기준열·정렬·표시 정책 비교, 그리고 동일 화자·발화 수로 집계한 PCC 비교가 필요하다. 현재 표만으로 M3가 XLS-R보다 좋아졌거나 나빠졌다고 결론내리지 않는다. 옛 표의 `F1 0.70 / PCC 0.60 달성` 표시는 당시 지표·집계에 한정하며, 현재 서비스 목표 달성으로 이어지지 않는다.
