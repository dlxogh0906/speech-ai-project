# 일부러 틀린 발음 녹음 부탁드립니다

발음 평가가 **일부러 틀리게 읽은 소리를 제대로 잡는지** 확인하려고 합니다.
예를 들어 "한국어"를 일부러 "한쿡어"로 읽었는데 결과에는 "한국어"로 나오는 문제가 있었습니다.
여러분의 녹음으로 실제로 얼마나 잡는지 재고, 고친 뒤에 다시 비교할 때도 같은 녹음을 씁니다.

- 1인당 **약 10분**, 녹음 파일 57개입니다.
- 녹음은 **사내 품질 평가에만** 씁니다. 외부 서비스로 보내지 않고, 이름 대신 화자 번호(s01, s02 …)로만 관리합니다.

## 녹음하는 법

1. 조용한 곳에서 휴대폰 기본 녹음 앱으로 녹음합니다. 입에서 15~20 cm 정도 떨어뜨려 주세요.
2. **문장 하나에 파일 하나**입니다. 문장 앞뒤로 0.5초 정도 여유를 두세요.
3. d01~d26 은 두 번씩 읽습니다.
   - **맞게(c):** 평소처럼 읽습니다.
   - **일부러 틀리게(w):** "일부러 읽을 형태" 칸의 **굵은 글자만** 바꾸고, 나머지는 평소처럼 자연스럽게 읽습니다.
4. k01~k05 는 **맞게(c) 한 번만** 읽습니다.
5. 파일 이름은 `화자번호_문장번호_c 또는 w` 입니다. 확장자는 앱이 만드는 그대로(m4a 등) 두면 됩니다.
   - 예: `s03_d01_c.m4a`(3번 화자, d01 맞게), `s03_d01_w.m4a`(일부러 틀리게)
6. 다 녹음하면 본인 화자 번호 폴더에 모아 공유 폴더에 올려 주세요. 화자 번호는 담당자가 드립니다.

## 담당자용

- 문장 목록 원본: `tasks/pronunciation-assessment/evalsets/deliberate_human_v1.csv`
- 채점: `$PY tasks/pronunciation-assessment/scripts/eval/eval_human_deliberate.py --recordings <모은 폴더> --out <결과 폴더>`
