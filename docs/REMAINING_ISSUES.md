## 리팩터링으로 해결된 것 (참고)

- 경로 하드코딩 — `sys.path.insert("$HOME/…")` 41곳, `$HOME` 119파일, `$SPEECH_AI_DATA` 84파일 → `shared/paths.py` 한 곳
- 데모 파일을 라이브러리로 import 하던 구조 (6곳) → `src/mdd/pipeline.py` 분리
- `gop_feats_v2` 의 import 시점 `parse_args()` → `main()` 안으로. argv 우회 6곳 제거
- 의존성 파일 부재 → `requirements-*.txt` 2개 + `pyproject.toml`
- 민감정보 — 스캔 결과 API key/token/credential **0건**. 내부 Tailscale 도메인만 문서에 남김
