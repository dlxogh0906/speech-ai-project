## 리팩터링으로 해결된 것 (참고)

- 경로 하드코딩 — `sys.path.insert("$HOME/…")` 41곳, `$HOME` 119파일, `$SPEECH_AI_DATA` 84파일 → `shared/paths.py` 한 곳
- 데모 파일을 라이브러리로 import 하던 구조 (6곳) → `src/mdd/pipeline.py` 분리
- `gop_feats_v2` 의 import 시점 `parse_args()` → `main()` 안으로. argv 우회 6곳 제거
- 의존성 파일 부재 → `requirements-*.txt` 2개 + `pyproject.toml`
- 민감정보 — 스캔 결과 API key/token/credential **0건**. 내부 Tailscale 도메인만 문서에 남김
| 12 | **국적 ONNX 가 `batch=1` 고정 수출** | 배치 추론 불가 (배치 2 에서 `INVALID_ARGUMENT`) | 지금은 문제 없다 — CPU 에서 배치가 무의미한 게 원본으로 확인됐고(128배 키워도 1.2배) ONNX 단건이 PyTorch 배치보다 빠르다. **GPU 서빙으로 갈 때** `dynamic_axes` 재수출 + `onnxruntime-gpu` 설치를 같이 한다 |
| 13 | **배치 256 에서 GPU 처리량이 5배 무너진다** | 배치 상한이 128 로 묶인다 | 발음·국적 네 모델이 전부 47~58 건/초로 수렴 — 모델이 아니라 런타임 문제다. 메모리는 33.5/80 GB 로 여유. cuBLAS 워크스페이스 고갈이나 할당자 단편화로 추정하나 **원인 미확정**. `results/08_추론속도.md` |
| 14 | **KD 모델이 배포에 안 붙어 있다** | 국적 최고 성능(top-5 0.9584)이 서비스에 반영 안 됨 | 8905 는 데모, 실서비스 8900 은 구모델(0705, 0.9331). **8900 은 타인 사용 중이라 불가침** — 소유자 협의 + 병행 검증 후 전환 |
| 15 | **KD baseline 비교표에 두 출처가 섞여 있다** | 결론엔 영향 없으나 엄밀하지 않다 | `results/07_인코더증류.json` 의 baseline 행은 출하본 값(0.7510/0.9331/0.6170)인데 `clean_macro5` 만 재평가값이다. KD 파이프라인 재평가값은 0.7512/0.9333/0.6181 (차이 0.02%). 재평가값으로 통일할 것 |
