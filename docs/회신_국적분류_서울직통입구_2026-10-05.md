# 회신: 국적 분류 API 서울 직통 입구 추가

작성 2026-10-05 · NPU 서버 운영 담당 → 웹(accent.beavertalk.im) 연동 담당

## 요약

- **열었다.** 국적 분류 API 를 발음 API 와 같은 서울 직통 입구(Caddy 443)에 열었다(2026-10-05 22:07).
  - 새 주소 값과 토큰은 이 문서와 따로 전달한다.
  - 웹 서버 환경변수(`NATIONALITY_URL` 과 토큰 변수)에만 넣어 주기 바란다.
- **3문장(15초 녹음) `/predict_long` 왕복은 p50 0.68초 · p90 0.72초다.**
  - 같은 조건에서 Funnel 경로는 p50 0.96초라, 약 0.28초 빠르다.
  - 남은 시간은 대부분 NPU 판정 시간(약 0.63초)이다.
- **자동 시작을 등록했다.** 국적 API · 발음 API · 입구가 모두 서버 재부팅이나 비정상 종료 뒤 자동으로 다시 뜬다.

## 확인 요청 회신 (요청서 3절)

| 순서 | 확인할 것 | 회신 |
|---|---|---|
| 1 | 추가 가능 여부 · 일정 | **완료**(2026-10-05 22:07). 주소 값은 따로 전달한다 |
| 2 | 새 입구 `/predict_long`(parts=3, 15초 안팎) 왕복 p50 · p90 | 아래 측정 표 |
| 3 | 인증 여부 · 방식 | **붙였다.** 헤더는 `X-API-Key: <토큰>` 또는 `Authorization: Bearer <토큰>` 중 하나다. `/health` 만 토큰 없이 연다. 토큰이 없거나 틀리면 401 `{"error": "토큰이 없거나 맞지 않다", "code": "unauthorized"}` 이 온다. 토큰 값은 따로 전달한다 |
| 4 | 동시 처리 한도 | 국적 서버 워커는 8개다. 3문장 `/predict_long` 은 건당 약 0.63초라, **동시 8건까지 대기 없이** 처리하고 그 이상은 줄을 서서 늦어진다. 처리 한도는 **초당 약 12건**(추정)이다 |

**측정 조건**: 3문장 녹음 15초(webm/Opus 95 KB), `parts=3`, 연결 재사용, 먼저 `/health` 로 연결을 연 뒤 연속 요청했다.

| 측정 위치 · 경로 | 횟수 | 왕복 p50 | 왕복 p90 | 최소 ~ 최대 | 서버 처리 p50 |
|---|---|---|---|---|---|
| NPU 서버 안 → 서울 직통 주소 | 20 | 675 ms | 725 ms | 598 ~ 734 ms | 630 ms |
| 다른 서버(GPU, 인터넷 경유) → 서울 직통 주소 | 15 | 683 ms | 720 ms | 612 ~ 722 ms | 634 ms |
| 다른 서버(GPU) → Funnel 주소(예비) | 15 | 960 ms | 984 ms | 904 ~ 1,031 ms | 641 ms |

- `Authorization: Bearer` 방식도 같은 시간이다(5회 p50 707 ms).
- 웹 서버(Cloud Run 서울)에서 잰 값을 공유해 주시면 이 표 옆에 붙이겠다.

## 요청 항목별 상태 (요청서 2절)

| 항목 | 상태 |
|---|---|
| 입구 | Caddy 443 에 국적용 주소 이름 1개를 추가했다. 인증서는 Let's Encrypt 이고 자동 갱신된다(지금 인증서 만료 2027-01-03) |
| 경로 | 토큰이 맞으면 기존 경로가 모두 그대로다(`POST /predict_long` · `POST /predict` 등). `/health` 는 토큰 없이 열린다 |
| 계약 | 지금 국적 API 와 같다(필드 · 응답 · 오류 코드). `/predict_long` 은 녹음을 저장하지 않는다 |
| 인증 | 토큰을 붙였다(위 3번) |
| 자동 시작 | 국적 API · 발음 API · 입구(Caddy)를 systemd 서비스로 등록했다. 재부팅이나 비정상 종료 때 자동으로 다시 뜬다 |
| 연결 유지 | 입구의 쉬는 연결 유지 시간은 **10분**이다(발음 입구와 같다). 웹의 5분 재사용은 그대로 써도 된다 |
| Funnel | 기존 주소를 그대로 둔다(토큰 없음). 웹이 바로 되돌릴 수 있다 |

## 참고

- **직통 주소는 API 전용이다.** 테스트 화면(`/multi` 등)도 토큰이 있어야 열린다. 화면 확인은 Funnel 주소의 `/multi` 로 한다.
- **`/predict_long` 응답에는 필드가 더 있다.** `n`(실제 판정 구간 수) · `parts_requested` · `voiced_sec`(말소리 길이) · `per_part` 다.
  - `n < parts_requested` 면 글을 끝까지 읽지 않은 것이다. 이때 정확도가 1문장 수준으로 떨어지니 "끝까지 읽으면 더 정확해요" 안내를 권한다.
- **출처 표기가 필수다.** 결과 화면에 AI 허브 출처 문구를 넣어야 한다.
  - 문구: 이 서비스는 한국지능정보사회진흥원의 「지능정보산업 인프라 조성」 사업으로 구축된 AI 허브(aihub.or.kr) 데이터를 활용해 개발했습니다.
- **판정 시간을 더 줄일 여지가 있다.** NPU 길이 버킷 모델로 바꾸면 3문장 기준 0.1초 안팎 줄 것으로 추정한다. 필요하면 따로 검토한다.
- **자세한 연동 방법**(요청 · 응답 · 오류 · 녹음 길이 기준 · 예제 코드)은 연동 가이드에 있다.
