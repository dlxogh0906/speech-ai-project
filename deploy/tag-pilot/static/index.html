발음 전사 P0

외국인이 읽은 한국어 문장을 듣고, 실제로 들린 소리를 한글로 적습니다. 발화 40개 · 약 5분 분량.

전사자:
전사 지침 (처음 한 번 꼭 읽기)
  • 들린 그대로 적습니다. 맞춤법·원문이 아니라 소리입니다. 예: "샀어요"가 [싸써요]로 들리면 싸써요.
  • 표준 발음 규칙(연음·된소리 등)은 실제로 그렇게 들렸을 때만 반영합니다. 아는 규칙대로 고쳐 쓰지 않습니다.
  • 빠진 소리는 지우고, 덧붙은 소리는 넣습니다. 더듬거나 반복한 부분도 들린 대로 적습니다.
  • 확신이 없는 글자 바로 뒤에 ? 를 붙입니다. 예: 싸?써요
  • 음절로 못 적는 소리는 낱자모로 적어도 됩니다(예: ㅅ).
  • 칸이 미리 채워진 발화는 표준 발음이 들어 있는 것입니다 — 틀린 데를 고치세요. 그대로 두면 "표준 발음대로 들렸다"는 뜻입니다.
  • 필요한 만큼 다시 들어도 됩니다(Esc). 제출은 Ctrl+Enter. 작업 시간이 자동으로 기록되니 중간에 쉴 때는 제출 후 쉬세요.
