rhythm = 이해도

overall = 0.6×발음 + 0.2×유창 + 0.2×이해. 발음은 음소를 실제 발음과 대조한 값(검증됨), 유창·이해는 학습자 분포의 백분위다(80 = 상위 20%. 발화 1개 기준 사람 채점과 상관 유창 0.61 · 이해 0.43). rhythm 칸에는 이해 가능성 점수가 들어간다. 0 점은 숫자 대신 — 로 표시된다(0 과 판정 못한 자리를 합쳤다).
