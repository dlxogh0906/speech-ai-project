무엇이 다른가 · 실측
두 쪽이 같은 것 — 표준발음 보정(10-17 운영 반영) · 짧은 문장 말소리 기준(10-18) · 예사소리를 된소리·거센소리로 확실히 들으면 점수가 높아도 지적(10-18) · 문장 점수 계산.
10-21 운영에서 바뀐 것
  1. 모델: 지금 모델과 2차 학습 모델을 반반 섞은 것 → 2차 학습 모델 100%
  2. 빠진 소리는 소리 흔적이 거의 없을 때(강제정렬 점수 50 미만)만 "틀림" — 흔적이 있으면 "애매"
  3. ㄴ↔ㄹ 을 확실히(확률 60% 이상) 바꿔 들으면 점수가 높아도 지적
  4. 잡음·음악만 녹음(기준 소리 90% 넘게 다르게 들림) → 채점 안 함 no_match
  5. 말한 부분이 20초 넘음 → 채점 안 함 too_long · 기준 문장에 한글 없음 → no_korean (③·④는 앱이 새 오류 코드를 처리한 뒤 켤 예정)
같은 시험으로 잰 값 (이전 운영 → 지금 운영)
· 원어민 헛지적(100음절당): 낭독 7.8 → 5.1 · 대화 8.0 → 5.7 — 지적이 하나라도 뜬 문장 낭독 85% → 73%
· 학습자 실제 녹음 3,472개: 헛지적 발화 15.4% → 15.5%(같음) · 진짜 오류 지적 34.6% → 35.3% · 지적이 맞을 확률 46.1% → 50.9%
· 오류 종류별: 첫소리 세기(ㄱ→ㅋ 등) 30.7% → 37.0% · 받침 35.3% → 49.9% · ㄴ↔ㄹ 47.2% → 65.0% · 모음 14.9% → 12.7%
· 나빠지는 것: 학습자가 진짜로 빼먹은 소리 지적 455곳 중 217 → 110 · 맞게 읽은 첫소리를 틀렸다고 함 1,000자리당 4.5 → 6.3
· 일부러 틀린 합성 녹음: 2차 학습에 넣은 5단어(진구·싸과·한쿡·콩부·뚜부) 100개 중 41 → 63 · 나머지 10단어 200개 중 159 → 164
· 잡음·음악만 녹음: 45~62점 줌 → 거절 · 점수: 사람 점수와의 상관 그대로(종합 −0.1점)
· 그대로인 것: 모음 오류와 은근한 ㅅ/ㅆ 실수는 두 쪽이 비슷합니다.
읽는 법 · 주의

· 틀림(빨강) = 받아쓴 소리가 표준발음과 다르고 점수도 낮아 화면에 지적되는 자리. 애매(노랑 점선) = 다르게 들렸지만 점수가 높아 지적하지 않은 자리. 아래 목록은 "기대 소리 → 들린 소리"입니다.
· 이해도 점수는 여러 문장을 모아야 나와서 한 문장 비교에서는 뺐습니다.
· 들린 그대로 = 모델이 받아쓴 소리를 글자에 맞춰 쓴 것(발음 표기). 색이 있는 글자가 표준 발음과 다르게 들린 곳이다 — 노랑은 다르게 들렸지만 점수 기준(60점 미만) 때문에 사용자 화면에 "틀림"으로 안 뜨는 자리.
· 모델 확률 = 그 글자 구간에서 모델이 각 소리에 준 확률(녹음을 표준발음에 맞춰 정렬한 뒤 구간 평균). 점수는 이 확률로 따로 계산한 발음 점수라 확률과 다르다.
· 채점 안 함(노랑 상자) = 그 쪽 API 가 400 오류로 돌려보내는 녹음. 앱에는 상자 안 문구 같은 안내가 갑니다.
