모델별 판정

test = 화자 분할 8:1:1 test 의 웹마이크 문장 발화(코퍼스). 9월 모델은 다른 분할로 학습해 같은 잣대가 없습니다.
알아 둘 점
  • test 수치는 AI 허브 코퍼스 안의 값입니다. 폰·노트북 녹음에서는 모델마다 순위가 달라질 수 있습니다. 서버에 저장된 한국인 녹음 34개에서 300m 전체학습이 Korea 를 1위로 고른 것은 원본 2개 · 무음 정규화 19개뿐이었습니다(10-26 점검). 서비스에 쓰려면 앞에 원어민 게이트가 필요합니다.
  • run_zeroth 의 test 수치는 누수 의심입니다. 화자 분할 전 목록으로 학습해 이 test 화자 일부를 봤을 수 있습니다.
  • GPU 모델은 bf16 으로 돕니다. 평가 로짓과 대조하면 300m 계열은 1위가 거의 같고, 2B 는 bf16 자체의 흔들림 때문에 일부 발화에서 1위가 바뀝니다.
  • 빠진 것: 언어식별 모델 그대로(107개 언어 출력이라 국적 분류기가 아님), 2B 첫 시도(학습이 멈춘 run_2b_lr5e-6_l24), 운율 점수를 나중에 합친 조합(따로 학습한 모델이 없음).
